# 世界史 · 架空历史总稿（2026-10-18，名字已定）

用户："我刚说的标注的出处都要来自于架空世界的历史，而不是现实世界，比如罗马在游戏里是什么 大希帝国，你要写好整个架空历史"。

**这份稿子的用法**
- 游戏里所有"出处"，包括技能、阶位称号、遗落物、书名、典故，都只能引这里的人和书，不引现实世界。
- 分两层：
  - **公开的历史**：世人相信的版本。游戏里的出处、教会的说法、学者的书都引这一层。
  - **真相**：只给写作的人看，随五章逐步揭开。公开历史里的空白和错处，都是真相留下的痕迹。
- 时代借了现实的轮廓：百城时代像古希腊，大希帝国像罗马，长夜和九邦时代像中世纪，繁花时代像文艺复兴，蒸汽时代像工业革命初期。但人、书、城、事全部是原创的。

## 一、纪年

世上通行**初灯纪元**（简称"灯纪"），由守灯会订立。灯纪元年是"大雾之年"结束、第一盏长明灯点起的那一年。

- 元年以前写作"灯纪前某年"。
- **游戏的当下是灯纪 1186 年。** 雾港码头东仓那场火在灯纪 1183 年冬天。

## 二、公开的历史

### 1. 传说时代（无年可考）

- 世人只知道一句："造物主分开了天与地、你与我，世上才有了别人。"教会都这样讲，讲法各不相同。
- 关于这以前的事，只剩些互相矛盾的碎片：旧神、巨人、一场烧尽一切的大火。学者大多当它们是寓言。

### 2. 百城时代（灯纪前 1000 年—前 420 年）

晨星海四周散落着上百座城邦，语言相近，彼此打仗，也彼此看戏。

**英雄时代**（约灯纪前 1000—前 800 年）
- **伊隆城之战**：诸城邦联军围攻伊隆城十年，城破。这一段只靠史诗流传。
- **盲诗人卡赛**作史诗《归航之歌》，写英雄**奥兰**战后十年漂泊回乡。
  - 最有名的一段：奥兰被独眼巨人困在山洞里，骗巨人说"我叫'无人'"。巨人被刺瞎后大喊"无人害我"，同伴以为他疯了，没有一个来帮他。
  - → 阶位 0 称号"无名者"、终极技能『我叫无人』。
- **伊雯**：伊隆城的公主，能预言，却从没有人信她。她说城会破，城就破了。
  - → 第二章终极技能『伊雯的预言』。
- **塔隆**：联军里最勇猛的人，争功失败后被女神惑乱，把一圈羊当成仇人，砍了一夜。天亮后他羞愧自尽。悲剧诗人**埃斯坦**把这件事写成悲剧《塔隆之狂》。
  - → 第二章技能『塔隆之狂』。
- **追猎兄弟利恩与利安**：一对孪生猎人，一个会死，一个不会。哥哥死后，弟弟求神让他分出一半不死，兄弟俩一起化作天上的"追猎双星"。
  - → 技能『双星追猎』。

**古典盛期**（约灯纪前 600—前 420 年）
- **雅隆城的剧场**：悲剧和喜剧在这里成形。
  - 演员戴面具上台，十几个人的**歌队**由**歌队长**领唱 → 阶位 4"歌队长"。
  - 舞台两侧立着三棱的**换景柱**，转一面就换一处场景 → 阶位 5"换景师"。
  - 戏到绝处，机关把扮神的演员吊上舞台，一句话改掉结局，世人叫它**"机关神"** → 阶位 2"降神者"。
- **哲人塞隆**作《论剧》，是后世一切戏剧规矩的源头。
  - **突转**：形势在一瞬间翻过来 → 技能『突转』。
  - 他主张一部戏只写一件事、一天之内、一个地方，后人叫它**"塞隆三一律"** → 阶位 3"立律人"。
- **辩士梅格**：在雅隆广场上教人"先顺着对方说下去，说到荒谬为止"，这就是**归谬法** → 技能『归谬法』。
- **叙兰城的学者欧米隆**（约灯纪前 430 年）：大希舰队围攻叙兰，他让城头的士兵举起磨亮的铜镜，把阳光聚到船帆上，烧了大希人的半支舰队。叙兰最后还是陷落了，欧米隆死在自己的沙盘前 → 技能『燃镜』。

### 3. 大希治世：大希帝国（灯纪前 420 年—元年）

大希原是晨星海西岸的一座农人之城，后来一路吞并了城邦、海岛和北方的部落，成了世上唯一的帝国。都城是**永城阿尔塔维亚**。这四百多年后人称作"大希治世"。

- **公民名册与监察官**：帝国每五年重造一次公民名册。监察官可以在某人名字旁边加一个记号，从此这个名字就带着污点：不能做官，不能作证 → 技能『污名记』。
  - 这也是雾港"港册"制度的远祖。第一章的认领、补位、归属，都是这套名册几百年后的样子。
- **大希剧场**：大希人照搬了城邦的戏，只把面具做得更精细。大希语里，"面具"这个词后来也拿来指"人" → 阶位 8"假面人"、遗落物"无主假面"。
  - **喜剧作家梅洛**开创了**错认喜剧**：孪生兄弟、主仆互换、认错人，一笑到底。代表作是《孪生的卢修》 → 技能『错认喜剧』。
  - **诗人维雷**写《诗艺书简》，说一部戏应当正好五幕 → 连招"第五幕"。
- **大希人的书信**：签完名以后，还要在底下补几句真心话，叫**附言**。大希有句俗话："正文写给体面，附言写给人。" → 技能『附言』。
- **拖延者瓦勒**（约灯纪前 210 年）：沙海的骑王带着象兵翻山打进大希腹地，连胜三场。老将军瓦勒不与他决战，只是跟着、拖着、烧掉他前面的粮。元老院骂他胆小，叫他"拖延者"。三年后骑王的军队饿垮了 → 第二章技能『拖延者之计』。
- **帝国的结束：大雾之年**。灯纪前七年，一场遮天的大雾从海上漫进陆地，七年不散。道路断绝，行省各自为政，等雾散时，帝国已经不在了，世上多了九个各自立国的地方，就是后来的九邦。

### 4. 长夜（灯纪元年—380 年）

大雾散后的四百年，寒冷、饥荒、灰热病一场接一场。

- **守灯会**就生在这时候：
  - 传说一个不知名的女人在长夜里挨家挨户点灯，替快死的人守夜，替孩子记下父母的名字。后来跟着她提灯的人越来越多。
  - 灯纪元年，她们在雾岬点起第一盏长明灯，世人从那一年起纪年。
  - 那时候男人多半死在路上或战场上，提灯的、记名的、守夜的，多是女人。所以守灯会从一开始就让女人当祭司。
  - 守灯会的教义第一条是："灯不问提灯的是谁。"
  - 他们供奉的是**黑夜女神**："夜不是灯的敌人，夜是让灯看得见的地方。"
- **观镜会**和**缄卷会**也在长夜里出现：
  - 观镜会相信镜子照出真相，做的是验证、裁定、见证；
  - 缄卷会保管封存的书，守着"不该被读的东西"。
  - 三会合称"三教会"，彼此合作，也彼此提防。

### 5. 九邦时代（灯纪 380 年—980 年）

- **九邦定形**：雾岬自由联邦、盐镜、铜冠、翡翠群岛、灰烬边疆、眠海、风碑、星桥、黎明环，各有领主、法典和怪事：
  - 盐镜的倒影会替人活下去；
  - 风碑的石碑夜里自己改字；
  - 灰烬边疆有一场仗每天清晨重打一遍。
  - 世人当它们是各地的"诅咒"。
- **行会兴起**，城里的手艺、买卖、学徒都归行会管。行会的规矩是：一门手艺父传子，女人不得入行。这就是后来"保守派"的根。
- **风碑的警告**：学者发现，抄自风碑的史书，十年后再抄一遍，常常对不上。从此有句话："风碑上的事，信一半。"
- **归一议会**的名字第一次出现在缄卷会的封存档里（约灯纪 700 年），只有一行："有一群人，愿意交出自己的名字。"

### 6. 繁花时代（灯纪 980 年—1120 年）

铜冠和翡翠一带的商城富了起来，学者从修院地窖里翻出城邦和大希的旧书，抄、译、印。后人说，那一百多年像是旧书里的花一起开了，所以叫它"繁花时代"。

- **百花之城菲奥拉**是繁花时代的中心，画家、剑客、乐师、剧团都往那里去。
- **剑术**：菲奥拉的剑术大师卡洛维写出第一部剑术书《左手之书》。
  - **侧身刺**：侧步让开对手的剑，顺势刺进他没防着的那一侧 → 技能『侧身刺』。
  - **佯刺**：先做出要刺的样子，引对手去挡，再刺别处 → 第二章技能『佯刺』。
- **绘画**：菲奥拉画家行会的说法，在画错的地方重新画过，叫**重绘**。几百年后颜料变薄，底下那一笔会重新透出来 → 技能『重绘』。
- **音乐**：菲奥拉的乐谱上，标着"急板"的地方，演奏的人要尽可能快 → 技能『急板』。
- **剧场复兴**：
  - 剧团在台口装了一只小箱子，**提词人**藏在里面，台上谁什么时候开口，由他说了算 → 阶位 7"提词人"。
  - 剧作家**洛伦**写《人世大舞台》：作者给世上每个人分派角色，国王、乞丐、美人、农夫，演完了都要回到作者面前交还面具 → 阶位 1"执幕人"。
- **秘仪牌**：菲奥拉的印刷匠刻出一副二十二张的大牌，后来成了占卜和赌博都用的牌。第一张是**街头戏法师**：一个摆张桌子变戏法的人，代表旅程的开始 → 阶位 9"街头戏法师"。
  - 游戏副标题"原创塔罗战斗 RPG"里的"牌"，在世界里就是秘仪牌。
- **同貌者传说**：一位旅行家在风碑记下当地的说法：在雾里遇见另一个和你一模一样的人，三天之内，你们两个只能留下一个 → 阶位 6"二重身"。
- **十阶说**：繁花时代的学者在旧书里找到一套"十阶"的说法，从最低的"王国"到最高的"王冠"，说凡人的灵魂可以一阶一阶往上走。三教会后来都用它来讲超凡者的阶位 → 游戏里的"阶位 9 → 0"。

### 7. 蒸汽时代（灯纪 1120 年至今）

- **灯纪 1140 年前后**：铜冠的匠人造出第一台能日夜转的蒸汽机。工坊、货船、抽水泵一下子多了起来，烟也多了起来。
- **灯纪 1150 年代**：老铜枝设计出第一台"奇迹压机"，起初是为了救矿难里烧伤的人。不久，铜冠就开始收买别人的悲伤，压成一件件小奇迹出售（第二章）。
- **进步与保守之争**：
  - **进步派**要机器、工厂、银行、奇迹，愿意让女人进工厂、学画图；可他们不管烟，也不问奇迹的原料从哪里来。
  - **保守派**守着行会和旧家族，要关厂、要治烟、要留住老手艺；也要把女人挡在行会门外，把穷人留在原地。
  - **守灯会**两边都不站：它要治烟，要男女同工同权，要停掉卖悲伤的买卖，也想由教会来定规矩。
  - 雾港的雾本来就重，这几十年又添了煤烟。雾港人说："以前的雾是白的。"
- **灯纪 1183 年冬**：雾港码头东仓一盏油灯打翻，烧了一夜，三十一个人没了住处。
- **灯纪 1186 年**：游戏开始。

## 四、真相（只给写作的人；按章揭开）

1. **承架文明**（第二章第 20 关）：
   - 在所有循环之前，有一个文明为凡人造了一副"承重架"，让人能一阶一阶扛起权柄而不被压垮，这就是"十阶"。
   - 繁花时代的学者找到的十阶说，是这副架子的说明书残页。
   - 铜冠的奇迹压机，是在照着地基里的古代结构仿造。
2. **循环与重置**（第三章）：
   - 世界经历过很多次"有人升神，然后一切重来"。
   - 灰烬边疆那场每天重打的仗，是上一次重置没有烧干净的一角。
   - 传说时代的"巨人"和"大火"，是上一轮的碎片。
3. **风碑删史**（第四章）：
   - 神座一直在删改对自己不利的历史，风碑就是它的刀。公开历史里每一处"信一半"，都是被删过的地方。
   - **无冕议长**是上一轮唯一活下来的人。他的妻子和女儿存在于一段被删掉的历史里，世上没有人记得她们。九邦时代他建立了归一议会。
4. **旧神与黑夜女神**（第四章）：
   - 旧神更像是封印的容器，不是天生的统治者。
   - 黑夜女神就是长夜里那个挨家点灯的女人：她把帷幕之径的权柄用到了顶，成了上一个"无名者"。后来她扛不住权柄对人格的侵蚀，把自己拆小，只留阶位 9 的一点力量，起名玛拉，在雾港守钟。
   - 守灯会不知道，他们供奉的女神就住在城里，签错过一张回执。
5. **大雾之年**（第五章）：
   - 那七年大雾，是九座界锚落下、把一个完整的世界隔成九种现实时扬起来的。大希帝国是最后一个完整的世界。
   - 雾港的雾，一部分是那时留下的。
6. **主角**（第二章起）：
   - 归一议会早就在你身上做了记号：你是帷幕之径的继承者，要长到阶位 0 再"交付"。
   - 妹妹诺娅用关于你的全部记忆付了账，换议会暂缓追索。
   - 你第一次用帷幕，藏得太深，丢了过去，只记得她最后叫你的那一声名字。

## 五、写出处的规矩

- 出处一律写成"谁、在哪部书或哪件事里、说了或做了什么"，不加现实世界的人名、地名和外文原词。
- 世界里的书名，引用时用《》。
- 同一个人物或典故在不同地方出现，说法要一致。新增典故先补进这份总稿，再写进游戏。
- 公开历史可以有错，但错要有来由：风碑的删改、教会的立场，或者学者的偏见。

## 六、已定（10-18）

用户："3可以，12 名字再好听点？"，看完新名字后说"好，按你定的"。

- **纪年**：初灯纪元，简称"灯纪"。当下是灯纪 1186 年。
- **地名**：大希帝国的都城是永城阿尔塔维亚；繁花时代的中心是百花之城菲奥拉；城邦围着的那片海叫晨星海。
- **时代**：传说时代、百城时代、大希治世、长夜、九邦时代、繁花时代、蒸汽时代。
- **大雾之年**是界锚分隔世界时扬起的雾，雾港的雾有一部分来自那时。
- **去掉的中式说法**：
  - 剑谱 → 剑术书；
  - 《归航记》 → 《归航之歌》；
  - 吊神 → 机关神；
  - 技能『悔笔』 → 『重绘』，『我名无人』 → 『我叫无人』。
