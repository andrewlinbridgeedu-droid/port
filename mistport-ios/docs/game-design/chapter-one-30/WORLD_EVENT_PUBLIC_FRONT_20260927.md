# 阵营世界事件：人人推进、强者突破

**当前体验入口：[《谁让雾港重新亮灯》](WORLD_EVENT_LIGHTS_CASE_20260927.md)。** 本页保留参与计分及战斗研究。新案让无人攻下核心时仍可按工程资格和公共成果授予合同，因此旧概率中的“无人死亡”不代表“没有经营结果”；新合同映射尚未迁入原型或重算。下一步先接内容与一条真实订单/行动闭环。

## 已确定的用户方向

2026-09-27用户明确选择：**70:30且装备、操作、准备相近时，人多且组织好的阵营明显占优；少数派靠更好的准备和操作翻盘。**

据此不采用按人数平均胜率作为主计分，也不把两边胜算强行调到50:50。新人加入后失败不扣团队已有进度，成功应有真实帮助。资金不能直接购买贡献、攻击倍率或核心选人权重。

本页是参与计分与战斗研究记录。下面的1/2贡献、每人一次、6/4核心机会是**本地新增首测候选**，不是用户已批准的正式数值，也不是Pro已经复核的新结论。

## 玩法分为公共战线和最终突破

“战役”统一对玩家称“阵营世界事件”：新闻预热 → 准备与投资 → 人人可参加的公共战线 → 关键人物最终突破 → 世界结果/产业承接。仍用单人实时战斗与异步回执，不做真人互杀或多人同屏。

### 公共战线：每个人的行动影响局势

- 合格报名者都可以参加，不抽签排除大多数玩家。
- 每账号本事件暂定一次产生公共世界贡献的尝试；普通目标成功1点，高难节点成功2点，失败0点。普通失败不扣分，不向个人追加欠款。
- 两条难度必须是真实不同遭遇。强者选择高难承担更高失败风险；普通玩家选择普通也能帮助阵营。不能把同一场战斗换标签领双倍点数。
- 个人唯一尝试、目标类型和遭遇版本在开始时冻结；失败、撤退和正常超时占用本次尝试，不能失败后无限重抽。额外演练与正式世界贡献分开，不伪造药品消费。
- 普通/高难单位都是事件实例身份。复用战斗机制或模型不等于再次击杀旧主线NPC，也不重发原关首通、铜币、功勋或遗落物权益。
- 到截止统一比较总贡献，不以最早上线或最早达标直接发经营权。实时新闻可报告节点和累计进度，但不能提前宣布结局。

每人最多2点，使一人不能用无限刷分包办大服结果。至少4个不同成功账号的最低推进要求仍为候选；这是账号规则，不保证4个不同真人。高难应提供“判断、技能与配装更好就更有效”的路径，而不是只认昂贵稀有封印物。

### 最终突破：公共推进改变实际进攻机会

为让前面的贡献产生世界效果，本轮离线模型采用以下桥接：

|关窗后状态|候选核心机会|
|---|---|
|双方均满足工程物料与至少4名成功账号，A公共贡献领先|A最多6次、B最多4次|
|B领先|A最多4次、B最多6次|
|双方有效同分|5/5|
|仅一方满足物料/成功账号条件|合格方最多6，另一方0|
|双方都不满足|0/0，不伪造突破|

机会还受真实合格人数限制；只有4个成功候选就最多4次，不凭空变出6名挑战者。公共战线与最终突破各有独立的一次世界尝试记录，不能把前一阶段已参战当成永远禁止参与下一阶段。

之后运行[四层突破候选](WORLD_CAMPAIGN_CORE_RACE_SPEC_20260927.md)：同一账号最多贡献一次核心结果，双方每轮一起结算，累计四个不同账号成功才改变关键人物状态。公共积分本身不杀NPC、不产生财产或经营权。普通突破是防护节点被击破，最终人物只死亡一次，不演出同一人死四遍。

最后一击可由少数人完成，但之前所有人的普通/高难行动会改变机会分配。这个方案仍需要验证未获得最终名额的人是否满意，不能只用“数学上有影响”代替参与感。

## 投资、工艺与新闻怎样进入

投资资金转入阵营项目，项目按有限预算购买真实工程物资；物资用于已定义的开路/准备动作。需要数量及配方仍待游戏接入，本轮算式假定双方物料齐备，不是已实现真实供货。

中立工匠可卖给双方，不因不选政治阵营失去工艺玩法。战斗玩家自行决定是否购药和装备，高难节点创造的是潜在容错需求，不是策划自动给所有人扣三瓶药。月卡或投资金额不改变贡献倍率和抽选权重。

新闻至少覆盖：双方公开目标、物资需求、准备事实、公共目标开放、节点推进、关窗后的进攻机会、最终人物结果、经营/继任。普通玩家完成行动、工匠完成交货都应在各自贡献记录中有可核对的事实。计分变化驱动新闻，新闻不暗改数字。

### 一个能说明方向的例子

100人，70人阵营A、30人阵营B，公共战线都到场：

- 相同实力都打普通、胜率50%：A在公共战线领先约99.996%，人数优势明确。
- A普通胜率50%，B是更强的一批玩家、打高难胜率65%：A期望35点，B期望39点，B公共领先约70.14%。
- 最终核心胜率另外固定为双方50%，物料齐备、获得席位者全到场：前一种情况下A独占32.23%、B独占5.86%；后一种情况下A独占12.94%、B独占24.85%。其余为无人死亡或双死，不能漏掉。

这说明在假设下能够同时保留人数优势和精锐翻盘路径；**65%是强玩家面对高难的假设，不是相同玩家打高难会更容易**。当前没有测到这些真人概率，不能据此直接冻结Boss数值。

## 尚未解决的验收项

1. **无人死亡偏多。** 最终核心p=.5时多数情景约61%没有NPC死亡；20人冷场更高。如果几周才开一次，可能缺少结果感。不能自动送胜利来掩盖，须设计可见的阶段成果和失败承接，同时测事件频率。阶段成果也不能凭空生成免费产能。
2. **一次失败是否过于惩罚。** 当前一次世界尝试是有限贡献原型，不能当最终用户体验定案。后续比较1/2/3次、个人贡献封顶和失败后的替代行动，保持上限公开，不鼓励无限刷药。
3. **高难是否垄断选择。** 同一玩家的普通pN与高难pH应实测；单次期望贡献pN与2pH只是参考，还需时间/成本。如果对所有人高难都更简单且更划算，普通路线失效；反之高难也可能无人选择。
4. **核心出席与抽选。** 6/4上限不代表一定有人到场。预约、资格锁定、替补、网络故障与合法上传截止按上一轮缺口另验；选择高手带来的条件胜率变化不能假装与随机人群相同。
5. **真人难度尚缺。** 两个新Boss已按v2方向实现隔离原型，新增机制边界测试和288场实际内核策略试跑；不等于旧72项清单全部执行，也不等于真人配对试玩。当前世界回执/概率中的success仍是受信任假设输入，尚未连接新战斗结果。
6. **真实经济尚缺。** 没有观察到药品购买率、高阶封印物愿付价、项目营业收入和动态成交价；这套比较不解决Q30持续发行问题，也不授权增加维修或删旧奖励。

## 下一步工程顺序

两种目标与新Boss的隔离试玩已建立；下一步先做真人配对试玩和路线调整，同时用最小新闻/结果页验证普通贡献能否被玩家理解。公共进度账迁入Swift时复用回执测试，最终共享服仍需要独立权威资产与世界账。时间线、事件NPC和产业收入未完成前正式入口关闭。
