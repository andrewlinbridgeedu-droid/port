# 雾港技能与遗落物配合重设计

2026年10月2日。研究提案，待评审；未修改游戏规则、奖励、存档或美术，未进行战斗模拟或真机验收。

本稿依据佛堂与剑堂两份参考报告、其战斗截图、用户提供的雾港三套外观法术拼图，以及当前工作目录中的 Swift 源码。建议把技能做成有分工的连招，把遗落物做成会改变连招用法的异常物件：**技能决定怎样制造和利用破绽，遗落物决定为了这种打法要接受什么限制。**

第一章保留四张普通牌、独立终极、一个普通主动遗落物、一个普通被动遗落物及独立通缉栏。重点形成蓄势兑现、借命抢攻、拒收反夺和封招守势等打法。借鉴剑堂的连续加速另做后续样板，以明确的停顿代价限制反馈。

本文扩展而不覆盖[此前三件衔接提案](SKILL_RELIC_INTERPLAY_PROPOSAL_20261002.md)。旧稿保留作为原始资料；本文的新技能数值、物件联动和通缉物件代价均为候选，不表示用户已批准实施。

## 一 这次应当重新设计什么

最值得改的不是给每件遗落物再添一条增伤，而是以下关系。

1. **同一份错位要有两种值得选择的用法。**双影先取一份、荒谬收尾，适合有时间完成连续攻击；荒谬一次收尽两份，适合短破绽或抢在重击前结束战斗。
2. **基础技能离开指定遗落物仍能成立。**遗落物改变条件、时机和对象，不把一张本来无效的牌修成必带牌。
3. **代价进入玩家正在做的事。**赶着杀人却要等迟签；急着输出却与目标互相拒伤；需要防守却得先给敌人送血；需要治疗却刚截走别人的治疗。
4. **利用代价是一项操作成果。**把回礼盾夺回来可以成立，但需要占用反客为主、找到实际受赠敌人，并放弃这张牌原本可能处理的另一个增益。不能仅因装备两件物品就自动免除所有代价。
5. **保留不围绕误认的打法。**盐囊、铜锚、镇纸、断线针分别经营毒伤、连续攻击、卡槽和治疗，不统一改成“触发后误认加一”。

第一章不新增通用的疯狂值、污染条或第三种连招资源。每件物品有自己的异常规律，玩家学习的是物件的脾气。

## 二 从参考游戏吸收的结构

| 参考观察 | 对雾港有用的部分 | 雾港的取舍 |
| --- | --- | --- |
| 佛堂先施加灼烧，再利用层数，最后引爆 | 状态来源、条件利用、消耗结算应由不同技能承担 | 使用现有误认与错位，不把灼烧、佛炎、金焰搬成三套新状态 |
| 佛堂的输出准备同时支持减益和生存 | 配合不必全部表现为伤害条变长 | 名片拒收、银扣反夺、镇纸封招都可成为配合的一部分 |
| 剑堂由施放推动攻速、冷却和追加攻击 | 技能可以改变后续节奏 | 后续仅试一次有限重演，并明确推迟下一招；不加入无上限概率刷新 |
| 六槽加类别羁绊形成组合门槛 | 编排界面应说明哪些关系成立 | 第一章四槽更紧，不再强加两件、四件同系数量门槛 |
| 高阶四张占据主要输出，辅助槽很有限 | 新技能应有明显价值，但不能只比较自身伤害占比 | 错步的短冷却、反客的驱散和伪证的铺垫保留独立用途，不用数倍倍率淘汰它们 |
| 莲、塔、龙、剑群等有可识别主体 | 同一套状态系统也能拥有不同的招式形象 | 延续鞋印、封蜡、名牌、双影、幕布、椅子等已确定方向 |

以上是从[佛堂分析](../../../../docs/reference-analysis/fotang-spells-20261002/佛光与佛堂法术体系设计分析.md)和[融合报告](../../../../docs/reference-analysis/fotang-spells-20261002/佛堂与剑堂融合设计报告.md)作出的设计取舍。参考游戏的“必须四加二”“保留四金焰”等内容是当时配置研究的约束，不是本项目的要求。报告中未核实的技能效果也不作为雾港数值依据。

已经查看佛堂和剑堂的实战拼图。佛堂的莲、塔、龙和紫金火柱确有不同轮廓；剑堂流光候选帧仍缺招式名，龙吟仍缺图。静帧不能证明完整起手和回收节奏，也不能证明跨楼层最优组合。

## 三 如何借鉴诡秘之主的负面效果

可以参考的是物品独有的使用规律和代价，不必照抄物品名称、具体能力或残酷行为。

公开可读的《诡秘之主》第345章中，太阳胸针在接触时就使持有者感到强烈炎热。这提供了一种有用的表现思路：物件的力量与不适共享同一身份，代价不是藏在装备面板末尾的百分比。[原作英文授权连载节选](https://www.webnovel.com/book/11022733006234505/37223783437748861)

“蠕动的饥饿”的读者百科摘要记录了供养要求、反噬，以及封印前后条件变化。本轮只取得搜索摘要，正文抓取受限，故仅把“使用后需要履约、不能免费占有力量”作为二手参考，不据此复述各版本的精确契约。[读者百科条目](https://lordofthemysteries.fandom.com/zh/wiki/%E8%A0%95%E5%8A%A8%E7%9A%84%E9%A5%A5%E9%A5%BF?variant=zh-sg)

下面是雾港自己的设计原则，不是原著规则：

| 代价类型 | 玩家会遇到的决定 | 对应物件 |
| --- | --- | --- |
| 借来的东西必须交还 | 现在借命，还是等重击之后再借 | 僭命勋章 |
| 规则对双方都生效 | 拒收敌人攻击时，自己也会打空 | 空栏名片 |
| 必须先付出才能得到保护 | 先给敌人盾或生命，再设法利用 | 返礼银扣、反照墨镜 |
| 拿走一种能力交换另一种能力 | 封掉一张牌，换一次承伤 | 缄卷镇纸 |
| 使用留下本场痕迹 | 毒收得越多，正常生命上限越少 | 盐封呼吸囊 |
| 抢来的东西会切断原有来源 | 截走治疗后，自己也暂时不能再恢复 | 归属断线针 |
| 提前取得未来的力量 | 多演一击之后，下一张牌必须晚到 | 后续候选折返路签 |

一件物品的说明应回答六件事：什么时候生效、得到什么、失去什么、如何预告、什么时候结清、怎样减轻风险。冷却、耐久和使用次数控制频率，不能单独充当异常代价。假面永久十裂纹是既定特殊契约，继续保留，不额外追加新的惩罚。

允许玩家通过技能和判断减轻风险。能处理代价才有研究价值；不要求每件物品用完都净亏。但不能用普通净化抹掉勋章交命、盐囊封上限、断线针封疗或假面裂纹，也不把离线时间变成喂养倒计时。

另外，绯月寿账签目前直接增加生命，没有走检查断线针封疗的统一治疗入口。因此“断线针也会挡住寿账签恢复”只能作为本稿统一治疗语义的候选，不能写成当前已生效；实施时须单独复算Q30。

## 五 技能分工和建议调整

### 第一章六张普通牌

基础倍率和冷却来自本轮源码。下表的“建议”列才是新的设计，所有新数值均为首轮候选。

| 技能 | 当前核心用途 | 新设计建议 | 让位给它意味着什么 |
| --- | --- | --- | --- |
| 错步穿行，4秒 | 110%；目标有误认或错位时自身倍率提高25%；可打第二目标 | 保留为短冷却的条件利用牌，不吃掉误认和错位；已有归结准备关系要显示清楚 | 适合持续输出和多目标，但不能代替荒谬的短窗爆发 |
| 伪证烙印，6秒 | 70%；误认加一，后续两个伤害技能获得强化 | 保留为稳定的专用铺垫牌；强化明确显示在对应目标上，多段一招只耗一次 | 占一个输出较低的槽，换后续两招收益；换目标可能吃不到准备 |
| 身份错置，8秒 | 80%；四层转换，不足则补一层；转换时延迟下一次起手 | 保留通常四层门槛；勋章有效时候选三层。成功转换清空误认，错位最多两道 | 需要准备；提前乱用可能只补一层，错过这轮转换 |
| 双影追猎，6秒 | 两段各65%；有错位时第二段97.5%，消耗一道 | 保留分段兑现，第二段强化成功才向玩家显示“取用一道” | 用掉一道后，荒谬不能再取得下述两道同收奖励 |
| 荒谬归结，12秒 | 基础150%；有错位再加80%，清空错位；另读归结准备 | 一道错位仍为230%；两道同时收尽候选260%。穿甲建议统一为仅有错位时30% | 一次收尽最快，但下一张双影失去强化，须重新准备 |
| 反客为主，10秒 | 驱散防御增益成功得一道错位；否则误认加二，无直接伤害 | 增加识别本人银扣产生的回礼盾，并只转移其剩余量；普通驱散仍保留 | 占用一张牌换目标控制与反制；无法同时处理两名敌人的问题 |

伪证的两次强化当前保存在各敌人的组合状态内。建议玩家文案明确为“对这名敌人的后续两次伤害技能”，再次盖印刷新为两次，不累加。若后续决定改为主角全局强化，必须作为独立改动，不能只改文案。

双影消耗、被拒收的技能是否仍消耗准备、同一技能部分命中等细节必须统一在规则层。首版建议继续采用“出招时读取并承诺消耗，拒伤不退款”的现有方向；画面可以分两段，不能在动画第二段再扣一次。上表“强化成功”指规则承诺的强化分支，不承诺敌人一定实际掉血。

### 两种兑现方式的算例

只比较基础系数，令目标已有两道错位，暂不计防御、误认易伤、伪证、归结准备、勋章、装备、溢出击杀和动作时间：

| 顺序 | 系数之和 | 特点 |
| --- | --- | --- |
| 双影强化，再荒谬收一道 | 65%＋97.5%＋230%＝392.5% | 两次出招才完成，首招为两段 |
| 荒谬收两道，再普通双影 | 260%＋65%＋65%＝390% | 第一招就得到260%，后续双影没有强化 |

新增的两道奖励暂取30个百分点，是为了让两个顺序的名义总量接近，同时把伤害到达时间拉开。它不是已验证平衡值。真实防御与两种荒谬分支的穿甲、出招时点、护盾和校准计数都可能改变排序，必须复跑。先荒谬可能抢到短破绽，先双影可能适合持续窗口，不再把一种顺序写成永久标准答案。

### 终极和后续辅助

无名宣告继续每场一次，为全场制造准备；不直接清空所有敌人的错位，不复制通缉机制效果。两层转换说明与执行分歧先确认，未确认前的样板按实际四层实现作基线。若采用两层权益，则终极两层、勋章三层、通常四层取最低，不相减叠到零。

后手改写保留“处理敌人施加的一项持续伤害，下一张铺垫多一层”的独立功能。它可以减少盐囊以后需要收容的毒量，但不能吐回已经封存的上限；也不能擦掉断线针封疗。取得它以后才开放相关搭配说明，不提前改发放节点。

## 六 十件普通遗落物各自改变什么

本节沿用当前序列9契约的主要收益与代价。H0指本场入场正常生命上限，不含临时借命增幅。表中的联动分为“现有机制可产生的策略”和“新增候选”，前者也不等于已完成真人验证。

| 物件与异常规律 | 收益和必须付出的代价 | 适配技能与具体选择 | 误用情形 |
| --- | --- | --- | --- |
| 假面谕令遗落物，沿用无主假面的叙事身份：“它替你被认领，也会记住你一次” | 4秒内最多承接两次直击；每次发动永久一道裂纹，十次用尽，教学豁免照旧；不挡持续伤害 | 现有策略：保护荒谬或转换前的一段危险时间；不新增免费误认，也不要求每场使用 | 面对毒伤开面具，或在敌人不出手时开；裂纹仍付出 |
| 僭命勋章：“借来的身份要拿余命偿还” | 8秒当前和上限×1.5、攻击×1.3；结束余命减半并恢复正常上限；24秒冷却 | 新增候选：有效时身份错置三层即可转换；用在三层已备好、身份将出手时 | 两层就发动、转换没轮到、八秒后紧接重击；都照样交命 |
| 迟签印章：“它只认约好的第三秒” | 一笔技能直伤延后3秒，加成min(原伤40%, H0的15%)；一次仅一笔、12秒冷却；目标离场或届时真免伤可作废 | 新增候选：迟到伤害实际结算后，若原目标存活且仍有误认，加一层；每张票据一次 | 收割残血、即将换波或关闭破绽时使用；既失去即时伤害，也可能整笔落空 |
| 盐封呼吸囊：“它藏住毒，也挤走你的呼吸” | 收容60%毒跳，容量H0；每收10封存1正常上限，本场不返，战后解封不回血 | 现有策略：撑到转换或击杀；后手改写取得后可降低未来毒量 | 把它当直伤防具，或拖长战斗来攒所谓额外收益；本稿不奖励吃毒 |
| 反照墨镜：“镜中人必须先收一份好意” | 锁定2秒后将一次普攻改为给目标回血；随后4秒可折另一名敌人的一击，最高20%H0；先送的血不退，切目标取消等待 | 现有策略：给需要集中处理的目标送血，等另一敌人直击；错步可兼顾旁敌，但必须留住有效攻击来源 | 单敌、目标满血、提前杀掉攻击来源、开名片拒收掉本来要反折的一击 |
| 缄卷镇纸：“第三行必须永远留白” | 就绪时封掉固定第三槽本次技能，4秒一次收容最高35%H0；牌的全部效果失去，冷却照走，18秒物件冷却 | 现有策略：第三槽放双影时，决定接受一次少打双影，换生存；其他轮仍能正常出招 | 把必须本轮生效的身份或反客放第三槽；不返还整招，不补回被封的误认 |
| 逆潮铜锚：“没有后浪，也不退第一道伤口” | 同敌同动作首击额外承受5%H0，随后2秒下两段共收容35%H0；10秒冷却 | 现有策略：针对确定的多段攻击；让输出牌在防守期继续工作 | 对单段重击只多挨首击代价；身份延迟起手不等于安全吞掉已在途后两段 |
| 归属断线针：“夺来的治疗会割断自己的后路” | 截选中敌人的外来治疗，最多20%H0且不超自身缺血；每场两次、12秒冷却；之后6秒封疗 | 现有策略：等自身有缺血、敌方确有外来治疗再截；尽可能把其他恢复放在封疗结束后 | 满血时期待储存治疗；后手改写不能解封疗。若采用本稿统一治疗语义，也会与寿账签周期回血冲突，当前存在例外 |
| 空栏名片：“不收他的攻击，也不让他收你的” | 主动3秒与固定敌人互拒直伤；自己的牌照耗；其他敌人、持续伤害和控制照常；18秒冷却 | 新增候选：窗口实际拒到目标一次正值直伤，自然结束时给原目标两层误认 | 无攻击时开、把双影和荒谬送进拒收期、以为切目标会把名片转给新敌人 |
| 返礼银扣：“每次拒绝一击，都欠来者一份礼” | 收容下一次合资格直击，最多30%H0；攻击者得收容量一半的普通盾；8秒且回礼盾清掉才再就绪 | 新增候选：反客可夺本人赠出的剩余盾并得一道错位；原盾移除，主角得到等量普通盾 | 盾已被打光才反客、找错受赠敌人、刚还清就以为物件无冷却 |

这十件不应按品质排成从弱到强的替换链。低价盐囊在毒战仍有用途；昂贵墨镜在单敌局反而可能无效。升级如果只是把异常代价越来越小，最后十件都会退化成无条件增益。

## 七 四项新增联动的精确条件

### 勋章与身份错置

通常在施放前检查四层；勋章有效期间检查三层。转换后误认清零，错位设为两道，不叠到三道、四道，不增加额外延迟，也不返还多余误认。

建议示例为：伪证给一层，反客在目标没有可驱散防御增益时再给两层，合计三层。此时若身份即将出手，发动勋章使本次转换成立，再把荒谬送给这个目标。这里牺牲了双影槽位，换取反客的快速准备和反制能力。若反客实际驱散成功，它走的是一道错位分支，应改用兑现判断，不能仍假装得到两层误认。

### 名片与误认

只记来自绑定敌人、原本应造成正值直接伤害、实际被名片拒收的命中。闪避、原本零伤、真免疫、毒跳和第三方均不成立。多段也只记一次。

自然到期，双方和战斗仍有效时，给原敌人加两层，封顶四层。不提前在第一击时发放，不因目标离场转给别人，不因胜利或撤退补发。自己的伤害技能仍会在拒收期消耗其准备条件；没有储存后返还伤害的功能。

### 银扣与反客

反客在所选敌人身上查找本次战斗、由本人银扣生成且仍有余额的回礼盾。存在则优先夺回：扣除该盾余额，向主角转移等量普通盾，施加一道错位。错位已有两道时不降低为一道，封顶仍为两道；此处是新联动分支的建议，不默默改写其他分支。

不复制敌人的其他盾，不返回初始金额，不变成治疗，不触发治疗反应。一次反客只走一个分支，不能又夺盾、又驱散另一增益、又加两层误认。银扣的八秒期限保留。

夺回允许减轻负面效果：代价体现为敌人曾经受到保护、反客占槽和出招机会被使用，而不是强制把夺回数额再扣回去。若实测无需注意时机也能持续免费得盾，才应调整回礼转移比例或联动频率。

### 迟签与误认

沿用当前一笔伤害的延后，不保留一笔即时伤害再复制一笔。只有迟到结算确实造成敌人生命或普通护盾减少，且该敌人结算后仍活着、当时至少一层误认，才补一层。击杀、真免伤、零伤和目标离场不补层，满层不溢出。迟到票据不生成新票据，也不触发重演链。

补层发生在伤害之后，不回头抬高这笔伤害。原本随技能施加的状态仍按原时点处理，不随票据再施加一次。

**与名片的冲突保留。**本轮源码先检查名片拒伤，再尝试生成迟签票据；因此在名片拒收期间向该目标出招，不会把被拒的伤害自动存起来。已经生成的票据若恰在拒收窗口结算，仍可能落空。必须在规则与界面中明确，不能把“迟签＋名片”宣传成天然无损输出。

## 八 配装应形成哪些不同打法

以下是合法槽数的候选配置，按“已经获得相应技能和物件”计算。购买、日限、借用资格和预算另行核验，表内阶段不保证玩家已经有铜币买齐。箭头只表示首轮编排意图，后续需看真实就绪提示。

| 打法 | 四张普通牌 | 主动与被动 | 什么时候有价值 | 放弃了什么 |
| --- | --- | --- | --- | --- |
| 蓄势兑现 | 伪证→身份→双影→荒谬 | 勋章＋迟签；已完成Q11并取得购买物后 | 稳定单目标、能活过几轮准备时 | 无反客，遇到关键防御增益处理差；不能保证首轮就凑够三层 |
| 借命抢攻 | 伪证→反客→身份→荒谬 | 勋章＋银扣；已完成Q12后 | 无可驱散增益时能一层加两层，借命提前转换 | 无双影；反客如果去夺回盾，就不再按原计划补两层 |
| 拒收反夺 | 伪证→身份→反客→荒谬 | 名片＋银扣；Q17开放且买到名片后 | 重击来源清楚、可切换目标、多敌压力不同步时 | 直伤会打空；没有双影，多段输出减少 |
| 封招守势 | 伪证→身份→双影→荒谬 | 勋章＋镇纸；Q18首通取得后 | 明确愿意牺牲第三槽的一次输出以承伤 | 每次封掉双影，整招伤害和相关效果都没有；不保证护层正好等到重击 |
| 转伤牵引 | 伪证→错步→反客→荒谬 | 名片＋墨镜；两件均已取得后 | 至少两敌、一名需要集中处理、另一名将直击时 | 缺身份的稳定转换；给敌人回血，且切目标或名片可能破坏反折 |
| 截疗抢杀 | 伪证→身份→双影→荒谬 | 勋章或名片择一＋断线针；Q26取得后 | 有外来治疗的敌阵 | 封疗期自己的恢复失效；主动物件必须按该场选择，不能两个同装 |

“转伤牵引”是刻意偏向反制的配置，反客没有增益可驱散时会缺稳定错位，应允许把荒谬换为身份，牺牲终结输出修复循环。界面要提示这件事，而不是把六套都标成同等推荐。

主动假面作为有限的救急选择保留。常规教学不能让玩家按推荐配置反复消耗不可恢复的裂纹，更不能用全新夹具证明真实存档还有足够次数。

独立通缉栏按墙关要求选择。普通遗落物连招不提供七号缺齿剑的墙关权限，也不替代伪造者倒签笔和规定塔层装备。

## 九 后续节奏路线只试一件物品

**折返路签候选：它让已经走过的一步再发生，也让还没走的一步迟到。**目录中同名物件目前没有第一章取得资格；本节是重新设计，不是新增掉落。

建议它作为普通被动，与银扣、迟签、盐囊等互斥。连续完成三种不同普通技能后，若其中有合资格伤害技能，重演这三招中最早一张合资格伤害技能的直接伤害，系数取60%，只打仍存活的原目标。选中目标后来变化不转寄。辅助技能须实际改变有效状态才算完成；伤害技能须造成生命或普通盾损失。被镇纸封掉、未完成或被拒收而没有有效结果的出招不计入三招。

重演不带误认、错位、控制、治疗、驱散、伪证次数或通缉计数，不复制终极、遗落物和另一次重演；按原招记录的各目标直伤额度计算，保留当时伤害构成，结算时仍检查当前免伤与普通护盾，不重新乘一遍勋章。

**代价候选：重演一旦生成，下一次普通自动施法最早开始时间向后推迟2逻辑秒。**这不是移动速度降低，也不影响手动遗落物、选敌或暂停。即使重演因原目标离场打空，迟到仍需承担。每10逻辑秒最多一次；一次触发后清空三招记录，锁定期间不预存下一次触发。

重演的最早伤害时刻不得早于触发它的第三招正式接触结算；新事件排在原事件之后，不能在同一事件内递归触发。战斗结束后不跨场追债，也不跨场保存三招进度；它的时间代价仅属当前战斗，和永久裂纹分开。

这条路线让玩家选择“现在多打一击，还是保住下一次及时转换”。首轮不再同时加入随机减冷却、全部技能加速、额外铺层与复制终极。是否值得在第一章开放，须先证明真实调度下不普遍优于十件现有物件，再单独决定取得节点。

## 十 通缉物件也要说明代价

当前三件墙关物件没有像十件普通遗落物那样清楚的异常代价，不能把“占一个独立栏”说成已经满足了异常设计。建议保留其必要的机制克制，再单独设计代价；不要在普通联动上线时悄悄削弱玩家已取得的墙关钥匙。

以下三项仅作下一轮对照候选，必须同时复算对应墙关，不与本稿四项普通联动一起默认实施。

| 物件 | 保留的克制职责 | 候选异常代价 |
| --- | --- | --- |
| 七号缺齿剑 | 打破强化和守势 | 每次实际触发破防后，下一次普攻只留下剑痕、不造成伤害；同一笔欠击只存一份，不能用一次零伤再触发新的破防 |
| 伪造者倒签笔 | 校准命中按两次、限制失败惩罚 | 一个校准窗口确实使用过额外计数后，记一笔待付代价：下一张普通牌实际施放后，其再次就绪时间额外推迟2秒；每窗口一次，未付时不叠加，不让减冷却抹除这笔追加 |
| 绯月寿账签 | 压住狂暴加伤、周期恢复 | 每次实际取得周期恢复后，4秒内其他治疗减半；不回扣本次治疗，不把没实际恢复的零值当触发 |

这些代价分别影响普通攻击、下一轮节奏、治疗安排，尽量让玩家通过配装判断应对。若使规定取得路径下的墙关无解，先调整代价和预算，不能靠要求多刷一天装备补洞。

其余七件仍为待开放条目。后续应围绕原定克制对象逐件设计，完整写出正常收益、异常代价和对应遭遇后才开放；本轮不把“克制某机制”的占位说明包装成七件完整成品。

## 十一 战斗画面必须解释规则

用户提供的拼图有三行外观和重复的技能编号列。同列主体大体一致，更适合作为同技能跨外观一致性的检查；没有证据把三行当作三套不同流派。

拼图里部分白亮区域和粉紫光量会吞掉材质与敌人轮廓，状态附近也有醒目的洋红色块。它提示可读性问题，但单图无法判定这些色块是调试元素、材质错误还是既有UI，更不能据此判定当前设备故障。后续制作应在同源录像里定位。

视觉沿用已经确定的舞台道具方向，把变化放在技能正在处理的物体上。保持大主体、有层次的材质、接触瞬间快速展开与明确回收，不用把所有特效缩小来解决遮挡。

| 动作 | 建议表现 | 玩家要读到的事实 |
| --- | --- | --- |
| 伪证铺垫 | 深红封蜡落印，留可辨认的破损印痕 | 这个敌人已被铺垫，后续强化还有几次 |
| 身份转换 | 帽子和旧名牌猛然换位，墨痕被带走，留下两重错影 | 误认被消耗，错位已建立；不是两种效果同时凭空增加 |
| 双影兑现 | 两道烟影分先后扑击，第二道沿目标错影咬合 | 这次第二段用了错位；不会看成两次独立技能 |
| 荒谬两道收尽 | 舞台道具落下，两个错影向同一落点折合，褶幕迅速收拢 | 两道一起清空，峰值强于只收一道；不再留下假状态 |
| 银扣反夺 | 敌人护层拆为不规则银丝和扣件，收回主角腕侧 | 转移的是剩余盾，不是治疗，也不是新造一份初始盾 |
| 名片拒收 | 双方之间的纸片擦去署名，实际拒到攻击才留两道待落墨痕 | 拒收已成立，但误认要等窗口结束才到账 |
| 勋章借命与交还 | 借命时旧铜身份章撑起外层影像；将到期时轮廓剥离 | 强盛是借来的，交命在临近；不要用一片白爆遮掉危险预告 |
| 镇纸封招 | 第三张卡的纸页被压住；主角身侧折页形成庇护后回收 | 本次这张牌没有发出，换来了一次承伤 |

不把直边框、规则光板、完整等距圆环或平行裸光条当主体。支援和盾不演成敌人受创爆炸。三套外观共享同一技能语义；更换服装不重命名机制或多发一段命中。

本次只完成视觉语义设计，没有制作或验收新特效。实际制作须使用当时有效的 `game-spell-impact` 和项目[命中华彩层规范](../../../../.claude/skills/mistport-spell-spectacle/SKILL.md)。本轮本机配置目录未找到通用 skill，因此不据旧归档替代执行制作流程。

## 十二 编排界面和战报

编排界面在四张牌和两件物品旁直接说明已成立的关系，例如“勋章期间三层可转换”“反客可夺银扣回礼”“第三槽将被镇纸封存”。未取得的技能不能算作已成立。第一章不再额外给这些关系叠一份羁绊伤害；界面说明实际规则即可。

战斗中分开显示三种信息：卡是否就绪、目标是否满足强化、下一张预计是哪张。尤其要显示“荒谬可收两道”“名片还在拒收”“回礼盾剩余可夺”。条件满足不代表此刻可点击施放，不能用按钮亮起误导玩家。

敌人状态用误认四格和错位两道表示，轮廓不同，不只依赖颜色。永久裂纹留在物件上；本场借命到期、封疗、回礼债务各在对应物件上显示，不增加一条所有物品共用的巨大负面条。

战报至少区分：

- 实际伤害按来源计，迟签分别标出原伤与物件追加；延迟原伤不能重复计作一份新伤害。
- 伪证、误认等支持带来的增量可另列贡献，但不再加进已经包含增量的伤害总计。
- 实际承伤减少、夺回盾、拒伤成功次数、转换次数和打空次数。
- 实际代价：交出的生命、送给敌人的生命或盾、被封技能、错失治疗、作废迟签。

避免把净化和反客的低伤害占比当作无用，也避免把延期后的一大笔伤害全当作印章新增收益。

## 十三 数值和代价的检查样例

这些是按规则手算的例子，用于检查设计语义，不是胜率或平衡验证。

| 情形 | 正确读法 |
| --- | --- |
| H0为1000，勋章发动前600血，期间完全不受伤不治疗 | 发动后900血，结束450血；相对发动前少150，不是从1500上限再扣750 |
| H0为1000，盐囊面对累计500毒伤，容量足够且舍入不影响 | 收300，仍受200，正常上限封30；原来600血会到400，未碰到970上限，不再额外扣30 |
| 银扣实际收容300 | 给攻击者150盾；敌人已消耗60后，反客只可夺90，不能夺150 |
| 印章接到原本200的一笔技能伤害，H0为1000 | 延后金额为200＋min(80,150)＝280；当下不另打200；若作废，连原200也没有 |
| 两层误认，名片成功拒收后自然结束 | 加两层到四层；还需要身份出招才转换，不自动获得错位 |
| 自己正在被断线针封疗 | 不把自动药耗掉后才告知无效；按既有合同阻止自动药消费，技能治疗则按规则无效且不返还技能 |

建议新增收益先放在条件和时机上，不全局提高基础倍率。唯一首批技能倍率候选为荒谬收尽两道时额外30个百分点；若实际偏强，先调这一增量，不抬高所有敌人生命掩盖选择失衡。

## 十四 实施与验证顺序

本节是建议顺序，不是本轮已执行的开发任务。

| 阶段 | 具体范围 | 必须回答的问题 |
| --- | --- | --- |
| 先统一契约 | 当前分支与实施分支对齐；核对错位余额、荒谬穿甲、终极阈值、技能取得、合法槽数 | 同一张牌的说明、核心、App和服务器是否是一回事 |
| 技能分歧样板 | 双影先兑现与荒谬两道同收，显示剩余余额和实际下一张 | 两种顺序是否分别有适用场景，手机上能否主动选择时机 |
| 普通物件联动 | 勋章、名片、银扣，随后单独加迟签 | 每件物品是否改变选择，真实代价是否仍会发生 |
| 完整配装对照 | 十件普通物件的适用和不适用敌阵 | 是否出现全场景必带、无条件免价或免费循环 |
| 后续扩展 | 折返路签及三件通缉代价分别立项验证 | 新节奏是否压倒其他打法，墙关是否仍按合法进度可解 |

关键规则检查包括：三层与四层边界；同一时刻先到期再新事件；错位封顶和剩余盾转移；名片真实拒收资格；迟签快照和作废；重演不递归；净化不删物件代价；暂停与×2不改变逻辑结果；战斗结束、换波、恢复和重复事件不重发收益或重扣代价。

用真实自动调度器复现例子，不用连续手动点名出牌代替正式操作。首轮按顺序可行只说明首轮，后续要观察最早就绪调度、目标切换和名片三秒窗口。在×2下三逻辑秒只有约1.5现实秒，若玩家看不清，应先改善预告与操作反馈，不让Unity单独延长规则时间。

平衡对照至少覆盖 Q8、Q12、Q18、Q22、Q26、Q30，并补毒伤、单段、多段、多敌、治疗和短破绽场景。分别记录合法取得状态、是否具备通缉克制与塔层装备、原版与新方案的战斗时长、最低生命、代价、打空和转换频率。

第一轮可沿用原提案的复审线：同装备完成时长缩短超过20%先分析来源；不满足墙关要求的组合被新增联动直接带过时暂停扩展。这个20%是检查触发线，不是已证明合理的强度目标。若一套在全部敌阵都胜出，应改组合条件和机会成本。

进度继续由 `MPCDailyPacing` 在开战前检查。物件研究不提前解锁天数，不添加可反复刷取的技能尘、通缉奖励或假面修复。新增权益、首通和购买均以既有账本为基础，已获物件不因本次提案被删除或重复赠送。

Swift确定状态、收益、代价与顺序，Unity只消费事件。后续若修改Unity运行资产，先核对设备导出新鲜度再构建宿主；真机测试夹具与玩家数据隔离，测试前后逐文件核对Preferences。工程通过、手机可操作和用户视觉认可分别记录。

## 十五 本轮研究结论与未验证部分

推荐保留雾港现有的误认和错位，使技能具备铺垫、转换、分段兑现、一次兑现与反制的分工；让十件普通遗落物分别改变时机、目标、卡槽或生存安排。首批研究的具体变化为荒谬两道收尽，以及勋章、名片、银扣、迟签四项有条件联动。更强的节奏反馈和通缉代价单独验证。

已完成本地报告与主要源码核对、两组参考实战拼图查看、原作公开节选及二手资料检索、候选条件和算例设计。未完成规则实现、战斗模拟、完整合法成长回放、当前手机状态核验或新视觉稿。因此本稿支持评审设计方向，不支持宣称新配装已平衡、可通关或已装机。
