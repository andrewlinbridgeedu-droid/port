# 雾港第一章：城市通缉调查玩法

状态：**第一版城图与调查流程已写入 iOS 工程，真机逐案游玩仍待验收**。本稿依据用户给的横幅港城原画，以及现有十案、五节点卷宗和战斗资源设计；原画中的建筑不能自动视为已有可走的场景。用户要求玩家在教会或酒馆接案、进城找人、必要时赢扑克牌、查明身份、战斗后返回交案，这一完整链条优先于旧稿中“不制作自由寻路城市”的限制。2026-09-25 的港城人物、道路与对话交互以 [《港城：满城漫游的街坊与通缉线索》](HARBOR_ROAMING_CITIZENS_20260925.md) 为准；下面涉及“只有主角走路／没有街坊”的旧句不再作为当前方案。

后续十案多路线、23 人对话与按玩家受理生成调查变体，以 [《港城人物与可变通缉调查》](HARBOR_CITY_BOUNTY_PRO_LUNA_20260925.md) 为制作规划；其中新机制仍未接入本页所述游戏版本。

## 玩家实际经历的循环

1. 主线达到案卷开放条件后，在教会告示板或酒馆柜台领取同一份委托。两处只是不同入口，共用案号、进度和一次性报酬。卷宗给出受害人、最后目击区与第一条可行动提示，不直接显示通缉犯位置。
2. 城图可拖动和缩放；街上不显示主角，23名街坊沿用户画出的铺装街道跨区随机漫游。点人物时镜头居中，白色头顶泡泡展开街谈；点房屋标记时镜头居中并直接进入可用室内。每案仍需实际访问地点、与不同人物交谈并核对物证，普通街谈不直接发证据。逐屋独有场景与十案分支对白须以实际制作状态逐项验收，不能从地图漫游完成推断已完成。
3. 目击与物证两条线可交换顺序。传闻会指出一个看似合理的嫌疑人；玩家收集独立时间线或工具痕迹后可以亲自排除。卷宗允许提前发现物件，但证据需要通过来源、时间、地点的交叉核验才升级为“可用证据”。排除支线不为凑齐“五格”而强制走；若玩家已掌握足够的独立证明，可直接推进到现场确认。
4. 个别知情者以一局扑克牌换消息。该人物出现的地点、赌局前说出的筹码与输赢后对话都服务于本案；不会每案都要求打牌。输牌只耗本局约定的小筹码或让对方暂离，玩家可稍后重赛，也可循另一条可靠线索继续，不得卡死主案或刷钱。
5. 比对完成后，卷宗才圈出可疑街区；玩家仍须移动到现场，检查至少两项身份特征或即时犯罪行为，再选择接近目标。仅凭“长得像”不能开战。战斗失败保留调查证据，重试从现场外开始。
6. 战胜后取得现场物证，卷宗状态为“待交案”。玩家回教会或酒馆向接案人陈述结果，完成交案对白后才一次性发铜币、功勋和对应装备。中途关闭或重启不会重复领奖。

## 这张城图如何使用

以用户横幅原画为底图制作**专用通缉城图**，不替换现有其他界面共用的 `MistportCityHub` 竖图。横图在手机竖屏上默认显示中央钟楼及相邻路网，左右沿海岸与街巷可拖到；“当前线索”只在玩家阅读过的区域给一个柔和方位提示，地图边缘有未入镜目标箭头。左侧旧街容纳酒馆、邮局、诊所、铁匠铺、照相馆和染坊；中央钟楼区容纳公告、档案、民事柜台、巡逻值房；上方花园与教会容纳受托与施济机构；右侧水路、桥和码头容纳渡运台、港务处、废船入口。废岗亭、浴场、纸窖等案件现场由可发现的门牌或码头入口进入，不在初始地图上画出“Boss”标识。西桥、港桥、花园桥、南桥形成两条可绕行的环路，避免十案都在钟楼广场来回折返。地图不把传闻画成精确红色敌人坐标，未识破目标也不显示血条或危险轮廓。

现行港城采用 2.5D：静态高分辨率城图、依据用户粗红线及西侧蓝色窄巷校正的街道路网、23名带角色身份与行走动画的街坊、可用建筑直接进入及头顶泡泡；港城界面不再画主角。通缉卷宗调查界面仍有独立的主角行动，使用同一校正路网，钟塔前改走可见环道，原画中被房屋遮住的巷段会遮挡角色，不让人物显示在屋顶或喷泉上。每个线索热点记录坐标、街区、室内场景 ID 和地图标签；手机实测后继续微调入口与触摸面积。

卷宗常驻一个可收起的“当前问题”条，写待验证的问题而非答案，例如“同一句求救声为何在两条街同时出现？”玩家可在卷宗切换已知调查方向。地图标记分为传闻区域、已知地点、到访未查完、已排除；普通街坊对话只是传闻，不能自动发卷宗证据。已知 NPC 再次点击可重读原话。长时间没有新发现时，玩家可主动请求三级提示：重述问题、标出有依据的建筑、标出建筑内可查看物；不会代替对话、自动给证据或跳过比对。已走过的路可使用城内马车/钟楼传送回**已发现的区入口**，不能传进未定位的犯罪现场。标准调查路线原则上跨大区不超过三次；重复拜访同一 NPC 必须有新的材料可出示。交案时允许点“返回教会/酒馆”走已知安全路，避免重复无意义跑图。

## 证据与扑克牌规则

现有 `witness`、`wound`、`exclude`、`compare`、`identity` 保持稳定 ID，避免旧存档失效；它们是现有五项案卷结论的兼容层，而不是五个可直接领取的 UI 按钮。新存档还要记录地点是否已知/到访、原始证词与来源、客观物证、玩家的推断与嫌疑人的状态。两个人转述同一本登记簿仍算一个来源；“某人戴红围巾”是真实证词，“因此他是犯人”只是待核验推断，后者被推翻时不能删除前者。`witness` 和 `wound` 可先后获得；`exclude` 可帮助澄清误导但不为凑数硬卡进度；`compare` 要玩家在相应人物/台面上选择真正匹配的一组物证；`identity` 要到现场观察并确认对应特征。玩家提前到后来地点时可以查看实际存在的物件，等取得其他线索后再回卷宗关联，不出现“未做到第三步所以眼前账册不能读”。错误比对只留下“已排除的猜测”，不抹除证据，不立即开启敌战。

进入缉捕的条件写成**身份特征匹配 + 独立来源的案件关联 + 现场确认 + 玩家主动出示通缉令**，由各案规则计算，不简单检查 `evidenceIDs.count == 5`。玩家需自己选择嫌疑人及两项支撑材料，系统只指出具体矛盾或同源问题，不自动替他选人。找到可疑地点不等于身份核验；已经核验也不自动开始战斗。对话、卷宗和扑克期间暂停城市时间，避免认真读材料反而错过关键人物。

扑克牌是某些 NPC 的关系门槛，绑定具体“情报”而非绑定通缉胜负。首章只在 B08 酒馆牌手与 B03 码头老水手等少数案出现；B07 新手案不设强制牌局。开始前显示规则、可赢得的口供和失败代价；单局目标约 45–75 秒，由 NPC 提供调查筹码，不押任务物品，也不要求玩家先赚钱。牌局需能在同样初始资源下用策略获胜。输牌后 NPC 坚持不说约定情报，玩家可立即重赛，或在相邻地点通过公开档案与另一证人构成替代交叉核验；替代线从一开始就存在。已赢过的同案同一知情人只需重读对话，不重打；普通信任也跨案件保留，只有新赌注才可能再开一局。重启时记录牌局结果。牌局不能替玩家自动接受犯罪传闻，也不能把无辜者当“可战斗嫌犯”。

| B10 换寿先知·绯欠／Q26 | 施济登记、诊所 → 守灯值班室 → 封闭施济厅 | 对照疗契正反面和病历时间，现场切断转接囊体。 |

## 首个可玩案 B07：从玩家视角的一次流程

Q5 后酒馆老板指出夜间有人敲门借声，玩家接 B07 卷宗；卷宗只写“旧邮局夜班邮差听到同一句求救”。点旧街路面走到邮局，与邮差谈得知两处街区同刻听见呼救；纸上记下两个具体门牌。玩家可以先去木工街质问修门工，但此时只能得到他被怀疑的传闻，不会自动判罪。到诊所问奥黛尔并看门闩样本，得到黏液和缺趾爪痕。再回木工街核对工单、五指工具痕和邮务时间，卷宗明确划掉修门工。档案员指向旧排水口；玩家在台面上把木漆、排水泥、重复声纹与三间空屋的记录比对，选中第三间。地图才显示排水口可进的支巷。角色亲自走进空屋附近，先听到喉铃复声，再看门闩上的缺趾痕，看见铃蛙诱骗另一住户；点击“阻止它”进入现有 B07 实时战。胜利后拿到喉膜拓样，地图提示回酒馆或教会交案。玩家到任一柜台说明修门工被排除、铃蛙身份已核实，领取一次性铜币、功勋与装备。败北时返回支巷入口，调查进度不倒退。

## 接入边界与验收

- 数据层补充城图地点、NPC 对话分支、现场交互、可选牌局和“待交案”状态。调查节点和战斗 ID 继续复用现有十案，不复制一份酒馆案卷。当前 `finishChurchBounty` 的胜利流程会立即给报酬，实施时必须拆分战斗结算和柜台领奖；旧存档已领报酬保持已结案，不回收或二次发放。
- `ChurchBountyDossier` 只保留卷宗回看，调查操作从房屋标记到门口、进入室内后发起 `investigate`/`answer`；地图上的标记本身不发证据。
- 第一轮验收用新档 B07：接案 → 先问修门工的错误猜测 → 邮局/诊所双线索 → 排除 → 现场比对 → 步行找到空屋 → 主动缉捕 → 战斗 → 现场收押 → 回柜台领奖。另验先到后续地点仍可查物、跳过非必需误导分支但用足够独立证据结案、读档、牌局输赢与替代线、战败重试、教会/酒馆双入口不重复奖励、旧档迁移。必须通过手机镜像逐步实玩并留下画面；自动规则测试不能替代此项。

本稿曾向右侧 ChatGPT 6 Pro 询问地图探索结构；采纳“事实与推断分存、乱序取证、牌局锁 NPC 不锁整案、现场收押后交付”的机制建议。它给的十个示例罪犯、案名和报酬是另造的样例，**没有**拿来覆盖本项目现有 B01–B10、奖励与剧情。
