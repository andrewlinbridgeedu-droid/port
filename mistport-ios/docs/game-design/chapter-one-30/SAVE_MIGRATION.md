## 迁移顺序

1. 备份完整原存档；应用旧pending结算的最终快照，取得确定余额与持有量。
2. Q1–15保留稳定关卡/遭遇ID。新版Q16–30使用语义稳定ID，显示数字另列；旧Q16–20存为legacy事实，不按同序号自动完成新版事件。
3. 制作逐条映射表：同一事件移动则继承完成与奖励收据；完全重写事件则保留旧史，新事件仍需打。主线遗物与凭证不重复发放。
4. 引入永久 `rewardEntitlementID` 账本；旧已领首通导入已支付收据，不按内容版本号重发。同一事件换位置只迁移资格；新的实际遭遇可另有普通报酬。
5. 原值保留铜币、技能等级、材料、药物余量、假面裂纹、已有天赋投入与序列。禁止用新奖励总和重算旧余额、补回已用药、自动装备暂停遗物。
6. 将已有晋阶主材映射到新版同用途材料/等价已支付凭证；不能删除后要求重买。已消耗材料留下仪式事务收据。
