## 故事与身份约束

玩家从追查自己的名字，追到把活人变成可认领、补位和押运的记录。伊恩的缺角茶杯贯穿寻找与救回；玛拉面对签署救援回执的责任，维娅自愿断契，洛克恢复允许被救者离开的原始条款。旧亡妻连续体为历史资料。

Q1–8失名与诊所 → Q9–16假家庭、错误救援与终止旧犬 → Q17–23补位交易、人物选择与替代封口 → Q24–27救伊恩、断契、截运、取得原档 → Q28–30总签官三次交锋及真死。主角因早于入港的外部追索被迫去黑盐岸；玛拉留城担责，救人胜利不撤销。

同实体重逢为旧犬Q3／4／16、维娅Q15／22／25、洛克Q13／21、撤运锤卫Q20／26、总签官Q28／29／30。其它同模型单位必须是不同实体。非致命退出、解除命令和真正死亡分别表现，不靠换名解释复活。

模型预算的旧“22母版”仅是9月16日阶段快照；后来新增五种塔怪与八体通缉已超出该口径。使用现行角色资产清单，不再把旧预算当当前资产总数。

## 战斗与经济的固定边界

单主角实时战斗，Swift管规则、Unity管表现。每关空编排、手动点选出招次序，未选只普攻；假面是可手动用的遗落物，不是第八张卡。永久十裂纹及Q3／Q4教学豁免保留。表现保留各招身份和命中契约；需要伤害冲击的招式强调接触瞬间快速撑开，治疗／强化不强套伤害爆炸。不能以缩小所有主体来修过曝，也不能把规则圆环／方框／等距裸光条当魔法主体。

主线首通2280铜、初始180铜；三材1080，另有待实施仪式预算280。塔首通1700铜／320功勋，通缉按当前十案核算；六地下委托560铜仍是设计，未实装收入不能预支。主线重玩当前存在铜币奖励，塔普通重玩没有首通奖励。J0无成本恢复收入保留。新增银行投资不得成为主线、塔或晋阶门票，不能发专属装备或用投资收益修补主线必需预算。
