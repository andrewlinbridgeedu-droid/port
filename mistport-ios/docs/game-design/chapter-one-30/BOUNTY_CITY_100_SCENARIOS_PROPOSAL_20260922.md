日期：2026-09-22。状态：**方案，未实施、未平衡、未原生/真机验收**。B04/B06 的角色、罪行和十份情节已按[新原画设计](BOUNTY_B04_B06_CHARACTER_REDESIGN_20260922.md)改写；游戏中仍是旧版。本文把“金币”理解为当前账本的**铜币同一单位**；不擅自增加兑换率或新货币。

## 决策摘要

保留旧六案 `b01`–`b06` 的唯一结案与已领收据，加入既有提案的 `b07`–`b10`，总计十名通缉目标。每名目标规划十份**内容不同、各有稳定ID且最多领取一次报酬**的公告，合计一百份；其中一份是已有/提案中的主犯核验及正式结案，另外九份是同一犯罪链中可追索的独立事件。十份是**可选内容库，不是必须在Q30前打完的十连任务或十次复活主犯**。目标状态（在逃、在押、销毁、灵体终结、异常收容）与每份案卷状态分开记录；主案只结一次，后续还可以调查遗留责任。

在主犯尚未结案时，公告追查其当次现身点、工具、同伙或被害者；主犯被拘捕、销毁或灵体终结后，余案改为“该犯遗留案”且明确标明本次需定位的**同伙、赃物转移点、仍运作的装置或失踪者**。不能让B01的已销毁执行体、B03的已终结灵体又无说明地重复出现。若玩家坚持每份公告都要亲自再打同一主犯，必须另立逃脱/分身/重构的世界规则并迁移旧六案结局；当前方案不建议那样做。

每次张贴都只公布已查实的**涉嫌行为与受害事实**，不显示坐标；玩家到实际城市场所与居民对话，取得至少两条独立来源并排除一条可信误导，再解锁目的地。不能把现有卷宗内“五个按钮铺在伪城市地图上”当成已完成的真实城内走访。B09先列为危险异常收容目标；谁驱使它咬毁账证，需要从人类获益者与装置追查，不能凭它是怪物就预断其主观罪责。

## 公告、对话、定位、触发

1. **发榜**：诺恩/教会公告板只展示头像、目标名、当次案号、具体罪行、受害者状态、建议调查街区、金币范围与“未查明去向”。告示不是定罪书；现有证据不足时写“涉嫌”，现场核实后才可宣告结案。
2. **查访**：接取后指向第一个确切NPC，不要求把全城每人点一遍。该NPC给时间/事件线；第二个独立来源给工具/物流线。至少一条线来自人证、一条来自物证或档案，不用同一谣言转述两次充数。两线可先后任意取得。
3. **交叉定位**：玩家选择哪组事实能排除看似合理的嫌疑者。错答提示缺的是哪种证据，不扣钱、不误抓路人、不永久失去报酬。对话日志与比对结果可重看。
4. **现场**：只有核验通过才在已开放城市场景标出调查点；到场再核对目标身份、同伙身份或遗留装置。新地点只在案内临时开启，不提前暴露在主城常驻列表。战斗只在确有抵抗时发生；受害人不设为敌方血条。
5. **结案**：救援、证物返还、逮捕/销毁/封存依案情不同；金币按案号收据一次性结算。没有杀死目标也可合法完成部分案件，但不能让放走正在加害的主犯成为唯一高收益路线。
6. **再上榜**：由下一项叙事条件、主线进度或上一份事件后果开放，不按现实日期强制刷新。推荐同时最多追踪三份案卷，默认突出一份；玩家可保留旧调查，不会因新榜覆盖而丢证据或奖励。系统只从已手写、已满足条件的案卷中推荐，不能随机拼接凶手、动机和受害者。

状态建议：`locked → posted → accepted → twoSources → compared → siteUnlocked → confronted → resolved → claimed`。`battlePending` 与 `victoriousUnclaimed` 保留独立中断恢复。每份公告用 `bountyID + episodeID`，主犯结案仍沿用既有 `bounty-close-bXX`；余案新收据如 `bounty-episode-b01-02`，以旧存档不能碰撞的独立键记账。只有 `claimed` 的主案可映射到主案已结，**不能**批量把其余九份标成已做。

## 十份内容的可见差异标准

每份至少变化三项：发榜原因、主动提供线索的人及其利害关系、交叉核验方式、实际地点/被定位对象、最后行为（救援/追逐/战斗/封存/返还）、犯罪链新信息和报酬结构。仅更换街名、怪物HP或换颜色，不算不同情节。允许复用同一角色模型及基础招式，但同一人的余案战斗应让**协犯/装置**承担差异，不能再造九套假装是新主犯的Boss。

计划形式为每人一个主案＋九份余案，使用十种可辨认的叙事功能，但不机械规定顺序：**验真缉捕、双主争物、残留救援、迟到的命令、错认翻案、追赃分流、证人拆供、赔偿选择、末端截流、结案回访**。各人从中取适合其犯罪链的十个具体情节，且每份还要按上段标准产生不同的证据、现场与结局；不强制每份都战斗。晚开放的B05/B06/B10不要求在Q30前全部开放，否则后段30关主线会被三十份支线挤爆。Q28起不再新推长调查，Q30离港后雾港现场调查按现行规则暂停，未结案号与已挣未领权益保留；已挣未领铜币可待未来可信的异地结算联络完成后领取，未做的现场不能靠远程按钮伪装完成。等将来真实回访功能完成再继续，不承诺目前已经可以瞬间回城。

## 奖励与房产：计算口径，均为新建议

主案铜币1060保持[既有十案提案](BOUNTY_TEN_PROPOSAL_20260922.md)口径，旧六案已领的不再重给。每名目标的九份余案设**六份普通查访**（90、95、100、100、105、110铜）与**三份高风险救援/截流/清除**（180、200、220铜），合计每目标1200、全九十份12000铜；十人百份全部完成可得13060铜。这是分阶段发放的**一次性新建议**，不是当前已在游戏里的收入，也不是同一关的掉落。高风险不等于必有战斗，关键是危险、时效、受害人数或执行成本；普通查访同样有金币，不把对话救人贬为零收益。非货币奖励以绑定案卷、外观、城市口碑、普通补给或家具图为主，**余案不再额外发技能尘/教会声望，也不掉晋阶三材、主线钥匙、强力遗落物本体或可出售的证物**。旧六案原有功勋保持，四新主案的非币奖励仍按独立设计核定。金额须在真实对话耗时、耗材与J0单位时间收入验收后才可定稿。
