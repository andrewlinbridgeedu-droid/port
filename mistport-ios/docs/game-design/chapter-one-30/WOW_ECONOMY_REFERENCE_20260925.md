## 经济含义：主agent推论

系统任务发奖和收购战利品属于玩家侧货币来源；付给不再把钱投入市场的系统服务属于回收。玩家互相买卖通常只是转账，不能把成交额当作新增货币，也不能把材料消耗当作金币销毁。若NPC有可再支出的真实预算，则支付给NPC只是转移；这一点需要雾港按账本定义，不能照搬“所有商店都回收”的口号。

自动化若反复领取系统金币，会放大货币来源；若主要采集，则先影响材料供给、价格和正常玩家可取得量。这是对不同刷取路径的经济推论，不是暴雪给出的定量归因。交易多次不会自动产生同等次数的新币。

制造的价值来自将材料和工时变成有用途的商品，市场订单把愿付价格与供给连接。重复消耗品与维修提供持续需求，绑定／活动资格保留个人进度；但这套结构本身不保证旧金币的长期购买力。资料片改变技术、材料和装备需求会改变相对价格，不能把这种变化都称为一般通胀。

WoW可以作为“来源—回收—玩家交易—实物需求—版本治理”的参考，不能作为“绝不通胀”的证明。未取得同口径长期固定篮子、货币存量及成交／缺货数据，本轮不编造其通胀率。

## 雾港对应建议

| WoW可借鉴的思路 | 雾港处理 |
|---|---|
| 系统明确控制金币来源和回收项 | 采纳逐来源总账；发行、销毁、财政转移、托管和贷款分列。具体金额需购买力定标与长周期压力计算 |
| 玩家制造与订单交易 | 采纳真实客户预算、配件进入自行车库存、交付后回款；不是点击“投资”自动产生收益率 |
| 合理的持续消耗与服务费 | 改造为可解释的维修、运输、检验与有限经营费用；不能专门抬高主线刚需让旧钱缩水 |
| 大额可选消费 | 可考虑银行装饰、收藏及非必需公共建设；不把强制缴税或没收存款当通胀解法 |
| 绑定材料与个人进度条件 | 保留证物、晋阶主材、借物及押金的现有保护；不让财力直接购买全部故事资格 |
| 更大的商品交易范围 | 待权威共享账和物流成立后分地区扩展；不能把当前离线任意铜币余额导入共享资金池 |
| Token的付费兑换 | 不采纳为雾港经营本金渠道，沿用不出售可交易本金与世界事件权重的商业化边界 |
| 用更新调节过量产金 | 建立预警和有限预算；旧存款、资产、已有合同完整保留。主线回放和J0改动不得未经连续验证就暗改 |

最终稳定性须同时报告固定基础生活篮子价格、实物足量率、支付能力、未满足需求、财政／库存缓冲剩余和可支付信用。金融局部账平、固定硬币总量或固定UI标价，均不是独立充分条件。
