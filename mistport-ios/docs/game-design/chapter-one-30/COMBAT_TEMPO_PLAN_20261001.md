## 2. 原则

1. **总伤害不变，拆成更多下**：
   - 敌人出手频率约翻倍，每下伤害约减半，每秒伤害（DPS）大致不变；
   - 玩家普攻同理。
   - 这样墙关、每日推进、经济都不用跟着重算，只需复核。
2. **分轻击和重击**：
   - **轻击**：现有的普通攻击，加快后成为背景节奏，快、小、不预告。
   - **重击／机制**：现有的蓄力、火球、绿焰、伏击、敲击、塔层充能等。时间和伤害不变，预告更醒目，因为现在有快节奏衬托。
3. **按次数算的防御只管重击**：
   - 假面幻影目前挡 2 下，纸人代身挡 1 下，未写结局闪避 1 下，空白名牌按次数挡。
   - 轻击变多以后，这些很快会被轻击吃光，Q4 用假面接双焰的教学就坏了。
   - 改成：**它们只接重击**。幻影在场时，轻击被“招架”，伤害减半，**不消耗次数**，飘出“招架”。
   - 护盾按数值吸收，轻重都吸。装备的百分比减伤照旧，伤害按比例缩放不受影响，已核对代码。
4. **敌人永远在动**：
   - 出招必须有身体动作：停步、蓄力、前冲、后坐；
   - 待机是战斗姿态，每隔几秒小跳换位；
   - 不允许边走路边出招。
5. **教学关慢一点**：Q1–Q3 轻击间隔用 2.0 秒，Q4 起用 1.4 秒，章末 Boss 用 1.2 秒。

## 3. 数值提案（规则库，云端做）

都放进规则库的一处常量（暂名 `MPCCombatTempo`），两个步进器共用。

| 项 | 现在 | 提案 |
|---|---|---|
| 敌人轻击间隔 | 3.2 秒（猎犬 3.0，记忆蛭核心 5） | 1.4 秒（猎犬 1.3，核心 2.5）；Q1–Q3 用 2.0；Q28–Q30 用 1.2 |
| 轻击伤害 | 攻击力 × 意图倍率 | **× 间隔比例**：例如 3.2→1.4 时乘 0.44，保持 DPS 不变 |
| 轻击出手前摇 | 0.65–1.1 秒（按敌人） | 0.30–0.45 秒 |
| 开场延迟 | 2.4 + 0.35×序号 秒 | 0.8 + 0.25×序号 秒 |
| 重击／机制 | — | 时间、伤害、预告时长**一律不变** |
| 重击之间的空档 | Q4 等脚本循环里有 8–11 秒空白 | 空档里插轻击；蓄力和破绽期间不插 |
| 玩家普攻 | 2.4 秒一下，硬直 1.65 秒 | 1.2 秒一下，硬直 0.8 秒，伤害 × 0.5 |
| 玩家技能硬直 | 1.75 秒 | 1.1 秒；技能冷却不变 |
| 假面、纸人、闪避、空白名牌 | 按次数挡所有攻击 | 只挡重击；幻影在场时轻击被招架、伤害减半、不耗次数 |

**校准方法**：用进度模拟器在新旧规则下各跑一遍，验收标准：
- 墙关探针（Q8/12/18/22/26/30 × 高中低）的胜负结论和最低塔层要求**与现在一致**；
- 主线 Q1–Q30、塔 D01–D11、通缉 B01–B10 每场的平均时长变化在 ±15% 以内，必要时再调轻击倍率；
- 除重击外，单下伤害不超过玩家生命上限的 6%，血条走得平滑；
- 每场战斗里，玩家每秒看到的“事件”（出手、命中、招架、飘字）至少 2 个；
- 规则库现有 559 项测试全过，另加节奏测试：轻重分类覆盖所有意图、幻影不被轻击耗尽、Q4 双焰仍需假面接。

**版本**：
- 教会系战斗升为 `church-battle-v3`，主线升为 `story-battle-v2`；
- 服务器按版本复算；
- 共享服还没上线，没有旧票据要兼容。

### 4.2 主角法术：快节奏下的新特效

在[技能梳理](SKILL_IDENTITY_REVIEW_20260930.md)已认可的方案上做，包括十件道具、九种签名、蜡和纸两种材质。加快节奏后另有四条要求：
1. **每招整段不超过 1.2 秒**：起手 0.1–0.2 秒，命中爆开 0.1 秒，余韵 0.4–0.8 秒。终极技“无名宣告”除外，它独占全场 2 秒。
2. **前后招叠着放**：前一招的余韵还在，后一招已经起手，画面不会空。同一招连放两次时换角度或镜像，避免完全重复。
3. **连段要看得见**：
   - 铺垫（假面谕令、伪证烙印）留下的误认记号挂在敌人身上；
   - 张冠李戴把它们换成错位；
   - 兑现招（双影追猎、荒谬归结）把记号吸走后爆开。
   - 玩家能看出“这一套打完了”。
4. **普攻也要好看**：普攻快了一倍，做 3 种交替的短斩、刺、甩牌，命中有小火花。
