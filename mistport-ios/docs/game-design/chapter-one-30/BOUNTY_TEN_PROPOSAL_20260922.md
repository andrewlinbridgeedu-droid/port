## 1. 这十案要补什么

主线讲“被规则认领的人”；通缉讲“有人怎样主动利用规则伤害别人”。人、亡魂、机器或恶魔都可以成为目标，**但长相、物种、职业、传闻不构成定罪证据**。每案要有独立受害事实、时间/工具证据及现场身份匹配，不把洛克、维娅或同一主线敌人再杀一遍。

玩法保持现有单人实时、战前按点击顺序编排、战中点击换目标及已有主动操作。反制不得要求新添闪避键、打断键、即时重排卡牌或无限假面。所有案都应有不买指定遗物、不烧永久裂纹的胜利路线。

奖励负责：

- 早期提供可选零钱和教会资格，不把主线药品采购锁在悬赏后。
- 中期练习选择目标、编排交替、驱散与有限持续伤害。
- 后期让铜锚、墨镜、断线针等有实际用武之地，而非强制装备。
- 有限首通技能尘是本轮新增建议，不是当前掉落。
- 不给通缉专属主线钥匙，不把全部结案变成Q30或晋阶门槛。

## 3. 案件共通结构

每案沿用“报案/独立证据 → 排除相似对象 → 交叉定位 → 现场确认 → 战斗 → 结案”。前两条证据允许先调查后接案，读过的内容可复看。

- 每案至少两条独立来源，不能把同一份传闻改写三遍算三证。
- 关键比对题的三个选项都要与案情相关，不总把正确答案放第一项；按稳定choiceID判断，显示顺序按案/存档固定打散。
- 答错说明缺了哪一条证据，不扣铜币、不扣声望、不杀无辜者，不形成付费重试。
- 受害者不是可攻击单位、治疗电池或掉落容器；战斗失败回到可重试状态，不永久销毁救援资格。
- 已确认身份与调查进度跨关保存；战斗胜利与领奖分开去重。
- 没有现实时间截止。Q30离港暂停雾港现场调查/追击，保留进度；已胜未领奖可补领。不能许诺尚未实现的立即回访功能。
- 本提案的实物证据名称先记在案件册；要变成行囊物品须新增专属绑定ID，不能占用主线44证据或晋阶三材的ID。

## 4. b07 三声敲门客

**一句话**：它偷走求救者的最后一句话，再用那句话请下一个人开门。

- 身份与开放：Q5后，独立吞声怪物，不是金喉树蛙塔内某只个体。它重复诱骗、袭击居民的行为已经被幸存者和现场证据交叉证明。
- 外形：低伏蛙形身体，喉囊像包住一枚腐朽小钟；唇边粘着不同门牌的木屑，背皮湿黑、喉部暖金。不是普通青蛙换红色，也不做满身规则光圈。
- 地点：旧排水道通往的三间空屋；正面是完整的门，门内却留下由外向内拖行的爪痕。

调查链：

1. 夜班邮差记录：同一段“替我开门”在两个街区同时响起，原说话者当时在诊所。
2. 诊所验伤与门闩木屑：伤口有黏液残留，三处木门都有同一只右前爪缺趾印。
3. 排除传闻中的聋哑修门工：他的工单、邮务时间及完好的五指工具痕独立吻合。
4. 将木屑漆层、排水泥和重复声纹比对，定位第三间空屋，不凭“听起来像受害者”定人。
5. 现场看到喉囊复制录下的呼救、缺趾爪碰到相同门闩；确认目标正在诱骗另一名住户，才能交战。

两招与节奏：

- **借声叩门**：身体伏低、喉囊分三次偏侧鼓起，第三次吐出一团破裂声压与湿亮碎沫，属于一次直接攻击。声音可关闭，喉部和敌方意图仍给相同提示。
- **吞门涎**：身体拧向一侧，低吐一条不连续的黏涎，造成有限持续伤害，几跳后自行结束；不是Q5全场递增毒雾的复制。

反制：Q5后已有错步、勋章、盐囊/银扣采购。盐囊应对毒沫、银扣应对爆音，两者不同时装备；没有购买者也能通过基本伤害与一次药品窗口完成原型目标。不得要求尚未解锁的张冠李戴或反客为主。

结案与掉落：教会封存**借声喉膜拓样**，受害者录音归还家属；60铜、建议缄卷20、30尘。证据不是活体器官商品。缄卷20可让Q9印章具备一条不依赖F11–20的资格路线。

美术实施：原型可借D10骨架验证蛙形发力，但需独立喉囊/缺趾/门木细节与动作；最终若与塔蛙辨识不足，应要新母版。塔内F22首现记录不改，也应承认同类身体提前出现在支线会降低塔的新鲜感。

## 5. b01 第七号空壳

**一句话**：已撤销的处决命令，仍在七号机的胸腔里准时执行。

- 原案保留：Q7；稳定敌人 `bounty_b01_execution_body`。它与Q1/Q7主线守卫是独立身份，不是被杀后又复活。
- 外形：灰铁甲、左肩残缺七号、双短齿缺口的长剑；身体其他灯已暗，胸腔处决灯有延迟闪动。
- 调查：双案相同封锁时段＋左斜剑创双齿 → 值勤登记排除正常巡逻 → 木门割痕和剑齿拓片锁定废岗亭 → 七号残标、指令时间与作案剑同时匹配。
- 关键题：不是“守卫看起来危险”，而是哪组时间与缺口无法由正常巡逻工具造成。

两段演出：

- **假停机**：下沉、垂剑、不移动，但胸腔灯和足部锁止声仍提示执行中；界面不得将攻击误标为真正安全恢复。
- **缺齿突斩**：肩部先抖开、上身前压，沿旧伤方向斜斩，命中喷出短促锈金裂屑，随后剑卡地面形成真正恢复窗。

反制与边界：突斩必须有完整可读预警，不做刚醒即伤害；能用当时已有构筑生存，不强制使用会永久耗尽的假面。一次真恢复窗可供自动卡序输出，不能要求玩家暂停普攻。

结案：销毁非法执行体、封存**第七号命令匣**；60铜、旧12功勋拟归守灯、拟加30尘。维修工责任另案，不因职业推定同犯。

现状区别：原六案调查、目标和假停机突斩逻辑已有；这里的精细动作、破口造型、尘奖励是打磨提案，不称已制作。

## 6. b08 借脸人·弥伦

**一句话**：他不偷你的名字——他让你的亲人相信，站在门外的你才是假货。

- 身份与开放：Q11后，人类冒名犯。使用异常面具伪造亲属关系、骗走财物并拘禁被替代者；不是“身份不明所以有罪”。
- 外形：成年瘦削男子，深蓝长衣缝着不成对袖口；半张蜡面具熔在颧骨，真人右手旧伤透过伪装。人类新母版需后续制作/用户提供，不把现有女主换色当完成。
- 地点：旧照相馆；场景中的家族照片只做线索，不生成可攻击的家人幻像。

调查链：

1. 被冒名者的雇主出示同日异地签收，两份记录物理上不可能由同一人完成。
2. 诊所旧病历、真实家人的独立描述记录右手伤；伪签留下的是另一只手的压痕。
3. 排除被勒令沉默的孪生兄弟：出港前检查底片与船员证言给出独立时间线，不凭双胞胎推罪。
4. 两张相片的蜡面反光、被盗收据的乳剂粉末，指向同一旧照相馆。
5. 现场人手持失窃原件，伪装换脸却保留指纹/旧伤、正在关闭拘禁者房门，确认弥伦。

两招与打法：

- **借脸招徕**：弥伦侧身抹过半面，衣摆分出两道不完整伪影；真身保留先前确认的手部伤痕和“证据已匹配”标记，不能只靠微小颜色在手机上猜。
- **反证刺**：伪影先做夸张挥臂，真身随后从另一角度短刺；伤害仅真实动作一次结算，不让装饰残影造成假多次命中。

反制：三目标中选择真身可推进核心战斗；打伪影也能逐个消除，不因一次误点软锁或无限重生。每轮伪影数量有上限；张冠李戴、伪证、错影已有，可形成多条编排路线。不要要求Q12的驱散或Q14才可买的墨镜才能赢；后者可用于日后练习但非首胜钥匙。

结案：交回失窃凭据、救出被替代者，弥伦失去伪装后被拘捕。**借面签收底片**入案件册；80铜、观镜20、30尘。与Q9观镜20相加，可在Q14形成40声望的非塔墨镜资格路径。

## 7. b02 背架收尸人

**一句话**：他的死亡证明比被运走的人，先到教会一步。

- 原案保留：Q14；稳定敌人 `bounty_b02_abductor`；人类绑架犯，非洛克。
- 外形：旧褐工装、外锁背架、向外扣紧的染血束带。洛克是救援背架，本案在锁扣朝向、衣色和步态上明确不同。
- 调查：活人领药记录＋逃出生还者证词 → 洛克救援录音/编号排除 → 外锁油迹与渡运收据定位废浴场 → 现场被绑活人、赃运收据与独立身份相互吻合。

两招与打法：

- **反扣束带**：拧腰推出空的机械锁臂，短蓄力后拘束主角；被害人不挂在武器上参与攻击。
- **闭架碾压**：锁臂闭合后产生有限持续磨损，随后松闩、俯身回收；不是无限毒伤，也不是瞬间把人判死。

反制：Q12已获得反客为主，可在卡序中处理负面窗口；其它路线保留足够的直接输出与恢复空间。拘束效果必须明确限制什么，不隐藏禁用全部按钮；失败保留调查和救援资格。战胜自动完成解锁救援，不另卖赎金按钮。

结案：绑架者被制止、幸存者转至诊所；**外锁束带与赃运单**封存。80铜、旧16功勋拟归守灯、拟加30尘；绝不掉主线洛克的个人物件。

## 8. b09 铜背吞契兽

**一句话**：被它吃掉的“已还清”，会在第二天重新变成欠款。

- 身份与开放：Q17后，具有理解契约能力的异常兽；被查实反复吞掉清偿记录、伪造债权并袭击追索原件者。不是因甲兽外形或居住地点定罪。
- 外形：四足低重心，背甲夹着各式旧铜封签；最厚的一片甲向左歪折，腹侧藏撕碎纸浆。与塔D07分离身份，形体细节不是同色小怪放大。
- 地点：废质押所地下纸窖，受害债户不放进战斗单位数组。

调查链：

1. 两名互不认识的债户保有原清偿收据，但账房底联同日被咬去“清”字。
2. 档案员验出断面唾液与同一枚歪铜齿的缺口；外来侵入痕不是自然虫蛀。
3. 排除被指控的账房学徒：清偿时间戳、公开复写本与异地登记都支持他已正常销账。
4. 废质押所纸窖的排浆含同一批票纸、铜屑，和破窗齿痕交叉定位。
5. 现场确认目标正在保护被吞清偿凭据、向受害者发出重复索偿并攻击取证者。

两招与规则：

- **借债甲**：前肢压地，背甲夹缝挤出不规则铜纸碎片；获得可破除的普通护甲/盾，绝不套真免疫再提示玩家驱散。
- **撕据崩**：后腿蓄力、前肢掀起一侧背甲短扑，碎甲从受击点向外炸开；出招后歪甲翘起形成短暴露期。

反制：普通攻击可逐步破盾，Q12的反客为主可清普通增益，Q17已可选空栏名片规避一次直击，但会牺牲自己那段输出。不能要求Q18才取得的镇纸作为首胜必需；后续镇纸仅是另一种构筑选择。

结案：异常兽被制止，清偿凭据由档案员复原，返还受害人。**反写铜牙拓片**绑定入档；110铜、守灯20、30尘。赃据不是商店卖钱道具，不免掉真实未偿债也不追索无辜者。

美术：D07可供原型骨架/体型试验，但需不对称背甲和撕据动作；新轮廓未做前不称独立成品。

## 9. b04 倒签客·乌檀

**一句话**：他偷用真章和铃签伪造两份互斥遗嘱，把活人的合法姓名从继承册中抹掉，再向夺产者收费。

- 保留案号、Q19、稳定敌人兼容键 `bounty_b04_forgery_engine`，身份改为主动作案的人类见证人，非Q17/Q29主线机器；旧英文ID不代表新剧情。
- 形象：黑金宽帽、青绿内袍、悬签与铃坠、细长验印杆；帽檐下的人脸要能在定罪前露出。
- 调查：两份互斥原件＋独立验印 → 缺半音铃声、悬签纤维与学徒收款簿排除普通书记员 → 废印厂公证席现场核真章、待覆盖房契和本人操作。

两招与玩法：

- **铃借前文**：止铃后反手摇两声，残签和不规则金墨笔迹卷起，显示已实际施放的最近两次技能；不偷牌、不封键。
- **倒签夺籍**：肩髋反扭、笔杆斜划，青绿墨裂翻出金边残纸；同技连用按既有2.5×ATK加重，否则1.5×ATK，接触瞬间扩大后快速回收。

公平边界：继承现有“惩罚连续同技”的身份，不改成偷走玩家整套卡。没有手动停牌能力也能用战前多牌顺序应对；不因玩家未点卡只普攻就永久免疫。记录在恢复/死亡/重试时清理，不把前一场的牌带进下一场。

结案：乌檀被拘捕，失窃真章查扣，假权属撤销、合法原件返还并救助被逐者；**真章印压与悬签纤维比对记录**入档。120铜、旧24功勋拟归缄卷、拟加30尘。原铜奖励高于更晚的B03保留不动，后续应按实测耗时与风险比较，而不是只按解锁关号加价。

## 10. b03 溺钟海盗

**一句话**：它已经溺死，却仍按一张没有注销的船员表，召人上船。

- 原案保留：Q23；稳定敌人 `bounty_b03_drowned_captain`；两个护航残影沿用独立ID。
- 外形：海蓝亡魂、胸前船锚章、湿重旧舰衣；周围不是任意泛白幽灵，而是两道带旧船员绳结的护航残影。
- 调查：真实船期＋钟台逆敲暗号 → 港工不在场与溺亡船证排除 → 退潮盐线/船证/钟点定位 → 海盗印、逆钟指挥与袭船行为完成身份核验。普通溺亡者不因此成为目标。

两招与队伍：

- **逆钟护航**：两残影从船长肩后错位掠出，维护来源清晰的保护；显示尚存护航数。仍按“先清护航解除保护”的当前身份。
- **沉锚追索**：船长回腰拉锚、再前掷砸下，短水幕与盐碎在目标处爆开，收势时锚链松垂。水形不做整圆光环。

反制：点击换目标处理两护航；双目标错步或分别集火均有路线。不能让船长真免疫还吸走所有自动目标，辅助血条与当前目标应可辨识。铜锚是否适用取决于实际同动作多段，不能仅因招名叫“锚”就强行适配。

结案：袭船灵体终结，赃货依账返还船主；**海盗印和赃货账**封存。100铜、旧20功勋拟归观镜、拟加30尘。赃货不全变成玩家战利品。

## 11. b06 熄灯药师·莱沃

**一句话**：他穿白袍伪造检疫令，用红剂令乘客失声昏睡，再熄灯拆钟把活人运给买主。

- 保留案号、Q26、稳定敌人兼容键 `bounty_b06_dark_hold_captain`；身份改为人类随船药师兼押运主谋，区别于Q26的B10换寿恶魔。
- 形象：乱束白发、暗圆镜、破损白袍与红衬、左右不同的红瓶和铜笼提灯；灯中面孔是被害者蜡面拓样，不能写成另一个怪物。
- 调查：熄灯航线与满油补给冲突＋独立检疫原件 → 获救者证词、水壶和红瓶残留 → 铜笼断齿与失窃钟舌定位封舱台 → 现场核他本人、押运名单与正在禁锢的活人。

两招与打法：

- **隔疫封灯**：提笼至胸前、开青瓶，错层青白雾褶短时合拢；维持既有3秒真实免疫，明确与可驱散普通盾区分，不做规整球罩。
- **赤剂醒灯**：红瓶入笼、蜡面骤亮，腰肩甩灯推出湿布状赤色液雾；维持既有3秒蓄力、2.0×ATK，接触峰值撑裂后迅速收回，随后3.5秒破绽承受175%伤害。

反制：观察护势结束的恢复窗，合理编排避免迟签印章的延迟包落在免疫中；可用不同已获得主动物生存，但不要求耗假面。人质在战斗场景外被保护，胜利后自动撤离；不增加倒计时永久杀死人质的隐藏条件。

结案：莱沃被拘捕，乘客离船送医，药瓶、假检疫令、铜笼和买主账册查扣；**无灯航线与红剂检验记录**入档。160铜、旧32功勋拟归守灯、拟加30尘。

## 12. b10 换寿先知·绯欠

**一句话**：每位痊愈者都以为自己付过诊费，直到另一个人的生命开始变短。

- 身份与开放：Q26后，独立欺诈恶魔，借“换寿治疗”窃取病患权益；不影射所有先知、医者或绯幕恶魔有罪。
- 外形：绯黑不对称长帷，脸前是磨损的双层薄面壳；掌心握碎裂账签，后摆像不断被抽去纤维。辅助体是**自愿同谋/被邪术驱动的收寿囊体**，不是无辜病人。
- 资产：可用D09体型与D03治疗动作作原型研究，但先知、囊体各有独立actorID、材质和表演；不是把塔两只直接拖来改名交付。

调查链：

1. 三位患者的“免费续期”收据在背面留下事后增补条款；与原签收底稿不符。
2. 诊所独立记录显示另一组无接触者的衰弱时点，与治疗收据号逐一对应；证据来自受害事实，不宣称会治病就可疑。
3. 排除守灯诊所：公开药剂批次、值班原稿与两组人行踪不重合，完整保留。
4. 追踪封条纤维、账签缺角及治疗转接印，定位封闭施济厅。
5. 现场把原始底稿与被偷改版本对照，看到先知命令囊体向自己转接外来治疗，确认同一条转接链和独立身份。

两招与辅助行为：

- **赊寿帷刃**：先知旋腰揭开一侧帷幕，帷边向前卷成撕裂弧刃，命中瞬间扩张再蚀散；不是规则矩形光板。
- **转息回款**：囊体在先知受伤后，从背囊抽出一束有厚薄变化的绯白气流，明确流向先知并出现实际绿色恢复数值。治疗属于外来治疗，不伪装成自愈或普通护盾。

原型参数建议：外来治疗每14秒至多一次、全场最多三次，每次不超过先知最大HP的8%；先知满血不空刷治疗。具体伤害/HP在正式可得构筑中再定，不把这些建议称为平衡通过。

两条完整胜利路线：

1. **无断线针**：先杀低耐久囊体，治疗链断开，再处理先知。即使保留囊体也有总治疗次数上限，不形成无穷战。
2. **有断线针**：主角已受伤且所选先知即将得到治疗时，保留囊体，利用截疗回血；随后6秒自身不能治疗是清楚显示的代价。切到囊体就不满足原目标条件；主角满血不刷截疗次数/收益。

归属断线针是Q25许可、Q26可购的可选玩法，不是开门钥匙。不得把囊体设为无敌，或让针无法购得的玩家无解。

结案：撤销伪造转接条款、释放受害者原记录，先知被制止；**换寿双联账**封存。150铜、缄卷30、30尘。该案本身无需先拥有高级缄卷租物，避免声望自锁。

## 13. b05 赤丝裁衣人

**一句话**：量衣单上写的是尺寸，收款条上记的却是谁还能开口说话。

- 原案保留：Q27；稳定敌人 `bounty_b05_silk_murderer`。独立人类加害者；不是Q25已断契的维娅。
- 外形：灰白衣、小银剪胸针、贴着袖口的暗赤线。与维娅的脸、衣装主色、背架结构明显区分，别只改血条名字。
- 调查：失踪名单与量衣单＋诊所生前针伤 → 维娅封存证言排除结法混同 → 染料批号/收款条定位后院 → 胸针、非法收紧结与受害者衣料同场匹配。维娅作证不抹去她既有责任。

两招与打法：

- **量骨双刺**：手肘贴身、前臂两次短刺，第二击落点改变；两次命中属同一已命名动作，若接铜锚必须按真实动作ID分组。
- **闭口赤缝**：短蓄力后双手错开抽紧赤线，束缚短促生效，随后拆结收线恢复；线体自然弯折，有纤维散边，不是等距平行红条或完整规则绞笼。

反制：铜锚对实际同动作双击有适配可能，但首段额外代价仍付；普通输出与已有驱散也必须有胜利路线。不要把短刺、拘束、后续持续伤全部误计成可抵的同一次多段直伤。

结案：裁衣人被制止、被缚者得救，**赤染收款条与非法紧结样本**入档；140铜、旧28功勋拟归观镜、拟加30尘。此案最后开放仍不迫使玩家延后Q30，只需在离港确认时告知未结状态会保留。
