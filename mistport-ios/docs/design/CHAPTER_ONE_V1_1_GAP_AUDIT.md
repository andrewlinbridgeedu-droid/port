# 第一章开发实施规格 v1.1：现状差异审计

基准文件：
[`chapter-one-development-spec-v1.1.md`](chapter-one-development-spec-v1.1.md)

本审计只记录差异，不代表已经迁移程序。

## 已一致

- 战前编排、战斗自动执行的战术环方向。
- 每回合执行当前已开放并装备的全部普通卡牌；序列不限制每回合张数。
- 普通卡牌最多6张，终极技能独立。
- 通用状态、目标规则和数据驱动方向。
- 不设置专用破盾要求。
- 敌人严格前后排；当前 Unity 已使用固定前排与后排槽位。
- 单体目标死亡后需要按照规则重新选择有效目标。

## 明确冲突

### 旧钟区前五关

| 节点 | v1.1 规格 | 当前程序 |
| --- | --- | --- |
| 1-1 | 空壳钟卫；战后获得假面呢喃、第二卡位 | 教学及奖励流程仍包含旧版错步穿幕授予逻辑 |
| 1-2 | 两张牌排序教学 | 钟卫与钟核战斗 |
| 1-3 | 假象联动教学 | 地狱犬 |
| 1-4 | 钟卫与钟核；后排优先教学 | 两张牌教学 |
| 1-5 | 地狱犬；纸偶非强制提示 | 镜面替身与纸偶教学 |

### 技能数值与机制

当前 `MistportCombatCore` 的愚者技能仍采用此前冻结数值。例如：

- 错步穿幕当前基础倍率、减益加成与 v1.1 不同。
- 假面呢喃当前倍率与 v1.1 的70%不同。
- 纸偶代身当前仍有旧版固定护盾/反制实现，与“最大生命15%、持续2回合、首次吸收触发”不同。
- 身份错置、伪证烙印、镜影追猎和荒谬终幕均需按 v1.1 重新建立数据合同。

### 钟核

- 当前治疗使用旧版固定治疗展示与临时防御逻辑。
- v1.1 要求：同伴生命低于80%时治疗最大生命10%；每第3次行动使最低生命同伴防御提高10%，持续2回合。
- 当前演出可以保留，但触发条件、目标、数值和持续时间需迁移。

### 目标选择

- 当前战斗仍保留部分临时点击选敌与“上一目标”行为。
- v1.1 要求主要目标策略在战前配置，并在目标死亡后自动按同一规则重选。
- Unity 点击区域已改为读取模型锚点，但完整自动目标配置界面和运行时合同尚需统一。

## 迁移建议顺序

1. 冻结 v1.1 为唯一产品基线，并为配置增加 `specVersion`。
2. 先迁移技能、状态、资源和目标规则的数据合同。
3. 再重排1-1至1-5教学关及奖励，避免关卡依赖旧技能行为。
4. 迁移钟核和地狱犬能力。
5. 更新演出、战败建议和第一章100关内容。
6. 为旧存档增加版本迁移，不直接覆盖玩家进度。

## 当前状态

规格已归档，尚未按上述冲突重写关卡或战斗数值。敌人严格前后排机制可以直接保留并作为 v1.1 遭遇配置的坐标实现。
