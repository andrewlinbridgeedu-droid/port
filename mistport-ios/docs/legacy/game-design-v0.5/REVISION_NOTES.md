# v0.5 修订摘要：三人副本

本版本正式把标准战斗锁定为：

> 1名玩家主角＋2名程序控制AI队友的固定技能回合制副本。

“三人副本”不是三名真人玩家联机。玩家只完整操控主角，两名AI按照确定性规则、评分和有限搜索行动；相同战场状态必须产生相同结果。

## v0.5 新增

- 新增 `DUNGEON_COMBAT_SPEC.md`：规定20–35分钟副本结构、战斗间生命与冷却继承、共享复活、敌人数量、三人队伍数值预算和遗落物结算。

## 锁定的队伍规则

- 新手前两场战斗为单人；
- 第三场加入第一名保护型AI；
- 第一次阶段守关前加入第二名恢复或辅助型AI；
- 此后标准副本采用三人队伍；
- 每名AI只有3个普通技能、1个终极技能和1个固定被动；
- AI不使用玩家完整天赋树，也不装备玩家可交易遗落物；
- 玩家每轮先行动，AI读取最新状态后规划；
- 玩家每轮可以覆盖一名AI的行动；
- AI默认不能消费玩家保留的假象、错位等路径核心状态；
- 普通难度不要求固定坦克、治疗或唯一队伍组合；
- 常规五人队伍不进入首版。

## AI实现边界

- 不使用生成式AI；
- 不连接远程模型；
- 不使用完整AlphaGo或深层MCTS；
- 使用硬规则＋最多128组联合候选＋已公开敌方意图的一步模拟；
- 软预算10ms，Boss回合硬上限30ms；
- 超时返回当前最佳方案；
- 决策必须可复现、可记录、可自动测试。

## 三人副本数值方向

- 玩家主角贡献约45%–55%的队伍有效输出或关键机制价值；
- 两名AI各贡献约20%–30%；
- 敌人生命不按单人血量直接乘3，首轮倍率建议约1.9–2.2；
- 普通副本由普通遭遇、分支、精英、整备和首领构成；
- 三人全部倒地才失败；
- 每个副本拥有1次共享复活。

## 仍然废止

- 真人玩家匹配与实时联机战斗；
- 自由移动、A*寻路和大型实时战场；
- 常规五人队伍；
- AI队友完整天赋树和玩家级装备管理；
- 强制固定坦克、治疗或仇恨职业；
- 公会、签到、体力与付费战力。

## 被v0.5重新启用但重新定义的内容

v0.4曾废止“AI队友与团队副本”。v0.5重新启用的是本地程序控制的三单位回合制队伍，不是真人多人系统，也不恢复实时移动、网络同步或六人团队玩法。
