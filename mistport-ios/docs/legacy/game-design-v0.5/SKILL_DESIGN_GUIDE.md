# 《秘仪：雾港升序》技能设计指导

版本：1.0  
状态：正式上游设计基线  
适用范围：六条路径、普通敌人、精英、首领、遗器与技能演化  
首个验证对象：帷幕之径（内部代号：占卜家 → 愚者）

---

## 一、文档目的

本文件规定本项目所有主动技能、被动技能、状态、连段和数值设计必须遵守的共同标准。

本项目不采用抽牌战斗，也不把“预测敌人下一行动”作为所有新手必须理解的核心机制。战斗的主要乐趣来自固定技能之间的明确关系：

> 铺垫 → 转换 → 利用 → 终结 → 重建循环。

玩家初期只需要理解两步关系，例如“先施加状态，再使用强化攻击”；随着技能逐步习得，才自然形成三步、四步和完整连段。

技能系统必须同时满足：

1. 新手不研究攻略也能操作；
2. 熟练玩家能够通过顺序和配装提高效率；
3. 小怪不强迫玩家执行完整连段；
4. 首领不会无条件免疫路径核心机制；
5. 新技能扩展旧技能，而不是简单淘汰旧技能；
6. 数值优势主要来自理解和组合，不来自付费或无限堆战力。

---

## 二、技能系统的基础规格

### 1. 每条路径的核心规模

每条路径首个完整版本原则上包含：

- 9 个普通主动技能；
- 1 个每场一次的终极技能；
- 6–10 个被动技能或精通节点；
- 2 个主要路径状态；
- 最多 1 个玩家自身的短期强化状态；
- 最多 1 个路径专属资源，且不应在新手最初阶段同时出现。

战斗前配置：

- 从 9 个普通技能中选择 6 个；
- 终极技能固定占用独立按钮；
- 选择 2 个被动；
- 携带 2 件遗器。

MVP阶段可以先开放3–4个技能槽，随着玩家理解系统逐步增加到6个。

### 2. 默认行动规则

- 玩家每回合使用一个主要技能；
- 普通技能主要通过冷却控制；
- 首条路径不同时使用法力、怒气、连击点和多个叠层资源；
- 追加攻击、反击和被动触发不应形成难以理解的长自动链；
- 单次技能说明应尽量在三行核心文本内表达清楚。

### 3. 技能必须存在关系

技能不能只是十个彼此独立的按钮。每个技能必须至少与另外一个技能产生明确关系，例如：

- 为另一技能创造条件；
- 把基础状态转成高级状态；
- 消耗另一技能产生的状态；
- 保护玩家完成铺垫；
- 缩短下一轮连段等待；
- 针对特定敌人替代标准连段。

一个技能若既不创造条件，也不利用条件，还不能解决特殊问题，则应删除或重做。

## 三、通用连段语法

每条路径可以使用不同幻想和状态，但原则上应包含以下角色。

| 技能角色 | 主要职责 | 玩家感受 |
|---|---|---|
| 基础攻击 | 无条件可用，承担补刀和连段衔接 | 我总有事情可做 |
| 铺垫A | 快速施加基础状态 | 我开始准备 |
| 铺垫B | 补足状态并提供增伤或延长 | 两个技能可以合作 |
| 防御铺垫 | 防御的同时推进连段 | 防御不是浪费回合 |
| 状态转换 | 把基础状态变成高级弱点 | 前面的准备发生质变 |
| 利用技能 | 消耗部分高级状态进行爆发 | 我开始兑现优势 |
| 终幕准备 | 为终结技能创造最后条件 | 爆发即将完成 |
| 终结技能 | 消耗剩余条件获得高回报 | 完整连段有明确奖励 |
| 反制技能 | 针对增益、净化、召唤等敌人机制 | 我能根据敌人换打法 |
| 循环技能 | 减少冷却或修复被打断的节奏 | 连段失败后仍能重建 |
| 终极技能 | 快速建立条件或开启第二轮爆发 | 我主动选择关键时刻 |

一条路径不必为每种角色单独制作一个技能，但必须覆盖这些功能。

---

## 四、三种连段长度

### 1. 短连段：2个行动

用途：脆弱小怪、普通小怪、补刀。

标准形式：

> 铺垫 → 强化攻击。

目标：玩家在最初三场战斗内，不查攻略也能理解。

短连段应能够解决大多数低压力战斗，避免每只小怪都要求完整循环。

### 2. 中连段：3–4个行动

用途：强壮小怪、特殊敌人、阶段守关敌人。

标准形式：

> 铺垫A＋铺垫B → 状态转换＋利用。

中连段是路径核心玩法成形的节点。玩家应当感受到状态从“普通增伤”变成“特殊弱点”。

### 3. 完整连段：5–6个行动

用途：精英、区域首领、章节首领。

标准形式：

> 两次铺垫 → 转换与追击 → 准备与终结。

完整连段不能成为所有敌人的唯一正确答案。首领战通常允许完成2–3轮完整或不完整连段，而不是要求重复同一套动作五六次。

### 4. 组合自由度

每条路径至少提供：

- 1条标准爆发路线；
- 1条防御或稳健路线；
- 1条针对特定敌人的反制路线。

标准爆发可以最直观，但不能在所有战斗中都绝对最优。

## 五、状态设计规则

### 1. 新手只学习两个主要状态

一条路径的首个章节最多向玩家介绍两个核心敌方状态：

- 基础铺垫状态；
- 高级转换状态。

例如帷幕之径：

- 假象：稳定叠加、提供小幅增伤；
- 错位：由假象转换而来，可被追击和终结利用。

不要同时加入“假象、误兆、迷乱、破绽、错乱、因果标记、精神裂缝”等多个意义接近的状态。

### 2. 每个状态必须回答四个问题

- 从哪里获得？
- 有什么直接效果？
- 被哪些技能利用？
- 什么时候消失？

玩家长按状态时必须能够看到完整答案。

### 3. 状态层数与持续时间

MVP建议：

- 基础状态上限3–5层；
- 高级状态上限1–2层；
- 基础状态持续3回合左右；
- 高级状态持续2回合左右；
- 状态不会因界面未说明的隐藏规则突然消失。

### 4. 控制效果

普通敌人可以承受短暂混乱、沉默或停顿。

精英和Boss不应完全免疫路径核心状态。强控制对Boss可转换为：

- 下一击减伤；
- 附加效果失效；
- 增益失败；
- 暴露弱点；
- 行动延后，但不完全跳过阶段。

核心原则：

> Boss可以降低控制强度，但不能让玩家整套技能失去意义。

## 六、技能习得与教学顺序

玩家不能一开始同时获得10个技能。

推荐顺序如下：

| 成长阶段 | 新内容 | 教学目标 |
|---|---|---|
| 初始 | 基础攻击、铺垫A、防御铺垫 | 理解“挂状态后攻击更强” |
| 第二阶段 | 铺垫B | 发现两个铺垫技能可以快速达成条件 |
| 第三阶段 | 状态转换 | 理解基础状态可以变成高级弱点 |
| 第四阶段 | 利用技能 | 完成第一次中连段 |
| 第五阶段 | 终结技能 | 完成完整路径连段 |
| 第六阶段 | 反制技能 | 开始根据敌人调整配装 |
| 第七阶段 | 循环技能 | 处理长战斗和连段中断 |
| 第八阶段 | 终极技能 | 主动选择第二轮爆发时机 |
| 第九阶段 | 流派精通 | 不增加按钮，强化一种打法 |
| 最终阶段 | 规则突破被动 | 每场有限次数跳过一个条件或改变一条路径规则 |

教学必须遵守：

- 每次只增加一个新的技能关系；
- 先让玩家成功使用，再解释完整系统；
- 不在首次出现时展示全部未来升级；
- 推荐组合可以提示，但不得永久替玩家自动操作。

## 七、数值设计基线

以下数字是第一轮原型测试基线，不是发行版最终答案。

### 1. 基础参考值

- 第一章玩家攻击：100；
- 第一章玩家生命：1,000；
- 基础无条件技能：约100%–125%攻击倍率；
- 熟练使用完整组合时，平均每回合有效输出应比随意使用技能高约25%–45%；
- 熟练玩家不能因为记住一套顺序就比普通玩家强五倍或十倍。

### 2. 技能价值预算

| 技能类型 | 建议直接伤害 | 其他价值 |
|---|---:|---|
| 基础攻击 | 100%–125% | 衔接、补刀或生成短期强化 |
| 铺垫技能 | 40%–70% | 施加2层左右基础状态、轻度减伤或增伤 |
| 状态转换 | 70%–100% | 消耗基础状态、生成高级状态、轻控制 |
| 普通利用技能 | 140%–230% | 消耗1层高级状态、追击或减少冷却 |
| 完整终结技能 | 条件满足后300%–400% | 消耗剩余高级状态、无视部分防御 |
| 防御铺垫 | 低伤或无伤 | 约最大生命18%–22%的护盾，并推进状态 |
| 反制技能 | 50%–100% | 驱散、偷取、净化或替代连段入口 |
| 循环技能 | 可无伤害 | 减少关键技能冷却、清除自身状态 |
| 每场一次终极 | 不以直接伤害为主 | 约等于节省2–3个铺垫行动的总价值 |

伤害、控制、护盾和冷却减少必须共同计算。一个技能不能同时拥有最高伤害、最强控制、最低冷却和最广目标。

### 3. 冷却建议

| 技能类型 | 建议冷却 |
|---|---:|
| 基础攻击 | 0–1回合 |
| 铺垫技能 | 2–3回合 |
| 防御铺垫 | 4回合左右 |
| 状态转换 | 4回合左右 |
| 利用技能 | 3回合左右 |
| 终结技能 | 5–6回合 |
| 反制技能 | 4–5回合 |
| 循环技能 | 5–6回合 |
| 终极技能 | 每场一次 |

### 4. 完整连段目标

六行动完整连段的总倍率，第一轮可以控制在约900%–1,000%攻击力。

这意味着：

- 平均每行动约150%–165%；
- 玩家在铺垫回合仍有少量伤害或防御价值；
- 终结技能显著，但不能单独产生完整连段的全部收益。

## 八、敌人血量与连段匹配

敌人血量必须从目标回合数反推，而不是先随意填写数字。

以玩家攻击100、第一章普通防御为基线：

| 敌人类型 | 目标回合 | 设计要求 |
|---|---:|---|
| 脆弱小怪 | 1–2 | 可以直接攻击或短连段解决 |
| 普通小怪 | 2–4 | 需要一次铺垫＋强化攻击 |
| 强壮小怪 | 4–6 | 允许中连段完成 |
| 精英 | 6–9 | 能承受约一轮完整连段 |
| 区域Boss | 12–16 | 约两轮主要连段并处理机制 |
| 章节Boss | 16–22 | 两至三轮连段，阶段之间改变问题 |

第一轮血量区间可暂定：

- 脆弱小怪：140–180；
- 普通小怪：260–340；
- 强壮小怪：420–520；
- 精英：850–1,050；
- 区域Boss：1,800–2,100；
- 章节Boss：2,200–2,700。

这些数值必须根据实际技能倍率、防御公式和测试结果再次调整。

## 九、Boss适配规则

### 1. Boss不能只靠加血

困难Boss优先增加：

- 净化时机；
- 增益和反制窗口；
- 阶段切换；
- 特定状态持续时间变化；
- 迫使玩家改用稳健或反制路线的机制。

不优先使用：

- 血量直接翻倍；
- 全状态免疫；
- 无提示秒杀；
- 强迫携带唯一指定技能。

### 2. 核心状态必须有效

Boss可以：

- 把完整混乱变为25%伤害降低；
- 每阶段适应一次相同控制；
- 缩短高级状态持续时间；
- 清除状态，但为玩家留下补偿窗口。

Boss不可以：

- 永久免疫假象或错位；
- 让路径的转换技能完全无效；
- 因玩家使用正确连段而无条件反杀。

### 3. 连段中断应有恢复手段

若Boss会净化或打断状态，玩家必须至少拥有一种恢复方案：

- 防御铺垫重新叠层；
- 反制技能直接进入高级状态；
- 循环技能减少铺垫冷却；
- 终极技能重新建立条件。

## 十、六条路径的差异化语法

六条路径可以共享“铺垫—转换—利用—终结”的可理解结构，但核心状态和玩家决策必须不同。

| 路径 | 基础铺垫 | 转换 | 主要利用方式 | 战斗核心问题 |
|---|---|---|---|---|
| 帷幕之径 | 假象 | 错位 | 追击、终幕、跳过条件 | 怎样让错误成为真实弱点 |
| 潮忆之径 | 记忆残响 | 共鸣 | 治疗、复制或重写状态 | 哪段记忆应被保留或消耗 |
| 远征之径 | 防守与蓄势 | 动量 | 反击、破甲、连续行动 | 何时承受，何时爆发 |
| 炼成之径 | 材料与元素标记 | 合成物 | 爆破、构装、元素转化 | 如何用有限材料组合答案 |
| 誓衡之径 | 誓约与代价 | 裁定 | 伤害分配、封印、净化 | 愿意付出什么代价换取优势 |
| 星渡之径 | 坐标与连线 | 航路 | 穿透、换位、目标联动 | 如何安排目标之间的距离关系 |

禁止只把“假象”改名为其他状态，然后复制完全相同的技能顺序和数值。

## 十一、帷幕之径标准示例

帷幕之径的10个技能作为本项目第一套验证模板：

| 编号 | 技能 | 角色 |
|---:|---|---|
| 1 | 错步刺击 | 基础攻击、终幕准备 |
| 2 | 假面低语 | 铺垫A |
| 3 | 纸人替身 | 防御铺垫 |
| 4 | 身份错置 | 状态转换 |
| 5 | 伪证植入 | 铺垫B、后续增伤 |
| 6 | 镜像追击 | 高级状态利用 |
| 7 | 荒谬终幕 | 完整终结 |
| 8 | 反客为主 | 敌方增益反制、替代入口 |
| 9 | 幕后换场 | 冷却循环与容错 |
| 10 | 无名舞台 | 每场一次的快速启动 |

标准爆发：

> 2＋5 → 4＋6 → 1＋7。

防御路线：

> 3承受攻击并铺垫 → 2补足 → 4＋6 → 1＋7。

反制路线：

> 8处理敌人增益并直接制造错位 → 1＋7。

最终阶位的规则突破不是继续增加新按钮，而是：

> 每场战斗一次，把连段中一个缺失条件视为已经满足。

## 十二、技能升级规则

技能升级优先顺序：

1. 新增与其他技能的关系；
2. 增加新的使用场景；
3. 改变状态转换方式；
4. 提供流派二选一；
5. 最后才是小幅数值增长。

合格的升级示例：

- 纸人替身破裂后额外施加1层假象；
- 镜像追击不消耗错位，但冷却增加1回合；
- 荒谬终幕击败敌人后返还部分冷却；
- 反客为主面对无增益敌人时改为施加基础状态。

不合格的升级示例：

- 伤害从120%提高到125%；
- 生命提高3%；
- 同一技能连续进行五次纯倍率升级；
- 新技能完全替代旧技能的所有用途。

## 十三、技能UI与反馈

### 1. 条件提示

- 当某技能的强化条件满足时，技能图标出现清楚但不过度闪烁的边框；
- 点击技能时显示“当前将触发哪些附加效果”；
- 状态转换时使用明显的图标变化，而不仅是数字减少；
- 终结技能应在完整条件下出现独特音效和动画变化。

### 2. 连段提示

新手期可以提示：

> “目标已有4层假象，可以使用身份错置。”

熟练后提示可关闭。

游戏不应长期显示唯一固定箭头，避免把策略玩法变成按亮键操作。

### 3. 战斗日志

日志至少说明：

- 状态由哪个技能施加；
- 状态为何被转换或消耗；
- 某次额外伤害来自哪个条件；
- Boss为何只受到弱化版控制；
- 技能为何没有触发强化效果。

## 十四、常见错误

禁止以下设计：

1. 十个技能各自独立，没有组合关系；
2. 所有技能都是“造成伤害并附加一个状态”；
3. 每只小怪都必须执行六步完整连段；
4. 核心状态依赖隐藏概率命中；
5. Boss完全免疫路径核心机制；
6. 一个路径同时管理四五种主要状态；
7. 后期技能只是倍率更高，直接淘汰早期技能；
8. 六个装备槽永远只有一套正确答案；
9. 循环技能可以形成无限冷却重置；
10. 终极技能只是一个巨大伤害数字；
11. 技能说明需要阅读一整页才能理解；
12. 付费遗器或月卡能够跳过技能条件并提高战斗上限。

## 十五、测试指标

每套路径在进入正式美术制作前，必须通过无美术原型测试。

### 新手理解

- 大部分测试者应在三场战斗内主动使用一次两步短连段；
- 玩家能够用自己的语言说明“这个状态是做什么的”；
- 玩家失败时能指出是铺垫不足、技能顺序错误、防御不足还是冷却管理问题。

### 构筑健康

- 不应有一个普通技能在所有战斗中的装备率长期接近100%；
- 至少存在三套能够通关普通难度的六技能配置；
- 防御技能不能被所有熟练玩家视为纯损失；
- 反制技能在适合的敌人面前应明显优于标准爆发技能。

### 数值健康

- 随意出招与正确组合的平均效率差距约25%–45%；
- 普通小怪不需要完整连段；
- 精英通常承受一轮主要连段；
- 章节Boss通常承受两至三轮主要连段；
- 正确使用防御和控制时，普通Boss战结束后玩家应保留约25%–45%生命；
- 单一技能不应长期贡献整场总伤害的绝大多数，除非它是需要完整条件的终结技。

### 操作节奏

- 连续两个纯铺垫回合不能让玩家感觉“什么都没发生”；
- 完整六步连段的动画和确认时间不能拖慢到令人疲劳；
- 一场普通战斗目标为3–6分钟；
- 一场首领战目标为8–12分钟，特殊章节首领可略长。

## 十七、最终验收原则

一套技能系统只有同时满足以下条件，才可以进入正式内容生产：

- 新手只理解短连段也能正常推进；
- 中期玩家能够自然发现状态转换；
- 熟练玩家可以通过六技能配置形成不同流派；
- 小怪、精英和Boss分别使用不同长度的连段；
- 每个技能都有明确职责和至少一个组合关系；
- 核心状态在Boss战中仍然有效；
- 数值能够解释目标回合数和战斗压力；
- 新技能没有单纯替代旧技能；
- 最终阶位提供规则突破，而不是继续增加按钮；
- 付费系统不影响技能条件、伤害上限或构筑完整性。

本项目技能设计的核心标准是：

> 玩家可以不研究就开始玩，但研究之后必须明显玩得更聪明，而不是只按出更大的数字。
