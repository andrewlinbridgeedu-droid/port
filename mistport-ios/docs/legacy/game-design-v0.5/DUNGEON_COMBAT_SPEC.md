# 《秘仪：雾港升序》三人副本结构与战斗间状态规格

版本：1.0.0  
状态：内容与程序共同实施基线

## 1. 副本定义

标准副本由玩家主角与两名 AI 队友进入。一个普通副本包含：

1. 战前准备；
2. 普通遭遇；
3. 分支节点；
4. 精英或机制遭遇；
5. 短暂整备；
6. 首领战；
7. 结算与个人余波。

目标总时长：20–35 分钟。短副本可以压缩为 2 场遭遇 + 1 场首领。

## 2. 战前准备

玩家可以：

- 选择两名 AI 队友；
- 选择队伍战术；
- 配置主角技能、天赋和遗落物；
- 查看敌人类型、已知机制和推荐应对标签；
- 查看遗落物剩余次数、稳定度和可能反噬。

进入副本后，普通节点不能自由更换主专精。Boss 前整备点允许更换主动技能和战术，但不允许免费重置天赋或恢复遗落物次数。

## 3. 战斗间继承规则

| 项目 | 战斗结束后的处理 |
|---|---|
| 当前生命 | 保留，并恢复最大生命的 15% |
| 护盾 | 清除 |
| 普通增益/减益 | 清除 |
| 剧情诅咒 | 保留 |
| 技能冷却 | 重置 |
| 每场一次终极 | 下一场恢复 |
| 共享复活 | 整个副本仅 1 次，不恢复 |
| 次数型遗落物 | 按实际触发扣除，不返还 |
| 喂养型稳定度 | 每场结算后扣除 |
| 契约绑定战斗数 | 每完成一场有效战斗减少 1 |
| AI 队友倒地 | 战斗胜利后以 10% HP 返回 |

整备节点可以额外恢复 20% 最大生命，或选择一次材料/奖励，不同时提供全部收益。

## 4. 敌人数量

首版同屏上限：

- 3 名队员；
- 1–4 名普通敌人；
- 或 1 名 Boss + 0–2 名附属单位。

敌人超过 4 名时使用波次，不同时显示更多单位。

## 5. 三人队伍数值预算

目标有效输出占比：

- 玩家主角：45%–55%；
- AI 队友 A：20%–30%；
- AI 队友 B：20%–30%。

敌人生命不按单人值直接乘 3。首轮建议：

```text
party_enemy_hp_multiplier = 1.9 至 2.2
```

具体敌人生命按目标回合数反推：

```text
enemy_hp = expected_party_damage_per_round
         × target_rounds
         × mechanic_adjustment
```

建议目标：

| 敌人类型 | 目标轮数 |
|---|---:|
| 普通敌群 | 2–4 |
| 强壮敌群 | 4–6 |
| 精英 | 6–9 |
| 区域首领 | 10–14 |
| 章节首领 | 14–18 |

Boss 不应因三人队伍变成纯血量海绵。阶段变化、召唤和机制时间计入目标轮数。

## 6. 敌方伤害预算

普通难度下，正确使用防御、治疗和队伍指令后，章节首领结束时：

- 队伍总剩余生命目标：40%–55%；
- 至少 1 名角色可能进入危险线，但不应稳定全员满血；
- 完全忽略机制时，预计总承伤应超过队伍可承受上限。

单轮敌方总有效伤害预算：

```text
enemy_damage_budget_per_round
= party_total_effective_hp
× target_depletion_ratio
÷ target_rounds
```

普通章节首领建议 `target_depletion_ratio = 0.45 至 0.60`。

## 7. 角色死亡与失败

- 单位 0 HP 后进入倒地；
- 只要仍有队员存活，战斗继续；
- 三人全部倒地则战斗失败；
- 玩家倒地后由 AI 继续行动，并优先使用共享复活；
- 共享复活已用且玩家倒地时，AI 仍可完成当前战斗；
- 战斗胜利后玩家恢复 10% HP；
- 副本失败默认从当前首领或最近整备点重试，不强制重打全部普通遭遇；
- 已消耗的次数型遗落物在正常战败时不返还；测试模式可配置返还。

## 8. 奖励与路径差异

副本主目标和敌人基础相同，但玩家路径可以改变：

- 一个战前情报；
- 一个可选机制解法；
- 一种额外奖励；
- 一段个人余波。

不为六条路径制作六份完全独立副本。

AI 队友不参与可交易遗落物的独立掷取。所有战利品归玩家账号，由玩家决定保留、交易、喂养或分解。

## 9. 遗落物结算

副本中遗落物按以下时点处理：

1. 技能触发时扣除次数；
2. 单场战斗结束后扣除稳定度；
3. 自动喂养只读取玩家预先允许的背包材料；
4. 不自动从市场购买；
5. 进入失控状态后，下一场战斗开始应用负面效果；
6. 副本中途封印遗落物只在整备节点允许；
7. 绑定型遗落物在绑定期结束前不能卖出或丢弃。

## 10. 新手副本节奏

- 前两场战斗：单人；
- 第三场：加入保护型 AI；
- 第四场：加入恢复或辅助型 AI；
- 第一次三人首领战只教学“玩家先行动，AI跟随”；
- 不同时开放天赋树、AI设置和复杂遗落物喂养；
- 序列 7 才正式开放主专精与更多队伍组合。

## 11. 首版队伍选择

首版提供 3 名可选 AI，同一副本选择 2 名：

1. 保护型远征化身；
2. 恢复型潮忆化身；
3. 构装型炼成化身。

其他路径 AI 在后续版本加入。首版不要求为六条路径同时完成 AI 技能与平衡。

## 12. 验收标准

- 普通副本 20–35 分钟完成；
- 玩家主角贡献至少 45% 有效输出或关键机制价值；
- 一轮动画在 2×速度下不超过 4 秒；
- AI 不会稳定抢走玩家击杀和连段；
- 不带特定治疗或坦克 AI 也能完成普通难度；
- 队伍组合影响打法，但不形成唯一强制阵容；
- 副本失败原因可以在战斗日志中定位。
