# 联网经济与轻协作边界

版本：0.4 补充约束  
状态：产品与服务端实施基线  
来源：产品负责人于 2026-07-21 确认——本作是网游，玩家互动主要依赖经济与交易，并包含少量协作。

## 一、产品定义

本作是**单人战斗核心的轻网游**：主线调查、常规战斗、首领战与晋升试炼均可由一名玩家完整完成；联网负责让资源、供需、城市事件和玩家选择彼此产生影响。

“单人核心”不等于纯单机，“少量协作”也不等于传统多人副本。游戏不建立坦克、治疗、输出职责，不要求固定队，不以多人实时在线作为主线门槛。

## 二、首发联网支柱

1. **匿名中央交易所**：玩家出售非关键异路径材料、公开素材与部分遗器；购买后按规则绑定。
2. **组织储备与缺货委托**：库存不足时由系统动态发布委托、开放材料转换或个人保底调查。
3. **异步城市协作**：玩家向同一区域事件贡献物资、情报或调查结果，累积公共进度并改变短期世界状态。
4. **调查援助**：玩家可以留下有限的战前提示、已验证的敌方规则或一次性支援资源；接收者仍独立完成战斗。
5. **云存档与服务端库存**：可交易资产、铜币、订单、订阅状态和关键奖励由服务器权威保存。

## 三、允许的少量协作

- 共同完成无截止时间或宽松周期的城市事件；
- 为组织储备贡献材料，并获得不可交易的贡献记录或外观奖励；
- 发布和完成由真实供需触发的短缺委托；
- 分享首领规则情报、调查线索与非剧透战术标记；
- 在特殊活动中提供异步“回声支援”，改变一次战前准备选项；
- 后续验证双人弱同步调查，但必须允许单人替代方案。

## 四、禁止项

- 主线、晋升、区域演证或结局要求组队；
- 六人职责、AI 队友补位、坦克/治疗/仇恨体系；
- 实时多人 Boss 同步作为 MVP 范围；
- 公会签到、强制捐献、体力互送或错过惩罚；
- 玩家垄断主线必需材料；
- 出售金币、战力、晋升凭证、稀有掉率或付费跳过主线。

## 五、低人口与断网保障

- 系统市场始终为第一次晋升和当前主线提供基础供给；
- 任一晋升对真人市场的依赖不得超过设计文档规定的 40%；
- 长期缺货自动触发 3–5 换 1、组织储备或个人保底调查；
- 断网可进行已下载剧情战、训练与不产出高价值可交易奖励的内容；
- 服务器不可用时保留本地战斗摘要，恢复连接后再校验上传。

## 六、MVP 实施顺序

1. 先完成本地回合制战斗与固定奖励闭环；
2. 接入服务端库存、铜币与系统模拟中央资源池；
3. 验证匿名买入/卖出教学；
4. 加入一种异步城市事件和一种调查援助；
5. 只有在单人体验完整后，才评估双人弱同步原型。
