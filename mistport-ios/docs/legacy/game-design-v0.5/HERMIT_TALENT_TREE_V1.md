# 隐者三系天赋 · 首版实现

2026-09-10。现有底层职业 ID 保留 fool，天赋界面按用户命名显示隐者，未批量改动剧情称谓。

入口：角色 → 天赋 → 隐者天赋星图。每系六节点，每节点一点；结构为起点 → 左右分支 → 各自进阶 → 双分支汇合终点。可跨系投入，深层天赋必须满足图中全部前置。测试版预算9点；正式版每首次完成两项任务获得一点，上限9点。默认零分配，免费全部重置。点数来源后续可由教会经验系统接替，不能重复领取。

配置保存至本地存档；在新战斗创建时快照生效，战斗过程中不追溯改写。更新配置会使预加载战斗失效。开发测试列表使用同一已保存配置。

## 结算约定

同次天赋伤害百分比相加，再乘以已有技能/遗落物结算结果；防御穿透在伤害公式前应用。多目标分别使用自己的生命、防御与误认层数；第三次伤害技能只按施法计一次。强化下一击的状态不被无伤害铺垫技能消耗，同类状态刷新不叠层。幻影护盾、治疗与反击准备在真实攻击命中结算时触发，不在敌人起手时触发。天赋不额外延长或增加幻影承伤次数。

本次不改变技能解锁、出招时钟或原有冷却参数。秘兆的高层节点依赖后续剧情技能；点亮天赋不会提前发放卡牌。全部数值为首版平衡值，需要实战继续调节。
