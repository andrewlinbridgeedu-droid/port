# 一、教堂现在有两套并行内容

**调查副本负责稳定获取和剧情，百层长阶负责长期推进和构筑挑战。**

| 内容   | 原有调查线             | 新增百层长阶           |
| ---- | ----------------- | ---------------- |
| 规模   | 每教堂6节点，共18节点      | 每教堂100层，共300层    |
| 主要作用 | 教学、剧情、必要能力、稳定刷材料  | 持久推层、阶段卡点、检验构筑   |
| 进度   | 任务与调查节点           | 三座塔分别记录最高通关层     |
| 重复奖励 | 保留经验、材料、研究及既有随机掉落 | **重打已过层不再发资产奖励** |
| 首次奖励 | 教学物、任务奖励、调查首通     | 少量材料、阶段研究、收藏奖励   |
| 晋阶作用 | 保留原调查首领的演证资格      | 不要求爬满，也不替代调查首领资格 |

玩家的实际循环变成：

**推塔 → 遇到卡点 → 查看失败原因 → 换卡、改天赋或准备遗落物 → 再挑战。**

需要材料时，可以回调查副本；不想继续研究当前卡点时，可以去另一座塔。

例如：

> 守灯47层暂时打不过，观镜可以继续到58层，缄卷还停在31层。
> 三条进度互不覆盖，也不要求三塔保持同一层数。

这与原来的确定性获取路径并存，不会把“六次有效调查自选遗落物”改成必须爬到高层才能使用。

**校准等级、珍奇遗落物、某系专精都不是入场条件。**

# 三、100层不是100个连续上涨的血条

每座塔分成10章，每章10层：

**8个普通推进层、1个精英检查层、1个关底层。**

第5层是精英，第10层是关底。精英后的第6层安排较轻的承接战，给玩家突破以后继续推进的空间，而不是每过一层立即再碰一道更高的墙。

| 楼层     | 主要变化           | 推荐准备，不是硬门槛  |
| ------ | -------------- | ----------- |
| 1—10   | 识别单一机制         | 修习3级、8点天赋   |
| 11—20  | 双敌攻击节奏开始配合     | 修习5级、14点天赋  |
| 21—30  | 保护、治疗、护盾形成关系   | 修习7级、22点天赋  |
| 31—40  | 检查开场之后资源是否继续运作 | 修习10级、30点天赋 |
| 41—50  | 续航与伤害兑现的取舍     | 完整构筑，少量校准   |
| 51—60  | 多目标选择与资源分配     | 开始针对敌人调整物品  |
| 61—70  | 死亡遗留、召唤、战斗收尾   | 不能只看击败敌人速度  |
| 71—80  | 护盾、反照与延迟窗口组合   | 需要检查实际命中记录  |
| 81—90  | 多种已学机制共同施压     | 成熟构筑与充分准备   |
| 91—100 | 序列9终段挑战        | 高难可选，不是晋阶门票 |

## 三座塔各自的重点

| 塔        | 经常出现的问题            | 不代表什么             |
| -------- | ------------------ | ----------------- |
| **守灯长阶** | 护甲、连击、开场重弹、蓄力与后续攻击 | 不代表只能诡术通关         |
| **观镜长阶** | 周期盾、治疗、保护链接、反照     | 不代表必须装备身份错置才能过每一层 |
| **缄卷长阶** | 召唤、死亡后效果、审验与记录     | 不代表秘兆可以无视生存       |

目前300条配置由**42个普通／精英遭遇模板和30份分章首领参数**展开。能够复用已有敌人，但还需要逐章检查重复感，不能把“生成了300行数据”当成“完成了300层有趣内容”。

# 四、补上满级之后的有限成长

前一版到修习10级、天赋30点以后，基本属性就封顶了。因此，不能一边说“打不过就去养成”，一边不给玩家任何实际成长出口。

本次新增一个候选机制：**演证校准，最多5级。**

它属于教堂的“强化自身”，不是新天赋树，也不增加技能槽、天赋点、冷却收益或触发次数。

### 开放条件

完成Q08，且序列9修习达到10级。

### 数值与费用初稿

| 校准等级 | 本级费用：克朗／秘质 | 满修习等级下总生命 | 总攻击 |
| ---- | ---------: | --------: | --: |
| 0    |          无 |     2,400 | 100 |
| 1    |     200／24 |     2,448 | 102 |
| 2    |     320／40 |     2,496 | 104 |
| 3    |     480／60 |     2,544 | 106 |
| 4    |     700／88 |     2,592 | 108 |
| 5    |  1,000／128 |     2,640 | 110 |

每级固定增加48生命、2攻击。**满级总增幅各10%，不逐级相乘。**

【计算】五级累计需要：

**2,700克朗＋340秘质。**

按照原第3调查节点的重复底薪54克朗、7秘质，完全不计主线和首通奖励，**50次有效胜利足够支付全部费用**。这只是独立预算计算，不是要求每名玩家额外刷50次；已有任务和推塔收入都能抵扣。原调查路线仍有明确的基础收益和自选路径。

### 为什么不是无限强化？

因为无限属性增长会把后半座塔变成“等攻击数值超过门槛”。本稿只给有限补强，保留：

**搭配改善可能比升一级校准更有价值。**

但也不能直接宣布“10%很小，所以一定公平”。攻击增长还会提高技能、护盾及候选幻影耐久，生命增长也会改变生存边界。**综合效果必须重新测试。**

前案的2,400生命、100攻击测试，统一视为**校准0级**，不能拿来证明校准5级平衡。

### 防止投入失误

安全区可以降低校准等级，按**实际支付过的费用**全额退款，同时降低属性。战斗期间不允许升级或退款。

退款必须读取原始支付记录，不能按热更新后的更高价格退款，也不能退款以后继续带着原来的战斗属性。

**这项校准仍是新增候选设计，尚未接入Unity或验证强度。假面耐久重设计也没有因此自动获准。**

# 五、敌人怎样逐层变难

## 1. 生命采用整场预算，不是每只怪各翻一遍

十章的预置敌人基础总生命预算为：

**1,100、1,450、1,800、2,150、2,500、2,850、3,200、3,500、3,800、4,100。**

再按章内位置调整：

| 位置     | 生命预算处理       |
| ------ | ------------ |
| 普通推进层  | 在本章基础值附近小幅变化 |
| 第5层精英  | 基础预算×1.10    |
| 第6层承接战 | 基础预算×0.92    |
| 第10层关底 | 基础预算×1.40    |

【计算】第100层关底预置总生命为：

$$
4,100\times1.40=5,740
$$

**5,740是本场预置逻辑敌人的合计，不是有三只怪就各给5,740。**

护甲不随层数统一上升，攻击频率也不全局加速。已有召唤物、护盾和治疗另行计算，所以这个生命预算不能直接当作有效生命或战斗时长。

## 2. 伤害有上升，但不指数膨胀

十章分别使用原型伤害的：

**40%、48%、56%、64%、72%、80%、86%、92%、96%、100%。**

塔里的敌人是“演证投影”，不会修改原剧情敌人的数值。低层塔内猎犬可以较弱，**原有400伤害教学火球仍然保持400**，不能误用同一个配置把教学一起改掉。

这也意味着后期难点更多来自阵容、时机和机制组合，而不是把一次普通攻击堆成无法预告的秒杀。

## 3. 最多两个明确词缀

1—30层不加额外词缀，31—60层最多一个，61—100层最多两个。关底使用自身阶段参数，不再叠一套普通词缀。

| 词缀示例     | 明确变化                    | 保留的解法            |
| -------- | ----------------------- | ---------------- |
| **错峰入场** | 第二名敌人首次起手晚0.6秒，第三名晚1.2秒 | 只改变攻击关系，不新增攻击次数  |
| **短钟蓄势** | 执事重击前摇从1.8秒变1.6秒        | 削稳仍有效；必须重新验收动画时序 |
| **厚雾时段** | 青幽灵盾持续3.5秒，周期仍6秒        | 保留2.5秒无盾窗口       |
| **镜面延展** | 反照窗口2秒变2.5秒             | 每窗最多两次反照不变       |
| **提前传唤** | 首次召唤提前，之后周期不变           | 场上召唤物仍最多两只       |
| **余烬迫近** | 死亡后首跳从2秒变1.5秒           | 仍有预告，仍可准备护盾或存证   |

**词缀不能变成“所有控制无效”“幻影无效”或“只有指定稀有卡有效”。**

所有伤害仍由实际命中结算。这些前摇、首次起手和阶段参数必须与动画事件同步，不会重新引入固定0.2秒提前扣血。

# 六、三个真正有“卡点理由”的楼层

以下配置已经写入300层数据，但**解法尚待完整战斗验证，不能宣称换一张卡就必胜**。

## 守灯47层：门卫＋修女

配置为门卫1,400生命、修女1,050生命，总计2,450。词缀使修女首次治疗稍早到来。

它考验的是：**伤害是否真正打进目标生命，还是不断被保护和治疗抵消。**

两条基础方向：

| 方向     | 调整                         |
| ------ | -------------------------- |
| 拆开关系   | 换入剧情必得的身份错置，阻断保护与治疗        |
| 先处理保护者 | 用错步降低门卫护甲，先击败门卫，再处理不能自疗的修女 |

战后应该显示分担伤害、实际治疗量，以及隔离窗口内打进了多少伤害。

这里不应每次都提示“攻击不足，建议强化”。

## 观镜58层：青幽灵＋赤幽灵

青幽灵1,415生命、赤幽灵1,549生命，总计2,964。青盾约566，存在3.5秒、周期6秒。

它考验的是：**破盾和延迟伤害有没有落在合适的窗口。**

诡术可以通过戏势、接缝与撬锁手提高削盾效率；秘兆可以围绕无盾窗口、自动封卷或延后兑现安排输出。身份错置可以阻止同伴治疗，但不是唯一解法。

不能把盾越刷越长，最后悄悄取消原本承诺的无盾窗口。

## 缄卷73层：唤影者＋信差＋碎镜巡官

三名预置敌人总生命3,640。首次召唤提前，镜面期稍长，但召唤物数量仍有上限。

它同时考验：

**召唤物处理、死亡后安全，以及是否触发过多反照。**

基础方向可以用错步处理副目标、敛息保留收尾护盾；另一方向是在信差死亡前做好误认，让灰烬存证盒消耗证据取消余烬，剩余证据再按规则移交。

这一层必须专门回归此前发现的问题：

> **三名误认敌人同刻攻击，基础敌方行为取证不能产生三次成功触发。**

# 七、奖励预算已经重算，不直接复制原六层掉落表

## 1. 首通奖励

设章节数为 \(b\)，从1到10：

**每层基础首通克朗＝4＋b。**

秘质按章节给：

* 第1—4章：每层1。
* 第5—8章：每层2。
* 第9—10章：每层3。

每逢第10层关底，额外增加：

**20克朗、3秘质、1点该教堂研究。**

前30层分别每层给10、12、14经验；31层以后不再给经验。满级后的经验不会转给序列8。

## 2. 总量

| 范围      |  名义经验 |    克朗 |  秘质 | 研究      |
| ------- | ----: | ----: | --: | ------- |
| 单塔前60层  |   360 |   570 |  98 | 本教堂6点   |
| 单塔100层  |   360 | 1,150 | 210 | 本教堂10点  |
| 三塔共300层 | 1,080 | 3,450 | 630 | 三教堂各10点 |

**三塔的30点研究不能跨教堂混成五次自选。**

不计已有调查进度时，每座教堂10点各能兑换一次、剩4点，共三次可用自选；剩余进度继续与该教堂的调查研究合并。

## 3. 遗落物奖励仍有明确终点

塔不再每层进行一次10%遗落物抽取，以免300层首通把原随机池和经济总量冲掉。

塔通过阶段研究提供定向获取，随机掉落仍留在调查副本。

例如只靠缄卷塔前60层：

**570克朗＋98秘质＋6研究。**

可以支付300克朗、30秘质，在工坊制作R18禁售校样，剩270克朗、68秘质。原来“六次调查自选”的较短路径也继续保留，**不是把R18改成60层专属物**。

每塔30、60、100层另给档案、徽章外观和完成称号，不附带隐藏属性，不藏必要技能。

# 九、晋阶后怎样处理这300层

序列9的长阶作为**演证档案**保留，晋阶不会清空已经通过的层数。

正式记录使用玩家实际获得的序列9等级、校准、天赋、技能和遗落物，不借用序列8额外属性或新增触发器。

这样后半座塔不会因为晋阶一次就立即失去挑战意义，也不会要求玩家为了爬完100层而推迟晋阶。

同时保留三个边界：

**旧校准不再作为额外10%乘区逐序列叠加；不免费借给玩家未获得的物品；不同回访方式不能重复领取同一层首通。**

序列8本身仍应有新能力和新挑战，而不是把序列9塔继续复制成更大的数字。

# 十、UI、存档和开发验收

## 1. 塔页不展示一条长到难以操作的300层列表

每座塔按10层一章折叠，默认定位当前下一层。

顶部固定显示塔切换、最高层和当前章节；中部滚动楼层；底部安全区固定放置**“敌情”“调整构筑”“开始挑战”**。

返回角色页调整后，再回原来那一层。已过层清楚标注“重打无资产奖励”，避免玩家误以为没掉东西是出错。

## 2. 存档不能只保存一个最高层数字

至少需要保存：

| 数据          | 原因              |
| ----------- | --------------- |
| 每塔最高连续通关层   | 决定下一层入口         |
| 每层首通与领取标记   | 防重复奖励，避免配置更新后重发 |
| 战斗唯一回执      | 同一结果重复回调不重复入账   |
| 各教堂研究总进度    | 与原调查路径合并        |
| 校准等级和逐级实际支出 | 防旧价、新价退款套利      |
| 外观和完成记录     | 三塔同序号奖励不串账      |

塔ID使用类似 `tower.s9.L.047` 的独立命名，不与原调查节点`L04`混用。

旧玩家完成过全部剧情，也不能因此自动推断“已经爬完三座塔”。新增字段默认0层，原来的任务、遗落物、研究和天赋进度全部保留。
