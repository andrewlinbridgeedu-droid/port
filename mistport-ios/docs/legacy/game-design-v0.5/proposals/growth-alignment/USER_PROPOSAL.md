# 二、序列9推荐覆盖多久？

## 推荐：三段主线，原则上对应三张地图

**【建议】序列9覆盖“旧城区初识 → 后续调查深化 → 身份自证与晋阶收束”三段主线。**

| 阶段             | 地图状态           | 叙事与成长任务                          | 阶段结束时目标                |
| -------------- | -------------- | -------------------------------- | ---------------------- |
| **第一阶段：旧城区初识** | 现有第一张地图20关     | 玩家遭遇身份异常，获得现有技能，开始选择自己的战斗方式      | 推荐修习约Lv5，累计8点天赋        |
| **第二阶段：调查深化**  | 后续地图，关数与具体剧情未定 | 将线索与不同人物、机构联系起来；通过旧技能的新组合解决更复杂问题 | 推荐修习约Lv8，累计22点天赋       |
| **第三阶段：身份自证**  | 序列9收束地图，尚未设计   | 处理调查结论与身份选择，使用完整构筑完成一段实质性冲突      | 前中段获得30点，最终演证前自然达到Lv10 |

这里的三张地图是**推荐制作结构，不是已经存在的内容**。目前不适合写成“序列9一共60关”或“需要多少小时”，因为后续地图的探索、对话、战斗密度都还没有确定。

### 为什么推荐这样安排？

第一张地图第13关已经获得八张现有技能。后续成长不必继续靠频繁发新卡，而可以转向：

**同一能力在不同敌人关系中的用途、遗落物改造、天赋分支，以及剧情中对身份与证据的判断。**

同时，**30点不能在最终首领倒下后才发齐**。建议在第三阶段前中段获得，让玩家至少用完整构筑经历一个完整案件和一场重要战斗，再进入晋阶仪式。

若制作资源只允许两张完整地图，可以把“身份自证”安排在第二张地图后段。**保留三个成长阶段，而不是为了凑三张地图重复铺战斗。**

## C3. 三系天赋需要哪些适配？

### 诡术：不把候选破甲当成已有能力

可以优先接入“不同类别主动技能交替”的基础路线，让错步、假面及其他已核实技能提供输入。

但接缝与撬锁手的前提必须检查。若现有错步没有候选错位，则建议**由天赋明确新增自身专属接缝标记**，而不是更改现有错误状态的含义。

### 幻身：先解决不依赖耐久的完整路线

P2、P6等候选节点依赖耐久。若继续采用现有假面，就应重写这些节点的触发条件，例如围绕**真实承接、次数消耗、承接后的进攻准备**，而不是继续使用不存在的耐久归零事件。

这里有一个结构性问题：

> 每系恰好六节点、各五级，30点纯专精必须六个节点全部点满。
> 因此，只要其中两个节点因耐久待定而无效，就不能声称幻身30点专精已经可发布。

本稿建议优先完成**兼容现有假面的六节点版本**，耐久版作为独立候选比较。不能让玩家承担设计尚未决定的空节点。

### 秘兆：起步阶段必须同时有入口和出口

四点阶段不能得到一批无法兑现的证据，然后等第11关某张技能才能使用。

**【建议】秘兆第一层核心节点提供一个完整但简单的记录与自动兑现闭环**，其来源接现有伪证、误认或实际有效命中事件；后续天赋再深化提前兑现、转移和窗口选择。

具体接哪个事件，要由技能契约确认。旧N、旧A不能成为隐形依赖。

**这些是适配方向，不是本轮已经完成的十八节点战斗重设计。**

# D. 构筑与经济验收方案

## D1. 先验证解锁没有循环

应遵守以下依赖方向：

**现有主线获得基础能力
→ 主线里程碑获得天赋预算
→ 可选调查与塔提供练习、材料和侧向选择
→ 后续主线推进身份与演证
→ 晋阶。**

不允许出现反向依赖：

| 禁止的循环                    | 修正                       |
| ------------------------ | ------------------------ |
| 获得必要技能要先打过需要它的塔层         | 技能仍由既有主线获得               |
| 主线需要30点，但最后8点由高层塔发       | 全部30点由主线里程碑发             |
| 处理死亡余烬必须有R17，而R17只能从该难关掉 | 提供不依赖R17的基础解，R17是更有效率的选择 |
| 晋阶必须打塔，塔又按晋阶后属性调难        | 塔完全不进入晋阶资格条件             |
| 角色等级决定已得点数，点数又决定任务经验     | 等级、里程碑点数、任务完成分别记录        |
| 获得身份错置后，才解锁“授予身份错置”的任务   | 删除重复授卡任务，改为读取既有获得事件      |

后续主线的天赋里程碑也不应要求玩家“必须用三系各赢一次”。可以教授三系，但正式成长不能强迫改主修。

## D2. 同阶段的至少两种应对方向

以下是**需要验证的解题方向**，不是已证明必胜的配置。

| 阶段与敌人问题             | 方向一                 | 方向二                                  | 需要记录                             |
| ------------------- | ------------------- | ------------------------------------ | -------------------------------- |
| **第3—5关，开场火球与后续攻击** | 按现有教学先形成假面，再安排攻击    | 以纸人作一次容错，调整进攻顺序减少后续受击；不得被调成必须触发纸人才过关 | 幻影形成是否早于命中、真实消耗次数、纸人触发原因         |
| **第9关后，错误／误认转换**    | 沿现有造错与转换链安排顺序       | 使用不依赖完整转换链的攻击和承伤方向，在允许代价下直接解决目标      | 状态从何产生、是否成功转换、延迟是否作用于尚未起手的攻击     |

| **22点阶段，护盾与延迟窗口**   | 持续削盾或在无盾窗集中原生伤害     | 记录后兑现，或用其他已实现技能改变攻击节奏                | 伤害打盾／打生命比例，兑现落点                  |
| **30点阶段，召唤＋死亡遗留**   | 优先清理新增威胁，保留防守资源处理收尾 | 利用已验证的标记转移、存证或延迟能力减少投入浪费             | 召唤物累计存活时间、死亡后伤害、转移是否重复消费         |

记忆蛭、寄忆核心和第17—20关精英的具体数值没有提供，不能给它们凭空补上沉默、吞证据等机制。它们需要单独的敌人契约后，再加入同一验收表。

## D3. 配点测试不只测九套满级构筑

|  预算 | 必测投入类型               | 主要目的                 |
| --: | -------------------- | -------------------- |
|  4点 | 三系分别4点；至少三种2＋2配对     | 三系是否都有入口，早期混合是否完全亏损  |
|  8点 | 各系8点；三组4＋4           | 中层前置是否合理，两卡／四卡阶段是否不同 |
| 14点 | 单系14；9＋5；7＋7         | 深投与覆盖第二种问题是否形成真实取舍   |
| 22点 | 单系22；15＋7；12＋10      | 深层节点是否无条件压过混合        |
| 30点 | 三套30；三组20＋10；三组15＋15 | 完整九套构筑的优势、代价与最小调整空间  |

配点向量要明确，不能只写“诡术流”。例如沿用原前置结构时：

* 4点根节点投入可以是`4,0,0,0,0,0`。
* 8点单支可以是`5,0,3,0,0,0`。
* 14点单支可以是`5,0,5,0,4,0`。
* 30点专精就是`5,5,5,5,5,5`。

这些只是结构示例。节点效果改动后，旧构筑是否仍有价值必须重新测，不能引用旧向量合法性检查代替战斗结果。

### 两类测试必须分开

**固定条件对照：**同技能获得进度、同槽位、同等级、同预算、同敌人，比较合理基础物品与合理进阶物品。进阶组允许继续使用普通物品。

**自然成长回放：**从第1关开始，不借卡、不赠未获得遗落物、不默认30点，记录玩家在每个里程碑实际能组成什么。

指标至少包括：

**剩余生命、实际打进生命的伤害、护盾与治疗抵消量、资源过期与溢出、状态处理、死亡后损失，以及调整一张卡或一件物品后的改善。**

旧v0.4的49项检查中，胜利是测试输入，不是战斗模拟打出来的结果，不能继续引用为新成长路线可通关的依据。

## D4. 经验：必须重新分配，不能叠加旧Q奖励

### 明确建议

**主线保证修习成长；调查提供有限首通经验和可重复材料；塔不再提供经验。**

这是对v0.3、v0.4的明确调整，不是原有事实。

旧Q任务共2490经验，已经足够达到候选满级2340；旧三塔另外提供1080名义经验。若再叠加现有主线奖励，第一张地图过早满级是很现实的风险。

### 一个可对齐的经验预算示例

暂用候选2340经验满级作为归一化尺度，不代表当前配置已经是这些数值。

| 主线阶段         | 本阶段主线预算 | 累计主线经验 | 按候选等级表对应 |
| ------------ | ------: | -----: | -------: |
| 第1—5关完成      |     100 |    100 |      Lv2 |
| 第6—9关完成      |     140 |    240 |      Lv3 |
| 第10—16关完成    |     180 |    420 |      Lv4 |
| 第17—20关完成    |     220 |    640 |      Lv5 |
| 后续首次独立结案     |     360 |   1000 |      Lv6 |
| 后续调查收束       |     540 |   1540 |      Lv8 |
| 身份自证前中段      |     380 |   1920 |      Lv9 |
| 最终演证前的主线准备完成 |     420 |   2340 |     Lv10 |

这些预算包含**必经剧情调查、物证互动、任务交付和战斗首通**，不是所有经验都必须从打怪掉落。

也不要求找齐隐藏收藏才能达到目标。最终演证前就应自然达到Lv10，不能打完最后首领才补到其要求的等级。

### 调查与塔的经验处理

| 来源        | 建议经验规则                           |
| --------- | -------------------------------- |
| 必经主线      | 合计保证2340，待核对现有奖励后重新分配            |
| 18个调查节点   | 每节点首次10经验，总计最多180；具体分配可调整，但总预算固定 |
| 重复调查      | **经验改为0**，保留克朗、秘质、研究和原有随机物品      |
| 塔首通       | **经验改为0**，保留材料、研究与收藏奖励           |
| 重打塔       | 继续不发资产                           |
| 重复教学、回看剧情 | 不重复发成长经验                         |

按此示例，不爬塔、不刷调查的玩家仍能正常满级。即便做完全部可选调查，额外经验也只有180，不会把序列成长提前压缩到第一张地图。

**取舍需要明说：重复调查不再承担无限刷级。** 若团队坚持保留无限重复经验，就必须接受积极刷取者提前满级，不能同时保证等级严格跟随地图推进。

## D5. 材料不能成为普通主线的重复劳动门票

建议确立四条预算约束：

| 项目             | 主线保障                     |
| -------------- | ------------------------ |
| 必要技能与纸人        | 固定获得，不花钱、不随机             |
| 第一次工坊教学        | 免费完成一次真实操作，不要求先刷材料       |
| 14点、22点的基础构筑支援 | 交付可用物品或可用分支，不先给损坏物再强迫修复  |
| 首次晋阶仪式         | 主线准备环节提供本次用品，不要求额外刷出仪式费用 |

旧版160克朗＋24秘质的晋阶费用，可以作为经济比较参数保留；本稿建议**首次晋阶由剧情准备提供用品，不从玩家自由余额额外扣一笔必需费用**。这不是新通用货币，也不能转卖。

普通制作、自选遗落物、收藏和五级校准仍可以消费材料。原调查自选费用与六次进度可以继续作为候选，但需要合并玩家在新主线里已获得的资源后重新测。

### 校准放在哪里？

**【建议】最早在身份自证阶段、已达Lv10且获得30点后开放。**

普通主线最终战先按**校准0级、基础可得物品、不用消耗品**验收。校准作为可选高层与收藏期成长，而不是用来弥补主线数值调得过高。

满校准的生命与攻击各加10%仍只是候选；它还会影响护盾等派生量，不能视为只加一点普通伤害。

# E. 最小制作范围

## 第一批：保留真实前五关，接出一个小闭环

不重做已经存在的天赋界面，先核实沙盘中哪些功能已经完成、哪些仍需验收。

| 顺序                | 最小内容                          | 通过条件                             |
| ----------------- | ----------------------------- | -------------------------------- |
| **1. 现有规则核对**     | 前五关、八张技能、纸人、真实槽位变化；建立技能与状态契约  | 同名技能差异明确；假面版本明确；没有提前扣血或多目标重复结算   |
| **2. 天赋正式状态隔离**   | 利用已有三系五级界面，区分开发预算与正式里程碑       | 正式玩家不继承沙盘30点；预算、前置、级联、保存、安全区逐项验收 |
| **3. 第9关的4点阶段**   | 接入三系所有在4点预算下可投入的节点            | 不能只实现默认推荐路线；三系均有可用入口和出口          |
| **4. 一座教会、一项调查**  | 第7关后守灯入口、复用已学守卫机制的见习调查、稳定材料结算 | 不重复发错步，不依赖未实现破甲或耐久；不成为第8关前置      |
| **5. 第10关后的最小长阶** | 守灯第1—3层，敌情、准备、手动开战、永久首通       | 可以回角色页调整再来；失败不掉层；重复不发首通          |
| **6. 第16关的8点阶段**  | 接中层天赋、四格实战和多敌案例               | 验证专投与4＋4混合；不需要先做满300层            |

第1—3层是独立测试切片，正式开放完整第一章之前，还要完成并验证其精英与关底。**不能用无技能木桩替代关底后，宣布整章通过。**

## 第二批：完成第一张地图的统一成长

再接观镜、缄卷的基础调查，工坊第一次免费操作，以及第20关后的塔11—20层。

本批重点不是增加更多系统，而是验证：

> **一个完全不爬塔、不使用测试赠品的角色，能否保留现有剧情节奏，正常走完第一张地图，并带着8点有效天赋进入下一张地图。**

## 第三批：后续地图与满30点

先完成后续首次独立结案的14点阶段，再做22点和30点，不提前把尚未定义的后续地图塞满精确关卡编号。

到满30点阶段，三系十八节点都必须有正式可用版本，且九套满预算构筑需要重新使用**真实八张技能**建立对照。

300层仍是内容方向，只有通过相应能力、战斗和奖励验收的章节才正式开放。

# 本轮建议冻结与仍需核对的内容

| 可以作为下一版策划基线           | 仍待验证，不能写成现有事实           |
| --------------------- | ----------------------- |
| 第一张地图20关不等于序列9毕业      | 后续两段具体地图数量、关数与时长        |
| 前五关与现有八张技能获得时机保留      | 八张技能的完整效果、状态与事件契约       |
| 第9关后4点，第16关后8点        | 当时三系全部可投入节点是否已有效接入      |
| 后续主线依次14、22、30点       | 根节点适配、幻身非耐久版本、秘兆默认出口    |
| 教会调查与塔不承担必要技能和天赋的唯一来源 | 旧塔各层在新卡池、新点数阶段的真实难度     |
| 主线保证等级，塔不再给经验         | 当前20关实际经验与材料总量，需要导出后重分配 |
| 满30点以后仍留完整剧情段落        | 五级校准的综合强度与长期材料负担        |

**这版的核心成长轴是：第一张地图获得能力并形成初步选择，后续调查学会组合与取舍，身份自证阶段使用完整构筑作出决定。教会和长阶围绕这条主线提供选择与练习，而不是反过来把主线变成一串系统解锁按钮。**
