# 一、先确定教堂到底承担什么

## 1. 教堂是任务和挑战入口，不包办所有成长功能

教堂受理城市中的异常案件，提供调查许可、敌情档案和战斗入口。案件实际发生在港区、镜廊、邮路、档案馆等地点，不需要把所有怪物都塞进教堂建筑里。

| 场所       | 本系统中的职责                    |
| -------- | -------------------------- |
| **三大教堂** | 接取案件、选择挑战节点、查看敌情与奖励、追踪调查进度 |
| **角色页**  | 调整技能顺序、分配天赋、装备遗落物、保存构筑     |
| **行囊**   | 管理材料、损坏遗落物、已修复物品           |
| **秘术工坊** | 修复、定向制作、切换改造分支             |
| **咖啡馆**  | 消耗品、案件线索和隐秘交易消息            |
| **晋阶厅**  | 检查演证资格、执行仪式、选择新序列身份        |
| **商店**   | 系统售卖；玩家寄卖留待经济系统验证后开放       |

## 2. “扫塔”与“扫荡”分开

**本稿的扫塔，是逐层推进和重复挑战，不是一键跳过战斗。**

首版采用以下规则：

| 项目          | 规则                      |
| ----------- | ----------------------- |
| 挑战结构        | 每座教堂一条六节点线路             |
| 每节点内容       | 首版一场战斗，避免先做复杂多房间地城      |
| 开始战斗        | 每场由玩家手动开始               |
| 重复挑战        | 已通关节点可以直接重打，不必从第一层重新爬   |
| 战斗之间        | 恢复生命、清空战斗资源、重置冷却，允许重新配装 |
| 失败          | 不撤销之前已通关的节点             |
| 进入费用        | 无体力门票、无付费挑战券            |
| 自动连续挑战／一键扫荡 | 首版不加入                   |
| 无限层数        | 首版不加入                   |

这意味着，**玩家调整构筑的机会发生在每场战斗之前**，不是打完六层以后才终于能换一张卡。

若以后增加“连续远征、生命不恢复”的模式，应单独设计，不能偷偷把它变成普通教堂挑战的默认规则。

# 二、三座教堂：不同问题，不绑定不同天赋

名称暂定，后续可以替换，不影响配置ID。

| 教堂       | 主要调查方向         | 主要战斗问题         | 构筑倾向           |
| -------- | -------------- | -------------- | -------------- |
| **守灯教会** | 城门、巡逻、封印和失控守卫  | 护甲、开场重弹、连击、蓄力  | 考验破防、承伤与攻击节奏   |
| **观镜教会** | 身份错置、镜像和双名事件   | 护盾、治疗、保护链接、反照  | 考验目标选择、隔离和兑现窗口 |
| **缄卷教会** | 失名档案、异常邮件和遗留记录 | 召唤、死亡后效果、审验、延迟 | 考验资源保留、转移与战斗收尾 |

**不设置“诡术只能去守灯、幻身只能去观镜、秘兆只能去缄卷”。**

三条线路都允许三系专精及混合构筑参加。玩家不需要选定唯一教会，也不会因为参加另一座教会的任务失去已有奖励。

# 三、主线任务、教学技能和30点天赋如何接起来

## 1. 十个固定任务

沿用前案技能缩写：N留痕针、F错步穿行、M假面谕令、E伪造证据、H敛息、I身份错置、R镜像追击、A荒诞终幕。

**教学需要的新技能，应在接受对应任务时发放，而不是要求玩家先用尚未获得的技能完成任务。**

| 任务            | 教学或调查目标                | 必得技能／遗落物       | 天赋增加／累计 | 经验／克朗／秘质   |
| ------------- | ---------------------- | -------------- | ------- | ---------- |
| **Q01 入职演证**  | 单卡起手、实际命中，随后开放双卡       | 接受给N，完成给F      | +4／4    | 80／60／4    |
| **Q02 假面与纸人** | 承接次数在命中时消耗；区分主动幻影与致命保护 | M、R01纸人、R02补缝针 | +4／8    | 100／80／6   |
| **Q03 失名邮件**  | 误认与基础取证                | E、R05旧邮戳       | +0／8    | 150／90／8   |
| **Q04 自护演证**  | 护盾、净化、持续伤害             | H、R08咖啡杯       | +6／14   | 180／110／10 |
| **Q05 代签调查**  | 阻断同伴治疗或保护              | I、R09返潮信封      | +0／14   | 220／140／12 |
| **Q06 镜匠回声**  | 条件追击、开场以后继续配合          | R、R03两色票根      | +8／22   | 260／160／14 |
| **Q07 灰烬留证**  | 敌人死亡后仍可能有危险            | R17灰烬存证盒       | +0／22   | 300／180／16 |
| **Q08 闭卷演证**  | 主动封卷、自动结案、空案的代价        | A，开放进阶遗落物目录    | +8／30   | 350／220／18 |
| **Q09 联合调查**  | 完成任一教堂第5节点             | 调查完成记录         | +0／30   | 400／240／20 |
| **Q10 晋阶推荐**  | 完成任一教堂第6节点首领           | 晋阶推荐资格         | +0／30   | 450／300／24 |

金额均为**一次性任务完成奖励**，不因回看剧情或重复战斗再次发放。

Q01至Q08使用专门编写的教学战斗，不把完整强度的首领或多敌精英阵塞进单卡教学。Q01可以只装备N，完成后再进行N＋F的双卡教学。

Q09、Q10读取永久通关记录。已经打过对应节点的玩家，不必因为“当时没接任务”再打一遍。

## 2. 天赋点不跟随刷怪无限增加

天赋成长固定为：

**4 → 8 → 14 → 22 → 30。**

经验、重复挑战、首领重复掉落、研究记录，都不能突破这30点。

三条教堂线路也不能各自发30点。这里是**一个角色在序列9的共同预算**。

## 3. 假面相关奖励仍有版本前提

这份补充**不代表批准“部分承伤＋耐久”的假面重设计**。

R02、R06、R12、R14等物品依赖耐久参数。采用它们之前，必须先确认假面规则，并同步修改教学、效果和显示。

因此，完整奖励表目前是候选配置，不能直接导入现有正式版。最小开发闭环只使用Q01和L01，不依赖这些待确认物品。

# 四、经验升级：给明确成长，但不替代构筑

## 1. 序列9修习等级暂定1至10级

这是本次新增提案。**修习等级不是序列数字：升到10级不等于自动晋升序列8。**

| 修习等级 |  累计经验 |  基础生命 | 基础攻击 |
| ---- | ----: | ----: | ---: |
| 1    |     0 | 1,800 |   80 |
| 2    |   100 | 1,866 |   82 |
| 3    |   240 | 1,933 |   84 |
| 4    |   420 | 2,000 |   86 |
| 5    |   640 | 2,066 |   88 |
| 6    |   900 | 2,133 |   91 |
| 7    | 1,200 | 2,200 |   93 |
| 8    | 1,540 | 2,266 |   95 |
| 9    | 1,920 | 2,333 |   97 |
| 10   | 2,340 | 2,400 |  100 |

前案战斗基准“2,400生命、100攻击”，对应这里的10级角色。

每行是该等级的**基础属性值**，不是每次升级把整行数字再加一次。

## 2. 不要求靠重复刷经验才能完成主线

**【计算】十个主线任务共提供2,490经验，已经超过满级所需的2,340经验。**

挑战节点还会提供额外经验，因此正常推进应足以满级，不需要故意安排“打完剧情还差大量经验”的缺口。

但这只证明经验预算足够，**不证明自然成长下所有教学和首领都已经调到合理难度**。

经验在战斗结束或任务交付时正式入账，不通过中途击败一只怪升级回血。满级后，经验不储存到序列8，也不转换成可交易货币；结算页明确显示“序列9经验已满”。

# 六、每次打完到底给多少奖励

## 1. 固定底薪

三座教堂同一节点序号先采用相同奖励档位，避免某座教堂仅因产出更高成为唯一选择。

| 节点   |  经验 |  克朗 | 秘质 | 本教堂研究记录 | 随机遗落物       |
| ---- | --: | --: | -: | ------: | ----------- |
| 第1节点 |  50 |  32 |  4 |       无 | 无           |
| 第2节点 |  65 |  42 |  5 |       无 | 无           |
| 第3节点 |  90 |  54 |  7 |      +1 | Q08后开放10%机会 |
| 第4节点 | 110 |  68 |  9 |      +1 | Q08后开放10%机会 |
| 第5节点 | 135 |  84 | 11 |      +1 | Q08后开放10%机会 |
| 第6节点 | 180 | 112 | 15 |      +1 | Q08后开放10%机会 |

每个节点**首次通关额外增加40克朗、5秘质**，并发放上一表中的指定物品或资格。

首通额外奖励、普通底薪、随机遗落物、研究进度分别记录，不混成一笔不透明奖励。

**首领不是遗落物刷取的唯一入口。** 第3节点也能积累研究和随机获取进阶物品；首领提供更高固定材料、独特战斗与晋阶演证。

## 2. 怪物死亡可以掉东西，但不能重复计算

建议将固定奖励预算分给本场预置敌人，用于掉落表现；**总额始终等于关卡奖励表**。

例如L03有守卫和齿轮偶：

| 敌人     | 临时经验掉落 | 临时克朗掉落 | 临时秘质掉落 |
| ------ | -----: | -----: | -----: |
| 守卫     |     45 |     27 |      4 |
| 齿轮偶    |     45 |     27 |      3 |
| **合计** | **90** | **54** |  **7** |

通关时把这些临时掉落正式入账，**不能再额外发第二份90／54／7作为通关底薪**。

召唤物没有独立奖励预算；首领的两个身体和阶段模型也不能各掉一份首领奖励。随机遗落物按整场判定一次，不是每只怪判定一次。

## 3. 首通一条线路的总收益

**【计算】任一教堂六节点首次全通，固定获得：**

**630经验、632克朗、81秘质，另加指定物品与演证记录。**

加上全部主线任务完成奖励，则为：

**3,120经验、2,212克朗、213秘质。**

以上未计随机掉落和拆解，经验超过修习上限的部分不继续提高属性。

# 七、遗落物：有随机惊喜，也有明确终点

## 1. 三座教堂的随机池

完成Q08后，第3至第6节点开放以下随机池。

| 教堂 | 遗落物池                    | 每次有效胜利的概率       |
| -- | ----------------------- | --------------- |
| 守灯 | R06无客面具、R11警员哨扣         | 90%不掉遗落物，两件各5%  |
| 观镜 | R10单面镜片、R14断线提偶、R15无名索引 | 90%不掉，三件各为10%÷3 |
| 缄卷 | R16空白终页、R18禁售校样         | 90%不掉，两件各5%     |

每场最多一件随机遗落物。损坏态随机物品需要修复；教学和固定任务奖励直接给可用的修复态。

在Q08之前，中阶挑战可以累积研究记录，但不进行隐藏的随机抽取。奖励预览必须明确显示：**“研究进度可积累，进阶遗落物目录尚未开放。”**

## 2. 每六次有效通关，自选一件

每座教堂独立记录第3至第6节点的累计成功通关数。

**每累计六次，获得一次该教堂目录内的自选制作资格。**

它不是连续胜利要求，也不会每日、每周清零。随机先掉出物品，不重置研究进度。

计算方式为：

$$
可用自选次数=\left\lfloor\frac{累计研究进度}{6}\right\rfloor-已使用自选次数
$$

这个数是**调查完成后的领取资格**，不作为第三种可购买、交易的货币。

教堂显示研究进度和目录，制作仍在工坊进行。

| R17 灰烬存证盒 | Q07        | 无               |
| R18 禁售校样  | 缄卷六次研究自选   | 缄卷池             |

物品的来源人物和事件沿用原设计。教堂负责受理和交付，不会把邮差、镜匠、咖啡馆等人物从来源故事里抹掉。

## 4. 修复与制作费用

| 品质 | 损坏物修复      | 研究自选制作 | 随机重复物拆解 |
| -- | ---------- | ------ | ------- |
| 普通 | 100克朗＋10秘质 | 同额     | 2秘质     |
| 稀有 | 200克朗＋20秘质 | 同额     | 4秘质     |
| 珍奇 | 300克朗＋30秘质 | 同额     | 6秘质     |

**自选制作支付一次费用，直接取得修复态，不再收第二次修复费。** 费用不足时，不消耗自选资格。

修复没有失败概率。拆解重复物不要求先修复，也不返还克朗，避免“制作 → 拆解 → 得到更多材料”的循环。

教学独有物不允许永久误删；同名遗落物及其分支仍然不能重复装备。

# 八、一个具体例子：不用靠运气拿到R18

玩家已经完成Q08，想用禁售校样构筑，但还没有打过缄卷首领。

可以先开放A03，然后在该节点累计胜利六次。

| 项目              |      六次A03的结果 |
| --------------- | ------------: |
| 固定经验            |           540 |
| 固定克朗，含A03首次额外奖励 |           364 |
| 固定秘质，含A03首次额外奖励 |            47 |
| 缄卷研究进度          |             6 |
| 随机掉落            | 即使为0，也不影响自选资格 |

到工坊选择R18，支付300克朗、30秘质，得到修复态禁售校样，剩余：

**64克朗、17秘质。**

这个计算没有借用主线已经发的钱，也没有算前两层奖励。

已经拿过A03首通奖励的玩家，六次重复底薪仍有324克朗、42秘质，同样足够支付。

**【计算】六次10%随机机会，至少掉一件随机遗落物的概率只有46.8559%。** 换言之，仍有53.1441%的情况一件随机物都不掉。因此，六次自选必须是真正独立的路径，不能被随机掉落重置。

这里保证的是**六次有效通关后的获取路径**，不是保证六次尝试就能打赢，也不是已经证明A03对所有构筑都容易。

# 九、失败、掉落和结算必须一起设计

## 1. 敌人倒下，不一定立刻宣布胜利

特别是灰烬信差和已经飞出的火球。

战斗胜利至少需要同时满足：

**必要敌人已被击败、仍会伤害玩家的已生成事件已处理完、玩家仍然存活。**

不能先发奖励，再让死亡余烬把玩家判成失败；也不能为了提前弹结算界面，把已经飞出的攻击凭空取消。

无目标的友方伤害、剩余技能冷却和纯装饰效果，不需要继续拖住结算。

## 2. 不同结果怎么处理

| 结果    | 本节点奖励           | 首通／研究进度 | 已完成的旧节点 |
| ----- | --------------- | ------- | ------- |
| 胜利    | 正常发放            | 正常增加    | 保留      |
| 失败    | 不发放本节点奖励        | 不增加     | 保留      |
| 主动退出  | 不保留本场未结算掉落      | 不增加     | 保留      |
| 训练／调试 | 无正式奖励           | 不增加     | 不影响     |
| 断线／崩溃 | 恢复同一个战斗或读取已提交结算 | 不能重新掷奖励 | 保留      |

采用“胜利后正式入账”，是为了避免反复击败召唤物或部分敌人，再退出刷取收益。

代价也要明确：玩家失败时，本节点已击败敌人的临时掉落不保留。作为补偿，普通挑战不收门票、不扣装备耐久，也不追回之前节点的收益。

## 3. 防重复领取不是一个按钮状态

开发需要区分以下身份：

| 事件      | 建议唯一身份       |
| ------- | ------------ |
| 接受任务发技能 | 玩家＋任务ID＋接受奖励 |
| 完成任务奖励  | 玩家＋任务ID＋完成奖励 |
| 单次战斗底薪  | 玩家＋battleId  |
| 节点首通    | 玩家＋节点永久ID    |
| 研究自选领取  | 玩家＋教堂ID＋自选序号 |

发奖时，**资产变化、已领奖标记、首通、研究进度和随机结果必须一起提交或可恢复**。

尤其要防止两种错误：钱已扣但自选物没生成；物品已生成但资格没消耗。

奖励表更新也不能因为版本号变了，就给所有玩家再发一次旧节点首通。背包满时进入有唯一物品ID的溢出仓库，不是让玩家重新领取一次。

这些是本次补充的实施要求，**本包没有声称已经通过真实断线、并发或写盘中断测试**。

# 十、教堂UI应该让玩家知道“为什么去打这一层”

## 1. 教堂首页

保留四个入口即可：

**剧情委托、调查线路、研究目录、训练房。**

不要再额外堆一套战斗加点、遗落物强化和晋阶按钮，把所有功能复制一遍。

每个节点进入前必须能看到：

# 十一、晋阶和经济边界

## 1. 晋阶不要求打完所有三条线

序列8入口暂定：

| 条件   | 要求                  |
| ---- | ------------------- |
| 修习等级 | 序列9达到10级            |
| 天赋进度 | 固定里程碑已获得30点，不要求全部花完 |
| 剧情   | 完成Q10               |
| 首领演证 | 三座教堂任意一位首领          |
| 仪式费用 | 160克朗＋24秘质          |
| 操作地点 | 晋阶厅                 |

仪式不随机失败，不消耗已经获得的天赋点。

另外两位首领保留为可选挑战，不暗藏必须补齐的天赋点。玩家可以晋阶后回头补做，但旧序列经验不能预先无限囤给新序列。

## 2. 不增加一堆货币

常用经济资源仍然只有：

**克朗和秘质。**

经验是成长计数；教堂研究是调查资格；首领演证是永久状态。三座教堂不各发一种代币，也不各自产一种必需强化石。

本原型不出售挑战次数、研究进度、掉率、额外天赋或装备槽。关键物直接以修复态发放，纸人免费复原，普通主线以不使用消耗品也能通过为验收标准。

商店寄卖仍保留在长期场所分工中，但**不能把尚未验证的无限重复战斗产出直接接入公共市场**。先明确哪些物品可交易、材料如何回收，再处理真实交易经济。

# 十二、开发顺序：基础任务发奖提前，完整经济仍靠后

原P0任务书将首领和掉落经济放在P3。这里建议只把**最小任务与发奖闭环**前移，不把整个经济系统塞进P0。

| 阶段            | 本补充增加的工作                          | 不同时扩张的内容        |
| ------------- | --------------------------------- | --------------- |
| **P0**        | 保持原任务：五级天赋、预算、前置、级联、存档、安全区        | 不加入新首领和随机经济     |
| **P1期间的最小闭环** | 守灯入口、Q01、L01重复挑战、经验与材料、R04首通、结算保存 | 不依赖假面重设计、不做随机池  |
| **P2**        | 接入另两座教堂、中阶挑战、研究自选；运行完整构筑对照        | 不把未实现效果静默带进正式关卡 |
| **P3**        | 三场首领真实阶段、晋阶流程、长期产出测试              | 公共寄卖和付费加速最后再决定  |

最小版本的验收可以非常明确：

> 玩家接Q01，获得N，完成教学获得F和4点天赋；进入L01，手动开始战斗；胜利后获得经验、材料和首次R04；重新登录不重复发奖；再次挑战只发可重复奖励。

这条链路成立后，再扩展到三座教堂。**不要一开始就同时制作十八层、七种随机物、首领阶段和交易市场。**
