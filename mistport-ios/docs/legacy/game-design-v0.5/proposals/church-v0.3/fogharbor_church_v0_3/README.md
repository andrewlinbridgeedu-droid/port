# 教堂任务、分层挑战与奖励补充包 v0.3

这是《秘仪：雾港升序》隐者序列9的独立补充方案，不覆盖旧战斗脚本。

## 文件

- `CHURCH_SYSTEM_SPEC.md`：完整中文实施规格。
- `church_config.json`：3座暂定教会、18节点、10任务、10级经验表、18件遗落物来源及奖励配置。
- `build_config.py`：重建JSON的标准库脚本。
- `audit_config.py`：22项静态检查与预算计算。
- `audit_tests.txt`、`audit_results.json`：本次实际执行输出。

## 复现

使用Python 3.10及以上，只需标准库，不联网：

```sh
python build_config.py
python audit_config.py
```

## 范围限制

没有修改Unity工程，没有制作手机界面，没有实现或运行新战斗模拟，没有实现生产发奖事务。静态依赖图可达不代表关卡可通关；预算闭合不代表经济平衡成立。

教会名称、新经验曲线、关卡收益、10%随机掉率、6次自选及晋阶费用都是本次设计初稿。假面耐久相关物品保留原案的实验依赖，不能未经确认就进入现有正式奖励。

最小原型只做守灯入口、Q01、L01重复挑战及R04首通物，不依赖假面重设计、随机掉落或首领。
