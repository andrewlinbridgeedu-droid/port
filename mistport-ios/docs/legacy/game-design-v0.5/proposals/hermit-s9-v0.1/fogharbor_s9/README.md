# 《秘仪：雾港升序》序列9开发验证包

## 复现

需要 Python 3.10 或更新版本；只使用标准库，不联网。

```sh
python run_all.py
```

也可指定 `--outdir ./my_results`。

## 实际覆盖范围

1. `validate_s9.py`：17项定向检查，九套配点可达性，首次轮播、CD就绪队列、0.5秒动作锁、普攻填空，独立假面探针。
2. `run_all.py`：穷举单系全部46,656种配点向量，及三组机制对照的生命/攻击敏感性检查。
3. `combat_subset.py`：双方0天赋，8张基础技能，R01/R02/R04/R05/R17/R18，护甲、周期盾、治疗、死亡余烬。

**这不是完整游戏或九套30点构筑的全量模拟器。** 不含18个天赋的触发实现、全部18件遗落物、全部敌人AI、精英和首领阶段。守卫的控制印记在机制对照中关闭，保留护甲和攻击，以隔离护甲/生存问题；这也给错误搭配更宽松的条件。不能据此声称完成平衡验证、真实胜率测试或全量防循环测试。

## 调度契约

所有主动技能CD从起手开始；动作锁0.5秒，主动效果在起手后0.2秒生效。普攻伤害60，最短起手间隔1秒，动作锁0.5秒，起手后0.3秒命中。新就绪技能不打断进行中的动作。第一次按装备顺序；以后按(就绪时间,装备位置)排序。技能不存储多次充能。
时间用0.01秒整数刻度。CSV只列20秒内实际完成的命中/效果事件，不把尚未命中的动作计入伤害。
九套时间线不含敌方控制导致的停手；也不把衍生伤害、资源状态或敌人死亡当作已实现的全量计算。技能顺序与遗落物均采用设计正文的标准态。B2的R06使假面CD从3变5秒；其他构筑没有CD修改。

## 三组有限战斗对照

双方生命2400、天赋0点。基础组攻击强度100；高价值错误搭配组攻击强度125（额外25%，仅为抗属性优势压力测试，不代表出售属性）。
高价值组装备R18、R06、R15。R18按规则生效，C1有真实复印触发；R06/R15由于未装备假面/身份错置而没有效果，不是人为封禁遗落物。

## 文件

`timeline_20s.csv`：含普攻的九套动作/命中时间。
`mask_probe_events.csv`：逐击的幻影次数、耐久与生命损失。
`combat_C*_*.csv`：三组双方逐事件战斗记录。
`results.json`、`allocation_exhaustive.json`、`combat_subset_results.json`、`sensitivity.json`：机器可读检查结果。

## 必须继续验证的内容

18天赋和18遗落物全部实现后的触发链；三系30点/20+10/15+15的敌型分化；所有延后上限；多目标触发去重；阶段切换、死亡传递、已封卷与未封卷互斥；九套构筑60秒及更长时间线；战后解释是否准确；手机安全区与减点级联。
本包不能替代客户端的正式事件结算实现，也不能作为生产服务器代码直接部署。
