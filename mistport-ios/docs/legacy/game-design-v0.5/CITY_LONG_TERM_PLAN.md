# 雾港主城与长期玩法规划

日期：2026-09-10。状态：策划建议，供评审；不是全部已实现功能。

依据：当前主城、街区探索、教学战斗及 STORY_BIBLE。旧文档中的三人回合制、旧技能开放阶位不覆盖用户最新决定：当前战斗采用独立 CD，已有错步穿行、假面谕令等教学能力保留。九联邦是长期世界蓝图，首阶段只打磨雾港。

## 用户最新确定的功能分工（优先于下方早期建议）

- 教会：接取三大教会任务，打怪升级和强化自身。
- 行囊：物品管理。
- 商店：系统随机售卖各种物品，也支持玩家寄卖。
- 角色：调整卡牌顺序、分配天赋；每职业三系，目前只实现隐者。
- 咖啡馆：售卖不同消耗品，偶尔提供隐秘交易会消息。
- 秘术工坊：修复遗落物、改造技能，形成不同打法。
- 晋阶厅：演证、仪式与身份选择。

第一批开发是隐者三系天赋及UI，详见 HERMIT_TALENT_TREE_V1.md。以下咖啡馆人物支线等仍是可选远期建议，不替代上述定位。

## 1. 产品核心

让玩家逐渐成为这座城市认识的人。主循环：街头听闻 → 调查与探索 → 手动选择卡牌和出招顺序 → 战斗 → 找回记忆与遗落物 → 城市和人物发生变化 → 整理构筑 → 深入下一片雾区。

长期动力由三条线组成：案件真相、打法成长、人物关系。每条主线任务至少推进其中两项。城市变化应可见：雾退去、商铺重新营业、人物改变路线与对白、旧地点出现新证据。

## 2. 板块分工

| 入口 | 核心职责 | 首期内容 | 长期扩展 |
|---|---|---|---|
| 角色 | 决定这次怎样战斗 | 卡牌装备与排序、遗落物装备、技能说明 | 构筑预设、技能分支、路径演证记录 |
| 征战，建议显示为「旅途」 | 决定去哪里 | 街区地图、主线、支线、已完成案件回顾 | 联邦旅行、特殊调查、精英挑战 |
| 教会 | 理解异常及组织立场 | 档案室、失名者登记、记忆证据 | 组织信任、禁忌档案、分歧选择、界锚调查 |
| 商店 | 获取普通物资 | 明码标价材料、非关键补给 | 地区特色商人、可预期轮换、外观 |
| 行囊 | 查看持有什么及来源 | 遗落物、材料、剧情证物分栏 | 收藏故事、追踪用途、重复物处理 |
| 午夜钟咖啡馆 | 认识并关心城里的人 | 莫莉、玛拉谈话、案件余波、少量传闻 | 同伴私谈、跨章通信、人物支线结局 |
| 秘术工坊 | 改造已经获得的能力 | 鉴定和修复遗落物、一次明确技能分支 | 流派侧向改造、材料转换、外观修复 |
| 晋阶厅 | 完成身份与规则权限的跨越 | 展示晋升目标、逐步取得演证 | 仪式场景、悖论试炼、人生可能的取舍 |
| 邮局 | 让远方和旧人物持续存在 | 邮差投递、寄件与寻人支线 | 联邦来信、选择后果、异地委托 |

避免重复：行囊负责收藏，角色负责装备，工坊负责改造；教会负责证据与立场，晋阶厅负责晋升。界面可以跳转同一件物品，但不复制两套升级规则。

## 3. 咖啡馆的具体设计

进入后是一幅有人活动的室内场景：莫莉在吧台、玛拉有固定座位、窗边放报纸，角落来客随任务变化。点人对话，点报纸看城市新闻；主要操作保持在交谈、传闻、点单三类。

第一次到访：莫莉记得主角点过什么，主角却没有这段记忆，建立「被保存的人」主题。完成幽灵事件后，窗边原本空白的合照出现两个人，来客对是否认识他们说法不同。猎犬事件后，玛拉解释假面谕令的交付来由及保护限制；玩家在开战前必定取得教学卡，不能靠随机出售或关系门槛获取。

推荐第一条馆内支线「留给不归人的一杯咖啡」：莫莉每晚留一杯饮品，邮差带来一封地址正确、收件人却无人认识的信。玩家从街区证据确认人物身份，最终决定把记忆交回本人还是暂时保护证人。奖励以人物结局、证物与侧向遗落物为主，不扣住主线关键卡。

点单作为氛围与小额可选准备；战斗难度按未饮用增益也可通过设计。不能把每次出发前喝咖啡变成强制手续。关系以共同经历推进，礼物只做补充，不用无限送礼刷满。

后期在咖啡馆安排同伴会面，但暂不承诺新增队伍战斗规则。旅行到其他联邦后，雾港通过信件与短暂回访持续反馈。

## 4. 工坊与晋阶厅

工坊的奖励是打法改变。例：错步穿行可在后续获得「集中破防」与「扩大冲击」分支，互有代价；假面谕令可偏向保护稳定性或替身破裂后的反击。具体数值在命中时序稳定后测试，不提前承诺无限叠加 CD 缩减。分支允许低成本重选；核心教学版本保持稳定。

遗落物应有主人、来源和作用。修复过程展示破损物到完整物的视觉变化，并附一段可验证的记忆。避免只堆随机稀有度和加号等级。

晋升由个人凭证、路径演证、仪式材料、剧情试炼构成。演证奖励理解能力，例如让替身真正承受一次攻击、用误导保护某人；失败可重试。达到条件立即开启仪式，不按现实天数等待。

长期延续故事圣经「失去一种未曾活过的人生」的代价。选择前清楚交代会改变的关系或身份，不以隐蔽永久战力损失惩罚玩家。第一章结尾只完成一次有分量的晋升，不连续弹窗升阶。

## 5. 教会、邮局和街头人物

教会是有不同声音的组织。首期由档案员解释公开记录和个人证词为何冲突；后期教会内部出现不同立场。信任开放视角与任务，不另加一套强制货币。

邮差在可行走道路上覆盖已开放街区，并定期回邮局。新区域解封后扩展投递路线。关键邮件可在邮局领取，不能要求玩家追逐 NPC 才能继续主线。

小丑有固定表演点、观众与中场休息。第一次看是街头演出，第二次能发现纸牌或台词中的线索，后期揭示他用表演掩护某位失名者。观察应有轻量反馈，不要求现实时间蹲点。

街区至少十余名居民分散活动，重要人物有家、工作地和短路线。居民密度随地点变化，咖啡馆和市场略密、桥与背街稀疏；剧情人物与关键交互应保持容易寻找。

## 6. 第一章的内容节奏

区分章、区和任务节点。现有界面每区 20 个进度格，应将它们视为调查节点，不默认每格都是战斗。若保留五区框架，100 个节点是内容预算上限，不是必须灌满的战斗数量。

建议每区 20 节点：8 个主线战斗、4 个探索调查、3 个人物交谈、3 个支线事件、1 个区域首领、1 个收尾变化。比例可按剧情调整，节点必须有实际内容才计进度。

第一地区建议阶段：
- 1–5：雨夜、幽灵、猎犬及基础教学；人物和卡牌来源明确，开放咖啡馆基础对话。
- 6–10：邮局与首条完整人物支线；工坊开放鉴定，得到第一项侧向构筑选择。
- 11–15：教会档案交叉验证；组合机制与精英战，展示晋升所需的演证。
- 16–20：区域高潮、人物后果、城市变化和下一区线索。第一地区结束不等于整章晋升。

测试模式继续允许自由进入和退出；正式流程按剧情开放，两种状态分离，不因调试解锁而提前发放后期教学卡。

## 7. 战斗与奖励约束

保留当前约定：玩家手动开始，卡牌默认不选，由提示引导手动装备；初轮按所选顺序，之后按可用 CD 调度，敌人独立行动。冷却用顺时针阴影展示。伤害、飘字和血条与命中同步，死亡后切换有效目标。假面持续与消耗按实际命中规则处理，不沿用旧回合数直接清除。

教学卡必得且来源有剧情交代。主线关键物品不可随机掉落、不可误卖、不可被消耗材料配方吞掉。后续改造不得悄悄改变教学说明。

首期保留金币和一种普通秘术材料，剧情证物与晋升凭证单独记录且不可当钱花。已有其他资源先明确用途再开放。声望用于表现信任与区域许可，不兑换消耗后重新锁门。首次完成给确定性进度，重玩给适量补充，不要求刷旧关补齐主线晋升。

## 8. 视觉与交互

统一材质：深蓝皮革、旧黄铜、羊皮纸、深红封蜡。任务采用带封蜡的委托，档案采用纸页和证物，工坊采用工作台，晋升采用仪式场景。真实物件应承载明确操作，避免每个功能都做相同表格。

底栏是快捷入口；进入地点后第一次体验场景，常用动作可直接打开。主城保留少量当下相关的地点标识，不把所有远期系统堆满天空。资源足够清楚即可，不常用资源进入行囊查看。每处首屏突出一个主操作，其他内容渐进展开。

## 9. 制作顺序与验收

阶段 A：完成第一地区闭环。咖啡馆一条支线、邮局一条信件线、工坊一次鉴定、教会一次证据事件；保证从地图到战斗到回城不丢进度。验收：新存档关键卡全可得、旧关不提前露卡、解雾对应街区变化、NPC 不挡关键路线、命中时序正确。

阶段 B：第一章内容深化。填充其余地区、重复利用场景制作不同案件、形成少量可辨识构筑，完成第一次晋升。验收：每个区域至少一个独特问题、一段人物变化；每次晋升带来能力用途和世界反应。

阶段 C：扩展第二联邦。新异常规则、新证据形态、旧人物来信，复用已有城市系统。先验证一条路径的完整成长，再启动第二可玩路径。

阶段 D：按章节拓展九联邦蓝图。每章增加一个主要规则，不整套重做成长系统。玩家市场、多人、赛季等只在核心体验和维护能力足够后另立方案，不列为首发依赖。

数据上把任务事件、卡牌发放、NPC 对白、雾区开放及店铺状态关联到统一剧情标记。保留存档迁移和测试旁路。验收除代码检查外，必须用新存档完整游玩及旧存档回访验证。

## 10. 下一次实际开发建议

先做午夜钟咖啡馆的可玩样板：进入场景 → 玛拉回顾案件 → 莫莉交付匿名来信 → 邮局确认线索 → 街区完成调查 → 回馆出现人物及对白变化。完成这一条，才能验证主城是真正的故事枢纽，再复制到工坊、教会与其他地区。
