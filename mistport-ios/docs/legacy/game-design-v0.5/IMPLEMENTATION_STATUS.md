`TurnBasedBattleView.swift` 是 v0.4 过渡原型。它们仍可编译，但不再作为规则依据，
也不得继续增加预兆或“预测意图”玩法。等 `MistportCombatCore` 通过全部规则测试后，
再由适配层替换旧实现。
