# v0.4 修订摘要

本次修订补齐此前遗漏的纵切、战斗模型、旧钟区任务与目录文档，并清除它们与 v0.3 总纲之间的冲突。

## v0.4 重点修订

- 重写 `COMBAT_MODEL.md`：删除自由移动、A* 寻路、四方向行走、多队友职责与多人同步；改为固定视角 2D／预渲染 2.5D 回合制战斗。
- 战斗技术结构统一为模拟层、事件管线、数据层、表现层与 UI 层；所有高阶能力介入同一事件管线。
- 重写 `OLD_CLOCK_QUESTS.md`：旧钟区从 20 个实时任务压缩为 4 项主要调查、约 8 场回合制遭遇。
- 删除旧钟区团队副本、追击、护送、守点、自由步行与大型地图；改用调查地图和战前准备界面。
- 旧钟区只提供区域演证、身份推进和阶位 8“误导”预演；正式阶位 9→8 晋升仍在雾岬联邦后续区域完成。
- 将旧钟区角色压缩为 3 名核心 NPC，其他人物只保留一项功能、一段秘密和一次可见后果。
- 重写 `CHAPTER_ONE_FOOL_VERTICAL_SLICE.md`：明确它是第一章中的旧钟区纵切，而不是完整第一章。
- MVP 内容改为 8–10 个主动技能、4–6 个被动、8–12 件遗器、4 项主要调查、6 种普通敌人、2 种精英与 1 个区域首领。
- 将新手“前七次会话”落实到纵切任务：先频繁反馈，后缓慢开放系统；不绑定连续七天。
- 更新 `README.md` 的权威顺序和禁用边界；名称带 `(3)` 的三份文件被明确标记为旧版重复文件。
- 更新总纲、成长系统和故事圣经至 v0.4，并统一 MVP 不执行正式晋升或永久“未活未来”损失。

## 继续沿用的 v0.3 原则

- 新手阶段“反馈频繁，系统开放缓慢”；
- 即时反馈、会话成果和长期目标三层成长节奏；
- 成长可以变慢，但核心进度不能只剩现实倒计时；
- 正式晋升通过主动仪式与战斗完成后立即生效；
- 前期奖励逐渐从基础数值转向规则权限、身份和世界反馈。

## 已废止内容

以下内容即使仍存在于旧备份中，也不再属于正式设计：

- 实时移动战斗与大型自由探索战场；
- 随机组队、AI 队友、团队副本与六人终局；
- 坦克、治疗、仇恨和组队协同职责；
- 四方向行走资产与多人网络同步；
- 旧钟区 20 个实时任务和每区 20 任务结构；
- 第一地区直接完成正式阶位 9→8 晋升；
- 出售主线章节、付费战力或付费跳过等待。
