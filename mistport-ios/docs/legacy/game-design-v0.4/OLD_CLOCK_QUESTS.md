# 旧钟区：NPC与纵切任务设计

版本：0.4  
状态：MVP 正式任务蓝图  
所属：雾岬自由联邦，第一个叙事区域  
主题：记忆能够被复制，但人格不能被无损搬运

## 一、区域事件

旧钟每到午夜都会多响一次。第十三声会交换居民最近一天的记忆。

起初，人们只是忘记工作与约定；随后钟匠开始记得陌生人的家庭，救援机械开始执行死者的命令，少数居民则被拥有完整生活记忆的“连续体”取代。

镜潮宅邸主人瑟维安·洛正在把居民记忆存入机械旧钟。他当前并不想毁灭城区，而是试图在雾潮彻底抹去所有人以前“保存”他们。

问题在于：被保存的是能够描述一个人的资料，并不是仍能继续作出新选择的本人。

## 二、区域结构

旧钟区不制作可自由行走的 25600×25600 地图。区域使用一张可视化调查地图，由四个主要地点组成：

| 地点 | 主要调查 | 战斗场景 | 功能 |
|---|---|---|---|
| 钟楼广场 | 雨夜醒钟 | 广场、临时诊所 | 教学、安全据点、组织入口 |
| 雾灯街 | 被偷走的一天 | 街口、熄灭雾灯 | 双目标、意志条、NPC关系 |
| 齿轮工坊 | 第十三声 | 工坊、校时室 | 周期强攻、冷却保留、精英 |
| 镜潮宅邸 | 午夜归一 | 宅邸大厅、归一旧钟 | 区域首领与结局选择 |

地点通过调查地图选择，不要求玩家重复步行。首次进入可播放 5–10 秒环境过场，之后直接进入准备界面。

## 三、角色规模

### 三名核心 NPC

#### 玛拉·格雷——守钟人

- 功能：主线引导、区域历史、演证见证；
- 秘密：现在的玛拉是原版玛拉截至三个月前的记忆连续体；
- 人物弧：从证明“我就是原来的她”，转向承认“现在的选择也能建立新的我”；
- 结局作用：支持分还存档，但反对强迫两个版本重新合并。

#### 奥黛尔·芬——记忆医生

- 功能：恢复品、状态说明、伤员变化；
- 原则：不以记得多少判断人格是否完整；
- 人物弧：从尽量保存所有记忆，转向保护患者继续形成新记忆的能力；
- 结局作用：愿意监管封存方案。

#### 伊莱“白雀”——街区信使

- 功能：隐藏情报、材料来源、模拟市场教学；
- 私人动机：用情报交换弟弟被归一议会收走的记忆；
- 转折：曾向瑟维安提供玩家行踪，最终决定是否回来救人；
- 结局作用：根据玩家态度改变首领战的一项情报提示。

### 次要角色

- **维拉·铜枝**：机械医生，解释救援机械为什么失控；
- **诺恩·凯德**：巡官，必须接受女儿不再记得自己；
- **十三号**：受损机械犬，只负责寻找线索，不作为战斗队友；
- **瑟维安·洛**：区域反派与首领，相信完整信息足以重建人格。

次要角色只需要一项功能、一段秘密和一次可见后果，MVP 不为所有人制作长关系线。

## 四、四项主要调查

### 调查一：雨夜醒钟

**目标**：在第十三声后救出玛拉，并确认敌人下一行动可以被读取。

战斗：

1. 空壳钟匠——明确单体攻击；
2. 发条兽——一回合蓄力扑击。

解锁：

- 基础攻击；
- 危险预感；
- 首个被动；
- 基础遗器“迟秒怀表”。

叙事结果：玩家发现第十三声交换的是记忆归属，而不是简单删除记忆。

### 调查二：被偷走的一天

**目标**：从两名拥有同一段记忆的居民中找出正在被寄生者，并保护奥黛尔完成诊断。

战斗：

1. 记忆蛭与空壳钟匠——教学目标优先级；
2. 校准傀儡——教学护甲与意志的区别。

解锁：

- 灵性闪避；
- 弱点判断强化；
- 第二件遗器槽；
- 一次安全的材料出售教学。

叙事结果：奥黛尔确认“拥有正确记忆”不能单独证明人格连续。

### 调查三：第十三声

**目标**：进入齿轮工坊，阻止校时设备把居民记忆压缩成统一格式。

战斗：

1. 镜面替身——外观相同、意图不同；
2. 精英“追钟人”——每三回合发动强攻，要求保留冷却。

解锁：

- 简易占卜；
- 预兆资源；
- 一个技能二选一；
- 区域核心线索“第十三声录音”。

叙事结果：伊莱承认自己曾向瑟维安出售情报，但声称这是换回弟弟记忆的唯一方法。

### 调查四：午夜归一

**目标**：进入镜潮宅邸，停止归一旧钟，并决定如何处理已经保存的居民记忆。

前置遭遇：

- 真假守卫组成行动队列；
- 玩家必须识别哪一个意图会触发旧钟强化。

区域首领：瑟维安与归一旧钟。

奖励：

- 旧钟区区域演证；
- 一份权柄回声；
- 预兆记录；
- 组织身份从“受观察者”向正式调查者推进；
- 一次阶位 8“误导”训练预演。

## 五、敌人原型

| 敌人 | 行动特征 | 教学作用 |
|---|---|---|
| 空壳钟匠 | 攻击与防御交替 | 读取基础意图 |
| 发条兽 | 明确蓄力扑击 | 闪避时机 |
| 记忆蛭 | 寄生并转移状态 | 目标优先级 |
| 镜面替身 | 外观相似，意图不同 | 不凭外观判断 |
| 校准傀儡 | 护甲与意志双层 | 先破意志再控制 |
| 吞灯幼体 | 隐藏一项非关键信息 | 有限信息处理 |
| 精英追钟人 | 周期强攻与假动作 | 冷却保留 |
| 精英记忆裁剪师 | 删去一个短期增益 | 状态管理 |

## 六、区域首领

### 阶段一：校时

三座护卫钟依次宣布攻击、强化和治疗。玩家必须判断优先目标，而不是平均输出。

### 阶段二：统一时刻

瑟维安记录玩家上一回合的行动类别。连续两回合使用同类行动会让他获得强化，迫使玩家在攻击、防护、削意志和蓄积预兆之间切换。

### 阶段三：第十三声

每四回合准备致命校时：

- 灵性闪避可令其空击；
- 危险预感可降低伤害并产生预兆；
- 击破意志可令其延后一回合；
- 满预兆的预兆记录可打断并开启暴露窗口。

普通难度不伪造致命技能图标。高难度只加入一次能够通过姿态和时间轴识破的假意图。

## 七、区域结局

击败首领后提供三个短选择：

1. **摧毁存档**：居民无法取回丢失记忆，但不会继续被复制；
2. **封存存档**：保留找回记忆的可能，同时留下未来被滥用的风险；
3. **分还存档**：把碎片交还关联者，部分人将同时拥有矛盾人生。

选择必须改变：

- 安全据点 NPC 对话与人数；
- 旧钟的场景状态；
- 后续盐栈区的一名支援角色；
- 一项万火结局信任条件；
- 模拟市场中一种记忆材料的供应。

选择不阻挡进入下一区，也不存在唯一正确答案。

## 八、新手成长与奖励节奏

| 时间点 | 玩家反馈 |
|---|---|
| 前 10 分钟 | 第一次读懂意图并成功防御 |
| 20–30 分钟 | 解锁灵性闪避或首件遗器 |
| 第一次主要调查结束 | 安全据点、NPC回应和明确线索 |
| 第二次主要调查结束 | 意志条、第二件遗器槽、首次物资交换 |
| 第三次主要调查结束 | 预兆资源、技能二选一、区域核心秘密 |
| 区域结束 | 区域演证、身份推进、结局变化与误导预演 |

奖励频繁但系统开放缓慢。旧钟区结束前不开放完整技能树、自由市场、复杂重铸或正式晋升配方。

## 九、重复游玩

完成区域后开放“旧钟回声”：

- 使用规范化属性重打区域首领；
- 可选择一种已公开的战斗变体；
- 奖励普通素材、技能粉尘和外观碎片；
- 不重复产出区域演证或剧情关键物；
- 不设置每日次数、体力或限时截止。

## 十、路径差异边界

MVP 只制作帷幕之径。未来其他路径进入同一调查时，可以改变一项战术解法或调查信息，但不制作独立地图，也不改变主线结局资格。

例如：

- 潮忆之径提前揭示记忆来源；
- 远征之径把承受强攻转化为反击资源；
- 炼成之径改变护卫钟的元素关系；
- 誓衡之径为双方设定一个对称条件；
- 星渡之径调整两个敌人在时间轴上的距离。

这些差异必须适配回合制事件管线，不引入实时移动、路线追逐或组队职责。
