# 角色成长与序列晋阶

状态：第一章正式规则  
目标：每个大区都有可感知进步，但路径能力始终比装备数值更重要。

## 三层成长

1. **路径天赋（身份核心）**：决定六条路径的玩法与团队职责。完成区域首领后取得“权柄回声”，解锁或改变被动规则。约占有效成长的 35%。
2. **技能演化（打法变化）**：主动技能不是只加倍率，而是加入弹射、标记、位移、护盾转化、环境互动等新机制。约占有效成长的 35%。
3. **共鸣武装（构筑选择）**：武器、护具与仪式器提供基础数值、元素、冷却和套装组合。旧武装可以重铸，不以整套淘汰制造重复劳动。约占有效成长的 30%。

商店只出售外观、剧情章节和便利型存档位；不直接出售战力、晋阶材料或权柄节点。

## 每区20任务的成长节奏

| 任务节点 | 奖励 | 玩家感受 | 敌人升级方式 |
|---:|---|---|---|
| 1–4 | 基础材料、技能熟练 | 熟悉新区域与怪物预警 | 普通移动、单一攻击 |
| 5 | 武装共鸣 | 武器获得一个可选词条或形态 | 首个区域首领、明确弱点 |
| 6–9 | 技能点、抗性材料 | 建立初步流派 | 远程、护甲、成群协作 |
| 10 | 技能进化 | 一个主动技能改变机制 | 双机制首领；开放本区团队副本 |
| 11–14 | 专精材料 | 为困难敌人调整构筑 | 控场、治疗、召唤、地形伤害 |
| 15 | 天赋觉醒 | 路径被动获得规则级变化 | 多阶段首领、移动场地 |
| 16–19 | 仪式证物 | 组合武装、技能与天赋 | 克制玩家惯用打法的精英 |
| 20 | 晋阶演证 | 取得本区的一项序列证明 | 权柄型终区首领与剧情选择 |

第一章五个大区各提供一项演证。玩家集齐五项演证并完成雾岬上城终局后，才举行序列9→序列8仪式。团队副本提供外观、横向流派组件和额外剧情证据，不是晋阶门票。

## 六条路径的成长方向

- 愚者·假面：假目标 → 标记引爆 → 身份交换 → 分身协攻。
- 女祭司·潮听：弱点揭示 → 记忆治疗 → 预知首领技能 → 梦境领域。
- 战车·远征：冲锋破甲 → 格挡反击 → 护送光环 → 不退阵线。
- 魔术师·炼成：机关炸弹 → 元素转化 → 战场构装 → 等价领域。
- 正义·誓衡：护盾 → 代价转移 → 禁用规则 → 临时誓约领域。
- 星星·星渡：位移射击 → 折跃连线 → 可能性标记 → 群体航线。

数值增长负责让新怪物“打得动”，机制成长负责让每个新区“打法真的不同”。若只有装备等级，玩家会觉得是换皮刷战力；若只有技能而没有基础数值，掉落和养成又会失去意义。
