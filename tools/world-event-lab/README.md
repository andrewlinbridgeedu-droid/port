# 雾港世界事件推演室

本地设计工具，打开后默认显示已验证结果和首测建议，不需要用户调参。世界走向、物资与投资、货币收支分为三个细看页面；高级参数默认折叠。所有情景只影响内存计算，不连接游戏存档、正式奖励或外部账户。

## 运行

在项目根目录运行：

```sh
python3 tools/world-event-lab/server.py
```

访问 http://127.0.0.1:8876 。仅监听本机回环地址，无第三方前端依赖。`server.py --port 其他端口`可解决端口占用。服务器启动后保持终端运行。

也可双击本目录的 `启动推演室.command`。该入口检查本机同版服务，存在则直接打开；不存在则在当前终端启动服务。不会修改 Chrome 账号或游戏数据。

## 复算

```sh
python3 -m unittest discover -s tools/world-event-lab -p 'test_model.py' -v
python3 tools/world-event-lab/audit.py
```

结果写入 [验证目录](../../docs/development/world-event-lab-20260927/)。页面可以导出当前完整参数、条件概率、项目账和货币轨迹JSON。重新输入相同参数与种子可以复算。

## 三种计算，不能混称一个真实市场

1. **事件：**公共行动固定种子抽样，普通1/高难2分；至少4名成功账号和实际工程验收才取得资格。按公共领先分配6/4、同分5/5；核心用动态规划精确计算条件概率，三处节点后转人物决战，同轮双边结算，首次死亡后停止。每次机会使用不同候选；到场率与各阶段成功率是独立假设，不是真人数据。
2. **项目：**安装12套需要钱和货同时具备。运营用有限客户钱包、付费订单和原料上限，逐日核对出资/客户现金＝项目余额＋卖家收入＋经营分配＋外部净流出。净利润不等于分红；本金回收另外记。推荐开机检查把前7日输入视为已付款且原料落实的预订单，必须足以覆盖调试成本；现实中不能拿意向或点击量代替预订。
3. **货币：**用行为输入计算系统发行与真销毁，单独比较两种上线人群假设：每天同一批活跃账号、每天独立活跃。每7/14日一次按唯一账号领取概率计算，包括观察末尾不完整窗口。此表没有内生价格、个人钱包负担、迁服已有余额、信贷或财富分布，也不会自动叠加项目表中的同一笔支出。

当前首测建议：普通目标85%成功仅作准备好的普通玩家的设计目标，组具报价60铜、经济成本34铜和主动制作时间6分钟仍为待实测候选；并未改变正式配方或奖励。

首测规则与补救办法见 [规划定案验证](../../mistport-ios/docs/game-design/chapter-one-30/WORLD_EVENT_FIRST_TEST_DECISION_20260927.md)。
