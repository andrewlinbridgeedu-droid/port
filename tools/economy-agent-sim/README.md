# 2000独立账户经济实验

这是离线仿真，不是游戏实现或服务器压测。每名玩家有独立钱包、库存、角色资格经验、专业熟练度、配方知识和装备拥有状态。自由P2P仅在模拟器中启用，不修改真实游戏。

## 可复现

```sh
python3 tools/economy-agent-sim/extract_inputs.py
python3 -m unittest discover -s tools/economy-agent-sim -v
python3 tools/economy-agent-sim/run.py --out docs/development/economy-agent-sim-20260926/year1 --days 365 --workers 4
python3 tools/economy-agent-sim/run.py --out docs/development/economy-agent-sim-20260926/year2 --days 730 --only baseline,supply_2x,supply_3x,repeat_best --workers 4
```

第一轮28组配置，各5种子（101、211、307、401、503），每组2000账户、365周期。第二轮事先指定基准、两倍供给、三倍供给、最高已通关重玩四组，各5种子、730周期。不是看到结果后只延长表现最好的种子。全部运行的配置和程序哈希写在manifest；comparison为种子均值、极值和失败检查。

## 输入依据

`source_inputs.json`由当前Swift源码提取Q1–30、F1–100、B01–B10及源文件哈希：主线首通2280、塔首通1700、十通缉1060；重玩逐关按原35%下限8公式，Q30为105铜。塔材候选从实际楼层所有波次怪物集合选取，不再抽一个假定物种权重。玩家是否获胜、多久晋度、多久重玩仍是假设，不能称为测得行为。

保留28+28/7周期测试默认，并对14/42等做对照。材料映射沿用Pro候选；每胜2/4/6单位用于供给敏感性，不修改正式掉落。底料库存、产能、生产成本、卖价沿用v2默认并成倍比较。NPC生产支付到资源账户，玩家买底料转给底料商；钱没有凭空恢复。事件托管来自12万铜初始国库，采购即消耗实物、剩余款退还；没有战斗工资或日常无限收购。

四职业各4档试验配方。中间两档是真正缺失目录的占位设计，沿用基本产品用途，不能直接导入游戏。等级2/5/10/15、熟练度0/20/45/70、确定性+3/+2/+1/+0。第一阶段只雾潮解锁织造最高档；另外三职业最高档未开放，消费者可能出现高档未满足需求，这也是观测结果，不自动送配方。每名玩家目前专精一种职业，并非四职业完整行为模型。

## 交易与会计

- 每笔撮合检查买家自己的钱、卖家自己的物；单独扣款、入账、转物、扣费。买不起不能借用别人钱包。报价/愿付价为行为假设，实际成交额在成交时记录。
- 5%交易费以万分比余数累计，避免小额分单把税全部舍成0；余数暂存模拟市场。这是实验规则，不是正式收费承诺。制作费1铜销毁。
- 每日重算总钱包（含所有NPC及托管），对照初始+发行−销毁；28类物品逐类核对期初/来源−生产投入/使用/建设消耗=期末库存，且无负数。
- 固定装备每档最多绑定一次；不会每天重置耐用品需求。制作成品最多个人库存8件，避免把卖不动无限生产当正常行为。消费修理包必须省钱，未修理时才会采购，不用无限NPC托底。
- 免费/月卡交易方向、每30周期重新分位的财富组交易额均记录。每种子基准留前3000笔真实交易样本；样本不是全部成交日志。

## 指标与预先冻结门槛

最后90周期免费药品履约至少90%，免费组因个人现金不足的药品缺口为0，最近三个完整30周期免费现金变化中位数非负。会计误差为0。价格篮子为布/皮革/铁/清液各1份及基础药膏4份，使用30周期每日实际成交中位价的中位数；基期价格为设定初始价。缺任何项则该期NA，不沿用旧价。底料为NPC固定价，故这个指数不能单独代表自由市场稳定，须与履约和组件价格一起看。

价格变化门槛20%使用相邻完整30周期、全部窗口（包含开服/事件），比只看无冲击窗口更保守；上涨和下跌都可能使检查失败。无完整报价覆盖不能判通过；诊断报告另说明稳定窗口和暂时冲击。730日尾部不足30天不纳入月窗，最后90日履约仍使用全部尾部90日。

通过这些实验门槛也不等于无通胀；税费、固定NPC价与需求假设可能稳定部分指标而同时造成缺货。

## 尚未覆盖的现实

- 需要实际配方、药效、商店库存、装备提升和战斗日志替换占位。不同药剂档目前都按一个战斗消费需求计数，不模拟血量/魔力。
- 每人默认一个可维修遗落物；新手价值120、老玩家400，胜利磨损2，维修按源码公式。是否真携带、失败/撤退比例没有实测；未把这些额外损耗伪装成真实消费。
- 主线材料260/340/480、其它技能和晋阶消费尚未加入个人预算。本实验的免费药品可负担性不能证明主线/晋阶全程可负担，也不能据正余额就削减真实奖励。
- 活跃采用异质概率而非真实留存；新玩家是2000账号中延迟进入的部分，不是额外发行无限新号。活跃下降情景将每个账号的活跃概率降低60%，不是逐账号永久退服；非活跃钱包和库存保留，不能拿来替别人支付。
- 囤货情景为5%账号保留自己获得的关键材料，不是有组织财团垄断模型；抛售为短期降低卖方要价。未覆盖多开机器人、串谋、借贷或银行挤兑。
- 雾潮/泵站只各触发一次，前置无实物则未就绪；重叠压力用额外药需冲击模拟，不冒充另外四事件已实现。实体产能仅建设成功增加，失败不免费增加。
- 假设专业供给、缺料选择、购买顺序、限价和价格调整速度会影响结果，因此设置相应对照。资金长期积累并不自动等于同幅度物价上涨。
- 内存逐笔结算不是数据库并发/崩溃/恶意客户端验证。银行、投资、配方二级转卖、跨服资产和月卡真实支付未模拟。

## 后续发现与修正批次

第一轮检查发现购物策略只尝试一个药品SKU，可能有替代品仍判缺货；成熟工匠也可能没有训练收益却继续亏本制作。旧结果保留作受限行为控制组，不再直接用于经济定案。

`run_shopping.py` 在临时副本应用可审计patch：同类药按报价顺序尝试，逐笔减少真实剩余需求，不能四份替代订单买出四倍用量；`--profit` 进一步让无训练收益、非自用的成熟制作要求覆盖材料机会成本及制作/交易费。机会成本使用模拟报价，有价格滞后，不是真实玩家预测；成交价可能低于预期，因此这不是保证盈利。新批次沿用4配置×5种子×365期，不改货币/掉落/配方或验收门槛。

```sh
python3 tools/economy-agent-sim/run_targeted.py --out docs/development/economy-agent-sim-20260926/targeted
python3 tools/economy-agent-sim/run_shopping.py --out docs/development/economy-agent-sim-20260926/shopping
python3 tools/economy-agent-sim/run_shopping.py --out docs/development/economy-agent-sim-20260926/shopping_profit --profit
python3 tools/economy-agent-sim/audit_results.py docs/development/economy-agent-sim-20260926/year1
python3 tools/economy-agent-sim/report.py
```

完整实际运行数最终由RESULTS.md统计，不把未结束的批次提前算为完成。两年批次的新玩家入场窗口由总时长决定，和一年不是完全相同轨迹续跑；只能作为不同长期人口节奏的情景。
