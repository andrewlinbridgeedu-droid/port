# 2026 诺贝尔化学奖 · 资料笔记（《积微成著》）

> 核查方式：多家独立来源（Nobel/KVA 新闻稿摘要、C&EN、Chemistry World、Nature、Science、Scientific American、新华社、日法媒体）检索摘要交叉核对。

## 基本事实
- 公布：2026-10-07，瑞典皇家科学院。奖金 1200 万瑞典克朗，两人均分。
- 获奖者：Henri B. Kagan（亨利·卡甘，巴黎萨克雷大学/原巴黎南大学）、Kenso Soai（硖合宪三，东京理科大学）。
- 颁奖词（英文原文）："for the discovery of non-linear effects and autocatalysis in asymmetric organic synthesis"
- 中文：表彰他们"发现不对称有机合成中的非线性效应和自催化"。
- 委员会主席 Heiner Linke：解开了"一个多世纪的化学谜题：同手性如何自发出现"；"Life as we know it is homochiral."
- 科普资料标题："They solved chemistry's asymmetric mystery"。

## 片中使用的事实与数字
| 内容 | 数值/说法 | 说明 |
|---|---|---|
| 手性 | 与镜像不能重合；Kelvin 1893/94 定名；Pasteur 1848 手工分拣酒石酸钠铵晶体 | |
| 对映体 | 熔点、沸点等相同；仅在偏振光与其他手性物质面前不同 | |
| 香芹酮 | (R)-(−)：留兰香；(S)-(+)：葛缕子 | 不用"柠檬烯=橙/柠檬"之说（已被证伪） |
| 生命同手性 | 蛋白质氨基酸为 L 型（甘氨酸无手性），核酸中的糖为 D 型 | |
| ee | (多数−少数)/(多数+少数)；50:50 为 0%，75:25 为 50% | |
| Kagan 1986 | JACS 108, 2353：产物 ee 与配体 ee 不成正比；正非线性效应＝不对称放大 | 机制：同手/异手二聚体，惰性的异手（内消旋）配合物"锁住"少数对映体（ML₂ 模型） |
| Noyori DAIB 例 | 配体 15% ee → 产物 95% ee（JACS 1989） | 片中以屏幕注释呈现 |
| Soai 1995 | Nature 378, 767：嘧啶-5-甲醛 + 二异丙基锌，产物（其锌醇盐）催化自身生成；2% ee 经四轮约至 88% ee | 诺奖科普稿据报为 87% |
| Soai 2003 | Angew. Chem. 42, 315（炔基取代底物）：约 0.00005% ee → 约 57% → 约 99% → >99.5% ee，三轮 | 0.00005% ≈ 一千万个分子中左右相差约 5 个 |
| 触发因素 | 圆偏振光、手性石英/氯酸钠晶体、¹³C/¹²C 同位素手性（Science 2009） | 产物手性与触发手性一致 |
| 自发对称性破缺 | 不加任何手性物质也会随机偏向 R 或 S（双峰分布） | Frank 1953：自我复制＋相互拮抗 |
| 药物 | FDA 2013–2022 年新分子实体：59% 单一对映体、38% 无手性、3.6% 外消旋 | 片中说"过半" |

## 易错点
- Soai 反应本身不是前生命化学（需有机锌、无水溶剂），只是"逻辑可行"的原理证明；Soai 本人："This is not the final answer."
- 0.00005%→>99.5% 来自 2003 年论文，不是 1995 年论文。
- 沙利度胺在体内会消旋，不能据此说"只卖单一对映体就能避免悲剧"（片中未使用）。
- 正非线性效应往往伴随反应变慢。
