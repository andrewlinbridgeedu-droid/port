# 主角三套服装的 4K 背面原画 · 2026-10-02

用户指定使用 EC2 上既有的 API key，以三张正面原画生成对应的全身背面图。

- 三套：雾港夜行、星辉魔术师、午夜嘉年华。
- 目标：原生 2160 × 3840 PNG，保持原立绘的手绘质感、服装剪裁、纹样、配饰和人物身份，采用同一自然背面站姿。
- API：`gpt-image-2` 的 image edit，`quality=high`。使用 imagegen 技能自带 CLI；密钥仅在 EC2 既有环境中读取，没有复制到本地。
- `references/` 保留本次用户提供的三张正面图；`prompts/` 保留完整英文提示词。
- `raw/` 保存 API 原样输出的绿幕图；`final/` 保存用 imagegen 自带去绿幕工具提取的透明 PNG。去背景不重画人物，也不改变分辨率。
- `manifest.json` 记录输入 SHA256、实际输出分辨率、生成与透明提取方式。候选图须经用户复看，不记为认可。

本次仅出图，不修改既有角色资源、Blender 模型、Unity、App 或玩家存档。
