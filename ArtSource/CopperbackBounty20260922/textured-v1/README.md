# 铜背吞契兽｜参考图贴图首版

用户提供的 Copperback Guardian 白模，按“日式鲜亮奇幻”方向绘色：赤铜甲、金边、青绿鳞皮、奶油色腹部与下颌、象牙牙齿、深灰爪尖，以及暖白封签和红蓝蜡印。

## 交付文件

- `Copperback_Guardian_Textured_v1.glb`：贴图内嵌的独立 GLB。
- `Copperback_Guardian_Textured_v1.blend`：可编辑工程，图片已打包，不需要原来的临时目录。
- `Copperback_BaseColor_4K.png`：4096×4096 颜色贴图，sRGB。
- `Copperback_MetallicRoughness_4K.png`：4096×4096 材质贴图，线性数据；G=粗糙度、B=金属度，R保留为1，不是烘焙AO。
- `review-*.png`：重新导入交付GLB后的实际模型渲染，不是生成的概念图。

## 制作方法与来源

使用内置 **imagegen** 绘制六面投影，再对实际模型的前后斜侧视图修正肩甲/腿甲串色、封签污染，最后投影并烘焙为普通 UV 贴图。没有使用外部计费 API 或用户历史消息中的密钥。

- 初始绘色完整提示词：`imagegen-prompt.txt`。
- 两个斜侧修正视图共用提示词：`imagegen-refinement-prompt.txt`。
- 左前方补绘修正提示词：`imagegen-left-correction-prompt.txt`。
- 配色参考：`reference.png`（用户原图副本）。
- 全部源图、脚本、验证记录：项目 `output/copperback-texture-20260922/`。内置 imagegen 的原始输出也保留在其生成目录中。

## 工程记录

原模型无UV。使用 Blender 原生 Smart UV Project，保留几何；所有1,723,716个UV三角形均为有限数值且非退化。高密度模型展开的小岛较多，UV面积约占图幅35%，本版优先保留原形，后续制作游戏低模应另行展开并从本母版烘焙。

最初xatlas展开尝试耗时较长，已终止本任务自己的计算进程，改用Blender原生展开。首次导出遇到Blender新版不再接受的 `export_colors` 参数，已去除并从保存的工程重新导出，不重复烘焙、不影响原件。

最终GLB已重新导入Blender并以EEVEE完成五视角PBR渲染：前斜侧、另一侧前方、后斜侧、侧面、腹底。两张4096×4096图片均内嵌，颜色与金属/粗糙度节点连接正常，三角面数、边界与原模型一致。最终SHA-256：`75ca6798742895814793c355f955a190167be9e0f59019130f584715ec72c273`。这些结构检查不等于全视觉合格。
