# 黑金旅人 · Blender 立体试作

参考：用户于 2026-09-22 提供的单张正面全身图（保存在 `reference.png`）。这是一件从图片观察后用 Blender 几何建模的独立试作；没有调用图片自动转模型服务，没有把参考图贴在平面上，也没有替换或接入雾港正式角色。

## 文件

- `VeiledWanderer_Trial.blend`：完整可编辑场景，角色零件按身体、头发、衣袍、帽子、饰物等分类；含灯光和回看相机。
- `VeiledWanderer_Trial.glb`：仅角色导出，不含影棚、灯光和底座。
- `build_trial.py`：可重复生成模型的 Blender Python 源文件。
- `render_views.py`：使用实际场景渲染多视角。
- `model_stats.json`：实际几何统计。

## 试作范围

制作了完整身体和推测的背面、独立手指、长发束与小辫、破损非对称宽檐帽、多片有厚度的衣袍与青绿内衬、曲面金枝叶纹、腰带及玉石扣、链节、符牌、铃铛、烟杆和流苏、鞋底与绑带。多角度图均来自同一个 Blender 场景中的真实几何。

## 还原边界

单张图片的侧面与背面没有观测数据，本次按正面服饰结构补全。脸型、手型、衣褶、金纹、纹身、符字均为人工程序建模的近似设计，不能当成对原画的高精度重建；符牌使用装饰性笔画，不声称是可读原文。轮廓和材质的审美仍需用户评审。

本次是静态摆姿模型，无骨骼、蒙皮、动画、面部表情、布料碰撞、移动端面数预算或游戏性能验证。原始 Blender 程序材质包含细微噪声；GLB 保留基础颜色、金属度和粗糙度，其显示效果会与 Blender 的完整渲染略有不同。未使用该模型修改正式游戏。

## 实际验证

最终 GLB 已重新导入空白 Blender 场景：1,730 个网格，644,076 三角面，18 个材质。检查了有限顶点、完整头部/背部/帽/烟杆/眼线/金纹、无影棚导出、黑紫和青绿等基础 PBR 颜色；另渲染了 GLB 重导入实拍核对实际呈色。`glb_validation.json` 和 `SHA256.json` 记录最终文件哈希。侧面检查发现的背腰穿模已局部修复，并重渲染侧背确认。
