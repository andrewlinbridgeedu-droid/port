# 猎犬追名事件（第3—6关）

第3—6关为同一只失名猎犬，不是四只敌人，也不引入狗王。

- 第3关：玛拉交付假面，首次击退；追踪尚未解除。
- 第4关：假面误认与双卡配合；猎犬暂时失去踪迹。
- 第5关：保留玛拉与纸人遗落物教学；追随纸人的假踪迹离开。
- 第6关：单猎犬收尾；残破身份牌与“十三号”指向第7关。

第6关交替执行 bite / name_hunt。普通撕咬100%攻击；认名扑杀150%。假面承接或纸人承接认名扑杀后，下一次正伤害命中提高50%，消耗破绽；不能叠加。纸人遗落物每场一次，假面不消耗纸人的次数。没有强制失败和数值锁。成长奖励保持原有表。

Unity标准资产：Assets/Models/HellHound/Meshy_AI_Emberwolf_quadruped。
原生SpriteKit：render_native.py从同一FBX导出PursuitHound动画帧，不再使用另一套DemonHound图片。原生画面仍为预渲染动画，不是实时3D。

修正：原生敌人攻击准备时只对守卫执行守卫尺寸重置；第6关玩家站位避开底部牌栏；记忆蛭退出第6关，保留资产供后续调查引入。
