# 白袍药师 Rodin 单图试作

参考图：`reference.png`；生成参数与状态：`generation-record.json`。

当前可在 [Rodin 分支作品](https://hyper3d.ai/workspace/rodin/33c3a3b6-650f-4330-9721-2778d4b0fe94) 查看并旋转：Gen-2.5、几何 Extreme-High、Native High 材质。网页预览能辨认白发、破损象牙白外袍、红内衬、红瓶、青色腰瓶、铜笼提灯与黑靴。网页显示 59,489 顶点、45,826 面。角色脸部与小配件仍需正式视角和近景复核。

12K「Extreme High」材质被 Rodin 的 Business 订阅弹窗拦住，未订阅；8K 选项用于一次 High 材质重做，但没有取得贴图文件，不能称已核实 8K 输出。Pack 中 GLB＋PBR/Shaded＋2K 到达 100%，本机 `~/Downloads` 未出现对应文件，浏览器也没有下载事件。本目录目前**没有 GLB 或 Blender 文件**；`inspect_rodin.py`、`make_blend.py` 是取得 GLB 后才可运行的复核脚本，不能当完成证据。

这是独立视觉试作，无骨骼、动画、减面或游戏接入。B06 的正式角色、罪行、法术设计见 [设计稿](../../mistport-ios/docs/game-design/chapter-one-30/BOUNTY_B04_B06_CHARACTER_REDESIGN_20260922.md)。
