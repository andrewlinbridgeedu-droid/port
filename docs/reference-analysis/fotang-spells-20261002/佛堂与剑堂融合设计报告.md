# 佛堂与剑堂的战斗设计分析报告

本文将佛堂与剑堂试炼中实际看见的法术、羁绊和战报放在一起，说明这款游戏如何用技能身份、状态循环、羁绊门槛、品质成长与六槽配置组织战斗。核心结论是：它不是简单挑六张面板倍率最高的卡，而是让每个技能同时参与一条战斗循环；佛堂以灼烧和引爆为轴，剑堂以攻速、冷却反馈与连招为轴。两堂共享“高阶核心＋同系羁绊＋两格配套”的构筑框架，却用不同状态机制制造差异。

## 研究范围和证据边界

本报告根据用户提供的截图、会话中直接读取的技能详情、强化条目、羁绊面板和结算战报整理。没有游戏源码、官方完整图鉴或可控制变量的实验。文中把事实、单局表现和设计推断分开；战报占比只代表那场战斗，不能单独证明某张牌跨楼层最优。技能详情页上的大数字若没有明确的伤害统计标签，也不当作本场伤害。

当前固定配招原则是用户指定的“最高级4个＋次高级2个”。羁绊只能在这六个法术之内优化，不能为了凑羁绊换入更低级法术。佛堂、剑堂各自的类别计数不同，不能把一堂的羁绊规则照搬到另一堂。

## 一、共同的战斗设计骨架

### 六个槽位构成一条循环

每招不只提供直接伤害。技能可能负责施加状态、放大后续效果、压制敌方、触发冷却反馈、消费已累积状态或提供回复。玩家要在有限槽位内组成循环，而不是把单招伤害榜直接抄成阵容。

### 羁绊把类别变成构筑条件

羁绊将技能所属流派转为团队规则：达到数量门槛后提供伤害、攻速或每次施法触发。于是两张配套技能的价值可能来自它们激活的整套被动，而非各自的结算占比。读取面板时必须检查已激活等级和数量，不能把“显示了该羁绊说明”误当成已经激活。

### 高阶成长重写旧技能的机会成本

低阶技能以前可能承担状态铺垫或羁绊填格；解锁高阶法术后，直接倍率、目标数和联动效率一起提高。低阶辅助是否还值得使用，要用相同楼层、同一套其它技能和相近战斗条件比较，证明它带来的辅助或生存收益能抵过失去的高阶伤害。

### 战报是诊断数据，不是机制本身

结算页显示每张技能伤害占比，但持续伤害、羁绊伤害、引爆伤害和增益收益如何归属尚未完全确认。占比适合找异常、看主力是否施放和比较同类尝试；不能把“输出条最低”直接等同于技能没价值，也不能由一次伤害最高推出它是全局最优。

## 二、佛堂：灼烧、放大、引爆和生存转换

佛堂的共同语言是灼烧及相关持续状态。技能可以先铺状态，再按层数加强效果，之后放大或引爆剩余伤害，并把层数转成回复或减益。顺序十分关键：状态准备太晚，后续技能吃不到条件；过早引爆，又可能让依赖灼烧的技能失去资源。

### 主要角色

- **四张金焰高阶核心**提供高倍率伤害，并分担群体覆盖、灼烧放大、减益和引爆回复等工作。已读取的烛龙焚罪详情为两目标6080%，并根据已有灼烧层数增加焚罪减益；这不等于增加灼烧层数。天佛宝轮、紫川神火、圣莲灼世的若干联动来自会话读取摘要，完整细节仍需回到详情复核。
- **大日炎轮经**是清楚可见的状态结算器：三目标2880%，引爆剩余灼烧；每个目标的灼烧层数超过2层时可触发回复，并额外驱散自身减益。它连接前段铺垫与后段生存。
- **净世业火莲**对四目标造成2448%，并延长本招和下一招施加的增益、减益。它是顺序型支持牌，必须放在目标技能之前；不能自动推断它会延长所有持续伤害。
- **佛光普照**八阶五重详情为三目标819%，施加两层灼烧并降低敌方攻速15%、持续3秒。它有状态和防守用途，但对比高阶金焰的直接倍率差距很大。此前将它推荐进高阶主力阵容的建议已撤回，除非同层测试证明其辅助收益足以弥补损失。
- **烛龙焚罪**强化“已有灼烧→更强焚罪减益”的转换；不要把焚罪与灼烧当成同一状态，也不能按层数简单乘出减益数值。

### 羁绊的组合约束

佛堂历史记录曾显示金焰二级4/4有效，而少林、佛门各自只有1/2，尚未形成第二个有效羁绊。按当前固定结构，先保留最高级4个和次高级2个；若次高级两招同属一个可激活的类别，再形成第二条羁绊。一张少林加一张佛门不能凑成两条。若两张次高级无法激活目标羁绊，也不能降阶换牌，应在同阶可用选项内寻找替代组合。

### 佛堂的设计意图（推断）

佛堂鼓励玩家经营状态资源。高阶金焰不只是面板更大，也提高触发状态、放大和结算的频率与质量；其它技能的价值取决于是否改善整条灼烧循环。它因此同时考验状态类别辨识、出招顺序和羁绊槽位分配。

## 三、剑堂：攻速、冷却反馈与连招循环

剑堂不是把佛堂的灼烧循环换成剑图标。读到的八阶技能显示另一套逻辑：攻速影响冷却概率、追加伤害和刷新几率；施放本身又能触发攻速叠层或额外攻击，形成“攻速→更快/更多施法→更多反馈”的循环。

### 四张高阶主力的功能

- **剑二十三**：三目标1386%，施放后获得幻影，攻速提高30%，并降低受到的会心与异常伤害，持续6秒。它兼有进攻起手和短期防护作用。
- **一剑隔世**：四目标1386%，额外两段各180%，攻速可提高追加伤害、上限360%；自身技能伤害再提高30%。具体增幅的归属和结算需要以战斗验证。
- **天外飞仙**：两目标1540%，召出三柄仙剑，后续武学或神通施放时触发额外伤害；攻速影响仙剑消耗概率。详情对140%的计量方式仍需确认，不能直接算成三倍总额。
- **万剑归宗**：四目标1309%，作为金色剑阁武学上阵后，金色剑阁武学施放时有概率减少该技能冷却，攻速提高该概率，并有伤害加成。被动上阵效果不要求它先施放，但战报里的直接占比可能低，仍要区分被动贡献和本体伤害。

### 两张羁绊配套牌

早段曾推荐红色候选**夺命十三剑**（攻击速度提升并追加伤害）与**六脉神剑**（施放后有概率刷新冷却，自身技能攻速和伤害提高）。它们只有在属于次高级可选项时才可进入当前两格；不能用低阶版本替换最高级四招或次高级两招。概率、刷新上限与增益是否叠加仍需实测。

后续进度的羁绊面板显示：**剑宗二级4/4**，提供剑阁武学/剑宗神通伤害加成，并在释放任意武学/神通造成伤害后获得可叠加的急速；**剑阁一级2/4**，提供较低一档伤害和攻速加成。界面因此支持当前“4张剑宗＋2张剑阁”的双羁绊结构。剑堂后段截图与早段八阶候选是不同进度记录，技能名字和品质组合不能混为同一时点。

### 剑堂实战证据

一次通过后的结算总伤害为27.8万：流光剑意22.73%、寂灭红尘斩22.90%、龙吟九霄剑24.48%、星河碎剑诀15.28%，万剑归宗5.49%、剑二十三9.11%。四个新神通合计85.39%。这证明该套配置能通过那一轮，且新解锁神通承担了主要直接伤害。

之后第72层失败的一场总伤害33.8万：流光剑意22.98%、寂灭红尘斩23.46%、龙吟九霄剑17.00%、星河碎剑诀13.75%、万剑归宗12.24%、剑二十三10.58%。另一次失败为21.2万，六招占比分别为剑二十三15.7%、寂灭红尘斩25.56%、流光剑意18.36%、龙吟九霄剑21.83%、星河碎剑诀13.85%、万剑归宗4.71%。

这几场说明高阶四招仍是主要伤害源；万剑归宗本体贡献波动很大，不能只靠其单场占比断定该被替换，因为它可能还提供被动减冷却或羁绊价值。失败局造成的总伤害反而可能高于通关局，说明“造成了多少伤害”不能独立判断胜负；敌方血量、己方生存、计时、施放次数、技能强化和随机触发都可能影响结果。失败原因应结合结束时剩余血量、时间和状态来诊断。

最新一轮推进至第79层并胜利，结算总伤害41.1万：星河碎剑诀20.16%、寂灭红尘斩24.20%、流光剑意22.12%、龙吟九霄剑23.17%、剑二十三6.06%、万剑归宗4.30%。这次胜利证明当前配置能通过该层；伤害占比仍只描述这一局，尤其不能据万剑归宗较低的直接占比否定它可能提供的上阵被动收益。

### 第90层新神通与当前进度（2026-10-03补记）

用户明确固定六槽结构为**最高级4个＋次高级2个**。当前剑堂配置对应四个最高级新神通——**瞬光·虹桥渡仙、瞬光·逐光万剑、瞬光·剑分黄泉、瞬光·九龙啸天**——加两张次高级法术**寂灭红尘斩、星河碎剑诀**。羁绊面板显示**剑宗霞光二级4/4**和**剑宗一级2/4**；这两条都在遵守4＋2的前提下激活。以后分析佛堂或剑堂配置都先执行这个结构，再在六槽内比较羁绊和顺序。

本次第90层失败结算总神通伤害为**132.6万**：虹桥渡仙22.75%、逐光万剑21.46%、剑分黄泉27.86%、九龙啸天8.89%、寂灭红尘斩12.17%、星河碎剑诀6.86%。四个最高级新神通合计**80.96%**，剑分黄泉是本局单招最高；两张次高级合计19.03%。较早一次第90层失败总伤害为**154.6万**，四个最高级新招合计82.07%（12.76%、18.42%、35.31%、15.58%），两张次高级合计17.93%。两次都未通过；配置与两次战报截图见[第90层六槽配置](evidence/sword-floor90-loadout.jpeg)、[154.6万失败结算](evidence/sword-floor90-defeat-1546wan.jpeg)和[132.6万失败结算](evidence/sword-floor90-defeat-1326wan.jpeg)。这说明最高级四招承担了两局的主要伤害，但配置仍未击败第90层，不能据此称为通关或固定最优。

用户于2026-10-03补充：本层个人最高约**170万**，感觉“差一点”，并估计约**175万**可能过关。170万是玩家口述的最高成绩，未附对应战报截图；175万是经验估值，尚未由实际通关确认。从170万到175万约需提升**2.9%**。因此继续遵守最高级4个＋次高级2个的固定结构，先在六招内部优化强化、出招循环与羁绊，不为凑羁绊换入低阶招式。

可读到的虹桥渡仙详情为：**13阶五重**，对3个目标造成5472%攻击伤害，施放后持续6秒；期间击杀目标时，神通伤害提高15%、持续4秒，同时自身及相邻已装备技能冷却缩短2秒。这个击杀触发对单体首领能否生效取决于战斗里是否有可击杀的小怪，需用详情页和实战帧再核。当前强化记录还包括九龙啸天增益持续时间延长50%、剑分黄泉会心伤害提高50%；它们是构筑背景，单场占比不能单独证明强化的因果收益。逐光万剑与剑分黄泉的完整技能描述、九龙啸天的持续机制仍待详情页复核。

从设计结构看（推断）：四个同系最高级招式承担高伤害与霞光羁绊循环，两张次高级招式用来补足剑宗类别并维持第二条羁绊。虹桥渡仙的击杀回馈把清杂和冷却循环绑在一起；九龙啸天的持续时间强化更适合长效覆盖；剑分黄泉则以会心伤害强化作为爆发点。当前失败局没有保留结束时剩余血量、剩余时间和首领状态，所以还不能判断卡点是生存、时间还是施法循环。

### 剑堂的设计意图（推断）

剑堂把玩家注意力放在速度和施法次数。攻速不是单纯的面板属性，而是多个技能的共同输入；羁绊急速再让技能命中推动下一轮循环。技能因此形成正反馈，但对冷却、概率和出招次序更敏感。用静态伤害排名替换技能，可能会拆掉藏在上阵被动和急速层数里的收益。

## 四、两堂的设计对照

| 设计维度 | 佛堂 | 剑堂 |
| --- | --- | --- |
| 核心循环 | 铺灼烧与相关状态，放大、施加减益，再引爆并转为回复 | 累积攻速与急速，触发减冷却、追加攻击和概率刷新 |
| 关键资源 | 状态层数、剩余持续伤害、下一招增益 | 攻速、急速层数、冷却和追加施法 |
| 典型时序 | 状态准备→放大/利用层数→终结引爆 | 起手加速→高频主力→触发冷却/刷新，维持连招 |
| 生存入口 | 灼烧层数触发回复、减益和驱散 | 降低受到的会心/异常伤害、攻速抑制或急速带来的压制 |
| 羁绊意义 | 使施法稳定提供灼烧/金焰，构成状态底座 | 伤害加成并令施法叠急速，推动速度反馈 |
| 常见误判 | 把焚罪、佛炎、金焰和灼烧混成一种；认为引爆总是增益 | 只看技能本体伤害，漏算上阵被动、急速与冷却触发 |

## 五、融合后的游戏设计画像

两堂共同构成一套“流派身份＋状态循环＋六槽取舍”的技能设计。技能品质和阶数给出基础成长，羁绊让技能类别形成阵容门槛，专属强化改变具体卡牌的相对价值，战斗顺序决定状态在何时被消费。挑战关卡则检验这套组合能否把理论循环转化成足够的伤害和生存。

佛堂与剑堂像两种不同的构筑语法：佛堂管理持续伤害状态，剑堂管理行动速度和冷却反馈。二者都用高阶主力提供强直接伤害，同时让配套技能承担状态或循环辅助。这种设计让战斗策略具有可读的方向，但也增加说明负担：如果状态名称、触发条件、羁绊激活状态、增益归属和战报统计口径显示不清，玩家容易把系统误读成纯粹比倍率。

## 六、可执行的构筑和研究原则

1. **先锁定用户的结构约束。**佛堂和剑堂都固定使用最高级4个＋次高级2个；羁绊只在这六个法术内优化。不能为了理论输出擅自换入更低级法术。
2. **在4＋2结构内优化羁绊。**逐项核实激活数量、等级和增益内容；不能为了羁绊打破最高级4个、次高级2个的配置，也不能用一张异系单卡期待两条羁绊同时生效。
3. **把高阶核心与辅助槽分开分析。**核心技能维持品质和进度，辅助槽则按本层失败原因在输出、控制和生存之间选择。
4. **按流派机制排列。**佛堂让状态来源先于依赖层数或引爆的技能；剑堂让起手加速和触发收益尽早进入有效窗口。具体顺序仍以技能详情和实战验证为准。
5. **每次只改一个变量。**同层尽量保持六招外的强化和玩法相同，每次只换一个辅助位或调一个顺序，比较胜负、总伤害、技能占比、施放次数和结束状态。
6. **记录失败原因。**结算时记录当前层、六招顺序、品质与阶数、已激活羁绊、强化、总伤害、失败时剩余气血/时间和重复尝试次数。只有伤害表无法分辨超时与生存失败。
7. **不要把建议说成结论。**目前已证明某些组合在特定战斗中通关或贡献主要伤害；尚未证明跨层固定最优顺序、所有技能的确切机制或战报完整归因。

## 结论

这款游戏的核心不是单卡强弱，而是把技能做成有流派身份的循环构件。佛堂围绕灼烧状态的建立、放大、压制和结算；剑堂围绕攻速、急速、冷却反馈和连招。羁绊负责把技能槽连接起来，高阶法术提供明显的成长动力，战报则给玩家提供有限但有用的诊断线索。最可靠的构筑方法，是遵守高阶和羁绊约束，读清技能间的条件关系，再用同层小步对照验证，而不是拿单场伤害榜当作万能答案。
