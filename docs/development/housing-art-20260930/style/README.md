## 连贯关系与参考

三张延续同一组湿铺石、引潮渠、黑铸铁栏杆、盐渍石灰岩、灰玄武岩基座、铜绿深挑檐和滴水槽，灯火暖黄；前景细节清楚，远处被灰绿与雾白的海雾遮住。第二张以第一张作连贯参考，第三张以前两张作参考。它们表达沿街移动的建筑方向，**不是精确坐标注册的地图，也不是可无缝拼接的全景**。

生成时参考了首页春、夏、秋、冬的白天原画，继承雕塑感石材、精细笔触、建筑尺度与柔和光色；四张参考只读使用。全部 15 张首页原画 SHA-256 与分支起点一致。输入顺序、提示词、输出哈希和原始生成文件名见 [generation.json](generation.json)。
