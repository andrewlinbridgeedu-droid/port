# 港城地图、街坊与昼夜（2026-09-25）

现行港城入口来自首页底部「进入港城」。港城地图铺满标题以下的手机屏幕；删除旧底部黑色说明条和标题下「沿街前往建筑」副标题。顶部西街、缩放和东岸按钮改为无橙边的浅色圆角样式，建筑屋顶标签只显示建筑名。轻点已开放建筑后，镜头先将其横向置中，再自动进入；轻点道路则让主角沿石路行走。顶部「返回主页」仍可随时离开。

主角原来使用的 22 个节点中，钟塔起点落在水池，几条连线穿过房屋和水面。这一批将主角初始落点移至钟塔南侧石路 `[1132,1000]`，并将步行图替换为 `WisteriaMap/navigation.json` 中逐段贴合原画道路的 27 节点、26 连线。路线从边上投影接入两端节点，再以最短路相连，避免从边上直接切过池水。主角在港城和通缉调查地图都按参考图每秒 19.6 像素移动；邮差为 135 像素／8 秒，主角约快 16%。镜头改为有死区的缓跟，移动中不对每一个路径节点重新启动补间。人物画面位置按脚底而非图片中心对齐地面。

街面当前有 13 条短距往返路线、10 个站立人物。原有邮差、信使及其他 Blender/GLTF 城市模型继续使用；新增提灯人、花商、水手、档案学徒四个可编辑 `.blend` 和含动画 `.glb`，放在 `ArtSource/HarborCitizens20260925`。六类行走人物都从近侧面重渲染为八帧地图小图，再按运动方向翻转，避免三分之四正面图在横向移动时像倒走。其余人物保留原地身份。东岸旧行人线曾经过蓝色屋顶，现改至右岸房屋前 `[1935,720]→[1995,720]` 的铺石路。旧导航遮罩把这段真实铺石路判为封闭，却把邻近屋顶判为可走；该路线以原图局部检查图 `output/harbor-map-daynight-20260925/route-far-right-720.png` 为依据，在验证脚本中对**精确坐标**单独备案。

行人被鼠标悬停时冻结两秒，之后从冻结处继续行走，不跳帧到未来位置。轻点移动或站立人物会显示有姓名的短对话；手机无需悬停即可直接点开。顶部「入夜／天亮」开关切换深蓝天空、星点和暖色灯光；地图、人物与建筑标签保持同一位置。当前昼夜为玩家手动切换，不按现实时间自动更新。

用户随后在镜像截图中指出钟塔上层与前景楼梯的两名人物看起来悬空。原路线分别跨过钟塔旁台阶 `[990,760]→[1145,760]` 和前景台阶 `[1020,1000]→[1120,1000]`；原有道路遮罩允许走台阶，但平面小图没有随台阶高度和遮挡改变。现把钟塔街坊移到台阶右侧平坦石路 `[1080,760]→[1150,760]`，档案学徒移到下方广场 `[980,1080]→[1050,1080]`。行走小图的脚底原比路线高约两画面点，现按图集非透明像素底缘将脚和接地阴影同时对齐路线；站立人物也按底缘对齐。路线检查新增两块台阶禁行区，避免这一类路线回归。原位与新位的合成检查图见 `output/harbor-map-daynight-20260925/grounded-clock-square.png` 与 `grounded-archive-apprentice-walk.png`；这两图是静态定位辅助，不冒充引擎截图。

验证：`tools/harbor/validate_routes.mjs` 检查 13 条行人路线、10 个站立落点、模型小图资源、台阶禁行区及主角道路节点与 `navigation.json` 的一致性，最终通过。四个新 GLB 各含 1 条动画；侧面渲染与原画逐段位置的检查图位于 `output/harbor-map-daynight-20260925`。签名 iOS Build 84 曾在 iPhone 13 镜像实看：底部黑条删除、浅色控件、夜间开关、点教会先置中再自动进入、点信使弹出对话均通过。Build 85 增加水池起点修正、完整道路图、侧面人物和更深夜景；镜像下实见港城，但用户的 186% 放大截图暴露台阶悬空。当前签名 Build 86 已构建、签名验证、安装并启动 iPhone 13；设备列表确认 `0.1.0 (86)`，安装前后以及启动后的 Preferences 8 文件逐字节相同。Build 86 镜像在 100% 地图上实见钟塔旁人物位于台阶右侧石路；随后 iPhone 镜像因手机使用中断开，未完成 186% 的同机位动态复拍，也未做整张地图逐路真机审美验收。原图精确落点、接地关系已用静态合成图核对，但不将其写成手机视觉全面合格。
