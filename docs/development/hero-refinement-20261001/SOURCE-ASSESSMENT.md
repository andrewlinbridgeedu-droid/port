# 用户提供的 Meshy 模型与精细度要求

2026-10-01 用户指出 v1 背影不够精细，并以金紫长外套背影图指定目标。v1 的构建和动作探针不代表视觉合格，当前继续草稿 PR #41，不能把旧预览当成新版本。

## 两份原件

| 原件 | 实际内容 | 形体与动画 |
| --- | --- | --- |
| `meshy-source/original.glb` | 用户提供的带贴图 GLB；4K 颜色／法线、2K 金属粗糙度／发光图，已有 UV | 9,653 个三角面，无骨骼、无动作 |
| `meshy-untextured-source/original.glb` | 用户随后提供的白模；没有材质、图片或 UV | 9,658 个三角面，无骨骼、无动作 |

两份文件已用 Blender 实际打开，分别观察正面、背面、背面斜侧三张原样渲染。将形体统一到 175 cm 高后，白模顶点到前一模型表面的距离中位数约 0.000021 cm，最大约 0.000072 cm；形体几乎一致，不能把白模称为更高精度版本或宣称三角形逐项相同。计算与方法见 [meshy-shape-comparison.json](meshy-shape-comparison.json)。原件 SHA256 分别记在两个目录的 `inspection.json`，用户下载原件没有修改。

## 当前判断与方向

用用户模型作身体、头部比例和剪裁基础，比沿用 v1 的粗糙基础形状更合适；已有贴图可作材质参考。但来源都是短外套，离用户指定的长外套参考还有明显差距，不能直接导入再换色就称为完成。

- 需要做有布料体积与重力褶皱的长后摆、紫色衬里、袖口、收腰、金属链扣和刺绣。
- 头发要保留碎发和不整齐的层次，不能变成整齐的头盔；肩袖不能保留明显三角面感。
- 雾港夜行、星辉魔术师、午夜嘉年华对应现有三套角色原画。身体、骨骼与动作共用，服装剪裁、外层、衬里和配饰分别做，不以三种调色代替三套服装；场景保持原样。
- 白模需做 UV、材质、骨骼和权重。七种施法动作仍需在最终三套衣装上复查，不能拿 v1 通过的动作记录证明这个新底子已验证。

## 建模试验，未达目标

`meshy-study/HeroMeshy-study-v1.blend` 是可复跑的静态 Blender 建模试验，不是最终角色。试验了来源 UV 保留、材质区分、弯曲后摆、金线、链扣和发束。第一轮细分产生 UV 分裂顶点间的裂缝，第二轮发束又变得过于整齐；已继续调整，但该稿整体还没有达到用户参考的精细度，**不能标为认可、不能作为三套服装交付、不能接 App 或装机**。

试验真实渲染在 `meshy-study/`，与参考图片严格分开。没有把 ImageGen 稿贴在背景上冒充模型。它没有骨骼和动作，没有合并成运行资产；当前未改 Unity、App、规则、战斗背景、真实 Preferences 或旧模型。

[用户精细度参考](hero-detail-target-v2.png)与[第二轮 ImageGen 参考](hero-back-concept-v2.png)是设计资料，不能替代模型证据。`imagegen-prompt-v2.txt` 保留本轮参考稿的设计提示词，使用内置 ImageGen；建模试验通过原生 Blender 生成，没有用图像工具替代 3D 模型。
