# 第一关对白过渡与全敌人退场 · 2026-09-15

## 实现
- 第一关第三次命中后等待当前攻击演出结束，再挂载透明起始的引导层。战斗画面用1秒线性淡到黑，随后人物对白以原有0.65秒淡入。移除旧的立即黑屏＋450毫秒黑屏等待；其它对白不改变。
- 敌人死亡退场保持1秒淡出，与原有死亡动作并行；记忆蛭保留原来的死亡演出等待后再淡出，没有增加其他死亡动作等待。
- 为Standard模型增加资源内固定编译的PBR透明Shader，保留颜色、贴图、法线、金属、遮罩及发光，避免手机构建剥离Standard透明变体导致突然消失。
- 水蛭使用现有专用透明Shader；守卫护印按原始_Opacity同步衰减。
- 中途重新显示、重置与禁用明确恢复原始共享材质并销毁临时副本；移除普通死亡下沉位移，避免先穿入地面再消失。
