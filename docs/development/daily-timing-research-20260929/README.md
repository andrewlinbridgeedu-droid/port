## 采集交付

`timings-template.json` 的16类活动均未填数据，每类至少3次（四类街坊委托分别采集）。在独立测试存档里正常操作，不跳剧情、不自动出招、不直接发奖；记录构建号、日期、设备、观察者、用时秒数、关卡/层段/配方/牌种、首通或重玩、装备及依据。保留失败、重试和等待记录，不能只挑快的成功样本。

一次样本的字段示例（占位符，不是测量）：

```json
{"date":"YYYY-MM-DD","build":null,"device":"设备名","observer":"计时者","mode":"human-normal-play","seconds":null,"context":"关卡、装备、是否首通及起止点","evidence":"录像时间戳或计时记录位置"}
```

从模板复制为新文件并填 `samples`，不要覆盖原始观测。运行：

```sh
python3 tools/daily-loop/timings.py <观测.json> > <中位数报告.json>
```

缺类、少于3次、非正数、缺依据、自动模式或同类混用构建会报错；通过只表示观测格式完整，工具不能证明人类身份或记录真实性，更不自动修改模型。中位数以秒和分钟同时输出，另列最小、最大值和日期。

采样默认包含入口、准备、剧情/调查、玩法和结算；制作、卖货、交货单测时材料预先持有，另记录取得材料的时间，防止模型重复计入。对战类还需分段记录纯战斗时间与界面/剧情时间；传话记录接单前步行与收话人步行；残余案记录调查与战斗。否则仅有整单中位数，仍不能安全替换分段 `Assumptions`。

## 模型对齐表

| 观测 | 目标 | 校准前必须处理 |
| --- | --- | --- |
| 主线/塔/通缉整单 | `MIN_MISSION/MIN_FLOOR/MIN_CASE` | 区分关卡与装备，不把最短关当全章代表；模拟器战斗秒数来自机器人，不能再叠加整单秒数 |
| J0/J1/J2 | `JOBS`、`postalSeconds` | J2 需记录塔层段、重复次数与递减后实收；J1/J2 模拟战斗与进出耗时分别映射 |
| 制作/卖货 | `craftSeconds/saleSeconds` | `MIN_WORKSHOP_BATCH` 还含F1刷材，不能直接等于制作时间；逐配方验证收益 |
| 四类街坊 | `errandSeconds/messageWalkSeconds` | 当前共用固定120秒；赶怪已另计战斗、传话另加步行，整单不能重复加 |
| 事件交货/战斗 | `eventDeliverySeconds/MIN_EVENT_DAY` | 聚合值须按实际交货次数和战斗次数加权，不能一律假设每天两战一次交货 |
| 残余案 | `remnantInvestigationSeconds` | 这里只含非战斗部分；战斗、结算、重复工作递减分开 |
| 牌局 | `MIN_TAVERN` | 区分牌种；5%抽水尚为候选，不自动加入 |

`budget.py` 仍含未实装地下委托U01–U06、固定工坊利润、事件每天20铜等候选。即便把时间换成实测值，也不能称它为当前App的精确经济回放。应先分离实际玩法与候选情景，再列逐日铜币来源、销毁、材料取得、首通与重复、失败和重试。当前 `Campaign.swift` 的教会门槛仍为Q7，而App一直开放；已向用户询问，尚未收到决定，未擅改。

## 共享服研究结论（无游戏改动）

已读三份指定设计文档，并核对 `tools/economy-agent-sim/README.md` 与模型使用范围。

1. 本地每日账本控制次数与幂等，不构成共享服国库或对手方付款。单机发给玩家的铜仍是新发行；NPC有限订单并不自动意味着共享市场转账。
2. 24铜普通工日／12铜六项篮子仍是候选。现实操作分钟与世界内8小时劳动不能直接换算；完整工资、原料、燃料、床位和服务成本链未证明。固定标价及买不到不能作物价稳定证据。
3. 2000人V3模型曾本地复跑与源包逐字节一致，但同时复现服务涨价、缺货及床位失败。工业进口缺付款/运输约束、J0恢复补助缺工作与关联账户核验、银行未连接真实违约传导，不能据此上线。
4. 独立账户经济模型有实物/货币守恒检查，但配方档、活跃、需求及耐用品选择仍有占位。成熟服Q30高频刷铜追加实验只放大铜，并未计额外战斗时间与成本；不能拿这些次数冒充真机可达频率。
5. 新时间数据到齐后，应把各玩法次数限制为每日操作预算可容纳的行为，同时接入实际共享递减顺序及跨任务重复账本；从真实配方、事件物资与已实现奖励重新提取来源。旧220轮与后续12/9轮参数不同，不能合称同一新版通过。
6. 先冻结对照情景及验收口径，再以相同种子比较基准、供给变化、成熟服、人口/战争冲击。至少报告分群药品履约、未成交/排队、现金不足、成交价格覆盖、铜币净发行、预算耗尽和会计误差；不是只报余额或固定价指数。银行存款、托管、产业投资是资金转移或锁定，不能当成销毁。
