# 第一条本地工艺接入

2026-09-28。用户要求从v0.3.3隔离试玩继续推进。本次把取材、图纸、制作、有限交货和安装接入正式Swift源码及真实GameStore；不迁入试玩中的48铜、30层装备、11套已完工工程或其他玩家成绩。

## 产品范围

沿用现有Q16工坊解锁点，商会地标进入皮革工坊。（2026-09-28更正：Build 142按用户标注重排主页楼名牌，删去“商会”，工坊入口随之失效；现按用户决定挂在“工业委员会”名牌上，见[M0第一批次记录](../M0_BATCH1_20260928.md)。）第一个订单是**工坊检修架**：2条维修绑带，18铜总价，一次性采购。交货取得货款，随后安装消耗已交付的两条；第三条留在真实背包。它是主线期间的本地工艺教学单，不是《谁让雾港重新亮灯》的第12套组具，不替任何阵营记贡献或判胜。

世界事件仍须第二章仪式、盐岸转运站、NPC与剧情入口完成后开放。Q30离开雾港后，现场工坊暂停操作，已得材料/图纸/熟练度/订单状态保留；不会为展示新功能把玩家传回雾港。教会远程服务及旧结算规则保持原门槛。

## 已实现的代码路径

- Q16后新发起的教会塔F1，胜利直接给1份盾颚韧皮。开战登记唯一票据；失败/撤退关闭票据；相同胜利回调与重启不能再领。只接F1，不把所有D01编队泛化成已核定掉落。
- 旧F1首通记录不补材料；铜币、功勋、装备继续走旧首通规则。胜利页另显示本场韧皮，不冒充重领首通奖。
- 免费学习基础皮革图纸；1韧皮＋13铜→3维修绑带，每批熟练度+1，本阶段上限20。高级图纸的序列/熟练度/学习要求仍显示为后续内容，未假造晋阶。
- 制作/交货/安装使用幂等操作ID；真实背包、玩家铜币、熟练度、项目库存与订单状态进入同一份教会服务结算回执。重启恢复绝对结果，不重新叠加奖励。
- 新旧教会服务账本兼容：旧记录缺少workshop字段时初始化空专业，不授予玩家现金或材料；旧回执没有inventory字段仍可解码。
- 无法解码账本时停止新的教会服务写入，保留原数据，避免用空账本重建采购额度。
- UI展示真实库存/余额、剩余采购量、已交货/已安装状态；订单结束后再制作会提示暂无买家。新增物品编入背包目录，素材图暂复用通用材料图标。

## 货币口径

本地NPC检修单新增**18铜一次性启动预算/存档**，不是已经证明存在的全服财政收入。最多向玩家支付18铜，售完后预算归零，不每日刷新。13铜加工款记录为外部支付。初始玩家71铜的验证样例：制作后58、交货后76；NPC预算18→0，外部13，71＋18＝76＋0＋13。剩余绑带不按报价虚计现金收入。

这个预算必须在未来共享经济里计入新号一次性发行/启动储备，不能当成净零发行，也不能将删除本地存档重开视为共享服唯一权益。P2P、银行、跨服和共享财政均未开放。

## 验证

- `core-tests.log`：新规则5个测试（其中缺钱测试含0/12铜两个参数），已通过。覆盖有限采购与钱物核对、幂等、序列化、缺钱原子拒绝、真实F1结果与入场票据匹配。
- `simulator-build.log`：首次双架构构建被主动终止，不算通过；`simulator-build-arm64.log`为最终arm64构建，`BUILD SUCCEEDED`。宿主编译正式App所有Swift源与正式战斗库，独立bundle ID `local.mistport.workshop-integration`；仅移除Unity运行依赖和非界面媒体资源，不修改生产项目构建设置。
- [`local-workshop-verification.json`](local-workshop-verification.json)：正式GameStore的17项检查全部通过，运行于新建的独立iPhone 17 Pro / iOS 26.5模拟器。包括Q16/Q30门槛、旧存档不补发、胜利回调查重、制作后中断回执恢复、有限交货、安装与重启、原药品/物证保留、退出票据失效、旧回执兼容、损坏账本停止写入，以及首次塔通关8铜/2功勋与1韧皮共同结算仅一次。
- 初次`ImageRenderer`不能渲染UIKit导航容器，其输出未作验收证据。已改用原生`UIWindow`＋`UIHostingController`，检查[未学习页面](local-workshop-before.png)和[订单完成页面](local-workshop-complete.png)：真实余额71→76、绑带0→1、熟练度0→1、缺料按钮禁用、采购完成和页尾说明可见，无内容重叠。这是390×1500pt加长原生窗口渲染，便于全页检查，不是手机物理屏幕截图。
- `--verify-local-workshop`只使用专属宿主和随机可删除UserDefaults suite，测试后清除临时suite；没有读写iPhone真实玩家容器。塔胜利来自正式内核运行器后交给正式GameStore，未冒充手动Unity战斗。回执中断由混合持久化字段模拟，未做硬件断电实验。

构建与规则测试：`tools/local-workshop/build_simulator_harness.py`、`tools/local-workshop/check.sh`。已安装独立宿主后，`tools/local-workshop/verify_simulator.py`可执行结算检查并导出报告；该脚本只面向本次专属模拟器。不覆盖真机玩家存档，不将模拟器宿主视为Unity视觉/真机整包验收。
