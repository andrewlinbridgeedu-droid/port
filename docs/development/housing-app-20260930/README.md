## 行为

- 赁屋行：首页铜名牌；无人背景、透明柜员、柜台前景独立三层。五步选房为看区、房屋卡片、室内三细节点、七天约与封蜡、搬家；六处住处、饮食菜单、等候登记均使用同一份目录。
- 用户指定的左侧远景是高级住宅区（高地石宅），右侧贵族区只作不可选地标。选房地图原样缩览 `CityAutumnDay`，不重画地貌。区名、房价和玩家名字均为可修改文字。地图坐标仍待真机复看。
- HousingService 异步接口后使用规则账本。太平洋日用 America/Los_Angeles Calendar（含夏令时），第一次打开日结，钱包与住处／体力共同写入现有回执。换餐不延长租约；签约不预收七天；当天已付款不重收，新档加成从下次日结生效。
- 日常制作、送信、街坊委托、余案、事件交货与事件战先授权体力，和任务回执一起保存。委托和余案全程用同一工作回执，重答、撤退重试不重复扣该工作的体力。事件战按每场票据收费，退场不返还。对传话在来源处主动接下时扣费。
- 所有新价格和体力花费读取 HousingStamina.swift。主线、塔层、通缉不加体力扣除；重复工作不再按第几单递减铜，保留原先功勋日限。旧模型可继续使用规则库的历史比例，App 明确使用体力方式。
- 首页住处名字门牌与一盏灯跟随选房；灯光走现有场景的昼夜开关。高地告示处只交入口、住户／今日付费资格和花费提示，不生成具体任务。
- 汤棚、面包坊与咖啡馆从相应柜台进入饮食登记，住处页也可换。宅内厨房按规则限制在高地石宅。
