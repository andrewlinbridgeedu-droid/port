# 从首页实际操作的租屋流程

修订版 169.12，源码 `f93210d`，iPhone 13／iOS 26.6。通过 iPhone 镜像实际点击，使用隔离账户 `mistport.housing-device-walk.20260930`，从 `--housing-screen=home` 进入。没有用阶段跳转完成流程；DEBUG 记录器只观察实际 UI 变化并导出原样窗口 PNG。19 张文件均为 1170×2532，哈希见 [export.json](export.json)，设备写出的顺序与时间见 [recording.json](recording.json)。

| 实际检查 | 记录或观察 |
| --- | --- |
| 首页打开赁屋行、翻住处册 | 真实点击首页名牌，再点击柜台按钮 |
| 看区、翻房子卡片、卡片回地图 | `00`–`03`；`00` 是 sheet 呈现中的原样帧，`02` 是返回后页面 |
| 进屋、分别点窗／壁炉／门印 | `04`–`07`，三处依次显示窗外拱廊、石屋干暖、封蜡记入口的不同文字 |
| 室内回卡片，再进屋 | `08`–`10`；`10` 是重进屋时详情重置的重复页面 |
| 看七日约、回室内、再看约 | `11`–`13`，6 铜房钱＋面包坊 12 铜＝18 铜／日，七天合计 126 铜但不预收 |
| 实际签约、盖章、收门牌 | `14`–`17` 为同一次按钮触发的四帧封蜡，`18` 为盖章结束后的新门牌页 |
| 搬家页返回、打开“我的住处”、滚动换餐 | 镜像中实际操作；从面包坊改汤棚，选中标记改变。这部分没有追加截图事件 |
| 住处回柜台、柜台回首页 | 镜像中实际点击；首页看见新门牌，钱包仍为隔离夹具日付后的 1988 铜。这部分没有追加截图事件 |

阶段截图脚本之后会重新启动自己的夹具；上一级住处／首页图用于页面复看，不表示保留了本次手动搬家的最后状态。此处 PNG 没有拼贴、修图或改文字，不是用户视觉认可。

流程在项目已有的 DEBUG 环境音静音参数下完成。此前开启环境音的镜像启动曾发生 Core Audio 崩溃，尚未修复；见 [异常记录](../AUDIO-MIRRORING.md)。安装后 Preferences 的最终比较见上一级报告；原始备份只在 SSD，不入仓库、不反写设备。
