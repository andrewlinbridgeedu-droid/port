# 主角背影视觉精修 · 2026-09-15

用户要求向《魔兽世界》角色美术完成度打磨，保留现有主角身份、衣装与轮廓。

## 本轮修正

实际战斗场景使用原 Fool mesh，不是历史 Nocturne 方案。检查发现：

- 原主角 normal PNG 按普通 sRGB 图片导入，不是 NormalMap，法线解码不正确。
- 原 Standard 材质仅连接 metallic 图片，roughness 没有接入；光泽来自 metallic 图片 alpha，不能表达原作者衣料与金属的不同表面。

新增 `HeroBackArtRefinement` 与 `HeroTailoredPBR`，保留原网格、UV、衣装彩绘、动作、场景光照。只修正 RuntimeModels/Fool 中重复资源的导入（原 Models/Fool 保留）。

- 接入正确导入的原法线及线性 roughness/metal 图。
- 暗衣料与金色镶边分别控制粗糙度、高光；保留原彩绘缝线和纹样。
- 只提亮被压黑的衣料阴影，保留深色衣装；加入距离过滤的微弱织纹及低强度冷色边缘光。
- 飘带丝绸与金色刺绣分别设定材质，不套全身金属值。
- 运行材质归组件所有，退出销毁并还原引用；不覆盖源材质，不影响错步残影 shader。

## 验证边界

同一实际战斗相机、同一动画姿态已输出 before/after：`output/hero-back-art-20260915/final/before.png`、`after.png`。720×1280，standalone exit 0，无异常/shader错误；已逐图查看。此轮是材质管线与辨识度修复，不代表已经达到暴雪美术完成度；模型拓扑、原贴图绘制质量、比例雕刻仍决定上限。不能把编译或截图导出当用户视觉验收。

## 第二轮实际背部设计

首轮同姿截图确认主角材质可读性增加，但背部仍过于空。第二轮降低过亮的灰色提亮和轮廓光，恢复深色衣装；增加上背双层人字金线、两侧收腰省道和中心小菱形纹章。纹样在实时肩/颈/髋骨确定的后背局部投射，限制在背部衣片，不铺满全身；金线参与金属粗糙度光照，不是发光贴纸。第二轮实际渲染已确认图案位于背部衣片，未溢到腿部或背景；恢复低调冷色边缘光，背部金线与现有领口/衣尾形成呼应。
