**看到的问题**

- 群体技能很强：内圈两只铜背在起步前就被开场的错步扫倒，外圈两只也多半走不到站位。
- 行走在这台低平相机下幅度有限；在整屏的旧特效里不够醒目。
- 旧路径里错步（以及敌人的部分招式）仍是整屏的特效，错步现在打 3 个，就是 3 份。
