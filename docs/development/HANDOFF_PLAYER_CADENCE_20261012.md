# 交接：主角连续出招节奏 · 2026-10-12

## 原因与修改

第四关使用战斗节奏样本配置，技能起手后的出招锁定为 1.1 秒、普攻为 0.8 秒；第五关等非样本场景的旧回退值仍为 1.75 秒和 1.65 秒。两张牌即使均已就绪，也被旧锁定隔开；普攻也会拖延刚恢复 CD 的牌。

App 的连续战斗、主线重放步进器和教会步进器现统一回退到 `MPCCombatTempo.standard` 的主角回复间隔：技能 1.1 秒，普攻 0.8 秒。卡牌自身 CD、普通场景普攻 2.4 秒间隔、每击伤害和敌人参数保持原配置。敌人轻击及伤害缩放仍只在原有三个节奏样本启用。

已就绪的牌更快相接，不要求等待整场技能特效收尾；规则命中仍在各卡原有时间到达。缩短锁定会改变自动出牌与普攻穿插时序；观看和跳过使用同一推进过程。
