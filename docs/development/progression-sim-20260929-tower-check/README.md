## 为什么纯数值墙做不成

用探针加 `GEAR_SCALE` 量过：Q18 要让“只有 F10、带药、任选出牌和遗落物的高熟练”必输，同时“F50、第一套配置、不带药的中熟练”稳赢，F50 装备要到 +114% 攻击、+650 生命、23% 减伤（原来 +46%）。带药和换打法带来的差距大约等于战力翻倍，每堵数值墙都要求相邻两个门槛之间战力约差一倍。照此推算，到 F90 大约 +300% 攻击、40% 减伤，其他关卡、通缉和塔后半段都会变得很容易。

## 改了什么

**塔层装备检定（新机制）**：Q18 裁定者第十三击、Q26 押运车猛砸、Q30 总签官猛砸，身上没有来自要求层（F50/F70/F90）或更深的塔装备时，按基础生命的 140% 结算；穿够深的装备就按原来的伤害算。“身上装备来自的最深塔层”是新加的 `MPCChurchGearStats.towerDepth`，由装备账本算出。所有战斗入口都用 `ledger.stats`，所以 App 不用改。Q8 不做检定，仍是输出竞赛。

| 3 | 高熟练只做通缉卡在 Q8 | ✅（三档、三个起始日都卡 Q8） |
| 4 | 低熟练三条线都做能通关；只补必需支线时，支线 ≤ 主线 2 倍 | ✅ 9 局全部通关（全都做、先清支线、按提示各 3 局）。按提示补支线：支线 88.8 分钟（塔 86.5，通缉 2.3，只做了 B01、B04、B10），模拟器主线 249.7 分钟，比例 0.36。见下方说明 |
| 5 | 低熟练能过 Q1–7 | ✅ |
| 6 | 满足要求后中熟练首次不用药能赢，不是险胜 | ✅ Q8 39%、Q12 28%、Q18 65%、Q22 50%、Q26 53%、Q30 59% |

**第 4 条的分母要注意。** 模拟器的主线时间含机器人把每种出牌、遗落物、勋章时机都试一遍的失败局，偏高。如果按“准备好了再打”的主线时间估（先清支线打法第 30、90 天的主线：高 28、中 29、低 40–46 分钟），必需支线 75–89 分钟约是主线的 1.9–2.7 倍。必需支线几乎全是爬塔到 F90（约 73–87 分钟）。如果要按严格口径压到 2 倍以内，可以缩短每层耗时，或把 Q30 的塔层要求往下调。

## 模拟器本次的改动

- 新打法 `hinted`：卡在墙上时只做失败提示要求的事（爬到要求的层、做对应的案），做完先换打法重试；不是墙或仍然输时才像 `all` 那样继续。它的支线时间就是第 4 条的“必需支线”。
- **修正第一轮的一个结论**：第一轮把“低熟练卡 Q8”归因于通缉战败丢光遗落物。这次改成只扣铜后仍然卡，查下来是模拟器的问题。低熟练在 F10 打 Q8，16 套打法里只有“返礼银扣＋第 14 秒勋章＋带药”能赢。机器人每次都把唯一一瓶药用在第一套打法上，换打法的重试又被“同一状态已经输过”跳过，而且爬完塔后不再重试。现在重试从另一套完整打法开头，药用掉输了就停，做完支线、判定卡关之前也会再重试。
- `WALLS=` 新增 `q18GearCheckHP`、`q26GearCheckHP`、`q30GearCheckHP`；探针新增 `GEAR_SCALE`。
- 注意：Q18、Q26 满足塔层后首次剩血 46–65%，战斗本身不难。挡人的是检定，不是这场仗。如果想让墙关打起来更有压迫感，可以再提敌人血量和攻击，不影响墙是否成立。
