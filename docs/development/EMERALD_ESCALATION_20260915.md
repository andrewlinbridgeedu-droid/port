# 翠焰亡灵持续毒雾与遗落物暂停 · 2026-09-15

用户新方向覆盖此前铃契约、三次固定毒跳与自动假面：开场毒雾越来越浓、伤害递增直至战斗结束；绿焰预告大招，两次无防护命中致命；假面留着使用。按用户“全部先去掉”暂时全局关闭遗落物，未删原资产和历史持有记录。

## 当前实现
- 翠焰亡灵首次memory_breath，之后仅charge→emerald_burst循环，不重复重置雾。
- 以1000最大HP为例：毒雾每3秒20、25、30……伤害；公式为初始2%最大HP，每跳增加0.5%。持续到胜负结算或显式取消/重试；不消耗假面。不是原66×3。
- 大招伤害至少ceil(最大HP/2)，受正常护盾/保护等防御影响。两次无防護直接命中致死。绿焰蓄力3秒。
- Q5假面不参与自动循环，须战前手动编入卡组，战中点击后在当前动作完成时释放。沿用正式技能2次承伤、12秒实时冷却；没有把旧试演4秒/1次承伤规则全局化。重试清空排队请求。
- 雾由权威浓度级别驱动，薄雾逐步加浓；敌人绿火使用真实可见骷髅范围，不使用隐藏猎犬包围盒。战斗停止/重试清雾与绿火。最后集成将毒雾固定在战场主角初始位置附近，避免假面出现时整片雾跟着假面偏移。
- relicsEnabled=false阻止正式与旧副本有效装备/效果及新奖励；保留历史拥有/耗尽/装备记录，暂停旧纸人→铃迁移。
- 删除交铃、铃债务、后续遗落物赠予与领取承诺；保留主线调查和怀表/身份牌等物证。隐藏行囊、角色装备、构筑及旧副本遗落物入口。移除旧纸人遗落物连招提示K07。
