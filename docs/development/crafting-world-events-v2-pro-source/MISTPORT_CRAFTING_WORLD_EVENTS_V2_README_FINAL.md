### 永久效果的实施解释
- mistcoat：开放高级织造世界条件；新人仍需个人等级/熟练度/图纸/材料。
- alternate_route：本地成功再给基础生产×1.05；失败后30周期仅世界路线技术到达，不给本地+5%。
- pump_restored：成功澄清药基产能+20/周期；失败扩散后仅+10。
- steamshop：高级皮革/金属世界门槛；成功再给基础生产与制作容量×1.15，失败45周期只解技术。
- medroute：开放盐雾茶世界门槛；成功澄清药基+30，并以trade账户全额支付一次有限外部进口：修复胶质最多560@5、盐晶粉420@3；失败只+10，无免费进口。
- injury_surge：仅暂时需求冲击，无永久配方门槛；失败后需求余波7周期，事件仍关闭。
