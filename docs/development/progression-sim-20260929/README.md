## 为什么按生命百分比

Q22、Q30 原来的惩罚按敌人攻击力放大（160%、125%）。塔装备一上来，玩家几秒就打完，惩罚来不及生效，怎么调倍数都挡不住。改成按玩家生命百分比，装备再好也扛不住，只有对应的遗落物能解。

## 没解决：Q18、Q26 数值墙做不出来

塔装备曲线太平：F10 已经给 +36% 攻击、11% 减伤，F50 也只有 +46%、16.5%，F90 +56%、20.5%。扫了 Q18 敌人血量 2400–4800、攻击 112–190、第十三击 200–260%：只要“F50 中熟练首次不用药稳赢”，“只有 F10 和缺齿剑的高熟练带药”就一定也能赢。Q26 同理。所以 Q18、Q26 仍是旧值，现在不是墙；Q30 墙上写的“F90”实际也不是必要条件，真正挡人的是寿账签。

可选方向，需要用户定：

1. **拉陡塔装备曲线**，例如每 10 层攻击 +10% 以上。会改变塔本身的难度曲线，要一起调塔层敌人。
2. **把 W3、W5 也改成机制墙**：Q18 用 B09 吞契铜背甲（克制蓄力重击），Q26 用 B06 无灯舱甲（克制押运车）。这两件原本排在第二批。
3. **只保留 W1 一堵数值墙**，塔改为给容错和省时间。

## 模拟器本次的改动

- 通缉结案发遗落物，不再发装备；主线按墙换上对应遗落物；日刊保底。
- 卡关时会跑 J0 邮务再买一瓶止痛膏，并在重试时换一件遗落物打头，像真人换打法那样。原来的机器人会在同一套输局上反复耗药。
- `walls` 模式：一秒内查完六堵墙（光板、只有之前墙的要求、塔全开不带本墙遗落物、最低塔层、首次不用药），用法见 `main.swift` 顶部。`fight` 模式逐套打法列出一关的结果；`TRACE=1` 打印每次敌人行动。
- “全都做”打法的主线时间偏高（250–900 分钟），是模拟器每爬一层塔就重打一遍主线造成的，不能当作玩家耗时。看耗时请看“先清支线”那一行。
