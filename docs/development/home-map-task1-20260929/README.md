# 首页港城任务 1 · 2026-09-29

从 main `d39e0ed` 开始，现已合入后续 main `931a81a`，将现有四季首页接成港城任务入口。用户授权按路面和入口修正坐标；又要求日刊移到报社、报馆有绘制的人物和报纸，并指出人物比例和纵深行走朝向的问题，本 PR 一并修正。

## 结果

- 首页读取与设计目录一致的 `home-map-layout.json`：三街区、道路、出入口、H1–H10、建筑与岗位。修正穿墙路线及广场、货场岗位；等候点的进场路径固定在可见道路上。
- 23 名街坊与建筑岗位、四位服务人物分层绘制；按身体真实可见范围和道路纵深缩放，同屏最多 10 人；页面被覆盖或应用不活跃时暂停。普通街坊只停步寒暄，约 4 秒后续走，不写存档、不发奖励。
- 原近景 Canvas 人物层退出首页，避免与新人物叠加、产生远处人物比近处大的错觉；远处不可点的运河气氛人物保留。
- 利用原有 16 个行走模型新渲染八方向、各八帧图集。沿当前路段切换背面、正面、侧面及斜向，不再沿纵深侧身滑动；原模型和旧图集不改。[方向对照](direction-proof.jpg)。
- 莫尔按用户最新要求通常留在酒馆，每半小时窗口错开外出时间，外出约 48–72 秒，街上点他只寒暄；牌桌从酒馆进入。老水手接既有牌局，商人接既有铜币商品，咖啡馆接既有补给，沿用现有开放条件。底栏真钱商店保持原入口。
- 用户要求咖啡馆店主通常在馆里做生意，偶尔满城外出。首页新增咖啡馆入口；店主仅约 8% 的环境周期外出，经过大道、广场和货场，从出入口换街区，街上点她只寒暄并提示进馆。任务召唤不受外出周期限制。未开放的咖啡馆和牌桌也有明确返回按钮。
- 新增邮局、诊所、港务处、旧街铺面、委托板；市政厅和警察厅进入柜台。委托板、港务处、市政厅、邮局、商人、诊所、警察厅、旧街铺面分别绘制无人的固定场景与独立透明人物，柜台前景遮挡人物下半身。换人只换人物层，背景固定；按钮和价格仍是原生文字；[原场景提示词](counter-art.md)、[分层原画与接入记录](layered-counter-art.md)。有相关通缉任务时柜台提供同一规则接口的问话，平时只寒暄。角色、教会、商店、行囊四枚底栏图标缩小 12%（169.6 的 8% 调整后，用户要求再小一点）。通缉任务接口由规则库给出人物、地点与当前节点，任务条可收起、切换及平移到目标，相关人物约 7 秒内到等候点。
- 日刊通过报社打开；取消底栏蓝色日刊按钮，首次每日自动提示沿用。报馆以固定的无人印刷室叠加编辑或排字工，切换人物保持房间不变，印刷机与纸张留在背景，可读内容呈现在纸色、报头与栏目排版中；残余案采用同类纸张的附刊页；[画面与生成提示词](newspaper-art.md)。
- 3D 街道、旧港城图、通缉调查地图的运行入口退出；旧源码与素材保留。日刊的街坊委托回首页委托板。世界事件和街坊委托的新任务流程按任务单留给下一单，未在本 PR 改结算。

## 验证边界

截图是设备渲染证据，不代表用户认可。八方向动作仍需用户在亮屏真机上看往返步态；CADisplayLink 仅记录主线程回调，不能当作 GPU 实际呈现帧率。当前通缉接口先承载原有节点，B07 六环与送信分别在任务 3、2 实施。
