# 翠绿持续毒雾美术优化（2026-09-15）

用户批准优化毒雾演出；本批不改持续加浓、每 3 秒毒伤递增、假面或大招规则。

旧版问题：头顶与地面云片一起覆盖中央视野，绿色烟贴图的重复取样造成平铺感，读不出气流方向和层次。

本轮实现：
- 毒气主体改为宽而低的三维气团，由脚踝逐渐抬至膝侧；不再生成头顶烟雾天花板。
- 42 股不同深度的云丝各自出生、卷动、扩散及消隐，以连续程序密度代替烟贴图四分之一取样。
- 体积内有缓慢水平旋涡、上升细雾和不同速度的细节层；暗翠内部与黄绿薄边表现厚度。
- 浓度消息仍由原生战斗控制；视觉平滑追随，不在本地计伤或决定毒雾结束。
- 共享体积着色器同时改善开场放毒云，保留返场 Burst 参数和全部调用契约。

备份：`backups/emerald-fog-art-20260915`。
