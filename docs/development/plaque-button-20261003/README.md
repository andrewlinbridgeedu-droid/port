# 大按钮文字被挡住 · 2026-10-03

用户在模拟器的胜利页上看到“继续 · 前往后续”按钮，说“这些btn似乎都被挡住了”。

**原因**：`MistportPlaqueButton`（非紧凑款，`SceneViews.swift`）的底图 `ButtonArt25MainAction` 是 866×192，上面 45 pt 是透明带，用来放右上角那支羽毛笔，米色板子在下面 76%。原来用上下各 25 pt 的拉伸边距把它压进 62 pt 高的按钮：
- 透明带落在被压缩的中段，板子只剩下半截（约 35 pt）；
- 标题仍按整个按钮居中，正好压在板子上沿，上半截落在深色页面上，看起来像被挡住。

这个按钮从 9 月 26 日导入起就是这样，9 处用到它：胜利页、地下城战利品、任务板、构筑等。

**改法**：整张底图按比例铺满 74 pt 高的按钮。全宽时接近底图自己的 4.5:1，`GameArtButtonStyle` 也是这样用这张图的。标题下移 17 pt，落在板子正中。按钮因此高 12 pt。

**核对**：`plaque-button-before-after.png` 是用 `render.swift` 在 Mac 上照同样的布局渲染的（字体与手机略有差别），不是手机或模拟器截图。
