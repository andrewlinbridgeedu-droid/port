## 关键结果

- 保留七张普通牌的 ID；新增 11 抢拍开幕、12 碎镜连弹、13 延时落款。退休的 02/03 不复用，假面/无名独立于四格。
- 四格严格循环；技能 CD 初版统一 7 秒，加速只改施法、后摇和固定引导的频率，不偷改敌方时钟/CD/状态寿命。
- 10选4 = 210组 × 24排列 = 5,040。六类夹具共 30,240 场基础枚举，各有 5–17 组可行配牌；只在可行配牌内部，73.4%–90.5% 的排列失败。
- 同样“抢拍、落款、连弹、错步”：首 7 秒顺排 882，反排 314；6发对3发，落款累计7次对1次；单体夹具24种排序有4种能过。
- 没有固定排序通吃六类夹具。最泛用的加速/后手/落款/连弹可过四类，后续要继续审计其优势。
