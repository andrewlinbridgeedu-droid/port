## 统一标准

1. 每个法术有独立身体动作：起手、蓄力、发力、收势均可辨认。不能只换颜色、旋转特效或复用同一Cast动作。形态合适才抬手，犬用颈胸与四肢，蛇用冠喉与尾链。
2. 发力与真实contact同步，先动作后爆发；蓄力清楚、命中只结算一次。大幅动作不能移动既定站位或改变伤害、冷却、玩法。
3. 命中炸开的瞬间明显放大，然后快速回收。D04四倍峰值＋双倍切面/碎片、D06四倍主体为已认可参考；其它怪按自身形态达到同等力度，不盲目把所有尺寸乘四。治疗、护盾、强化是独立状态表现，不套伤害爆炸。
4. 细节沿实体结构展开：骨节、刀口、晶面、石层、囊膜、声纹各不相同。保留大片、绚丽、有光彩，不退回细小微光，也不依赖通用粒子云遮住动作。
5. 待机、受击、死亡与施法衔接自然；取消、死亡、跨波、重试清理特效并恢复骨骼/材质。多敌目标正确，治疗/强化接收者死亡按既有契约取消。
6. 每招交付真实战斗全景GIF/视频及无遮挡的怪物动作近景，至少能看清蓄力、发力、命中、收势；检查正常命中、取消、死亡、重试。Unity验证、手机测试、用户视觉认可分别记录。
