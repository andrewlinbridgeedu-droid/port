# 主角头手结构制作 · 2026-09-17

本批接在 Hero Premium 之后。保留黑发、紫黑金衣装、主角身份及既有战斗规则，增加真实指骨和连续眼睑网格。尚未达到《魔兽世界》成品角色的美术完成度，不把技术检查称为视觉验收。

## 实际修改

- 原 24 骨之外新增 30 根分节指骨，每手五指、每指三节；双手实际顶点权重参与变形，未冒称原 Humanoid Avatar 已有手指映射。
- 右手原生成模型一处多余指状突起删除并封口；手部轻度平顺，保留手套和原 UV。双手分别 3,798 / 4,362 三角。
- 眼孔边界与八圈眼睑连接成连续脸部网格，加入眼球、虹膜、瞳孔和真正的 Blink 形变。虹膜使用既有原画投影，眼周使用脸部 UV；不以换贴图冒充眨眼。
- 手指待机轻微弯曲，不同施法有保守的指节差异。所有旋转从绑定姿态计算，关闭或角色隐藏后复位；死亡碎裂前短暂保留当前姿态，不声称死亡开始即复位。
- 修复第 06 招双影对可读 BlendShape 网格漏烘焙的问题，使残影保留生成瞬间的眼睑形态。
- 替换部分合计 59,966 三角；身体其它面、滚边、衣带另计。原始英雄 FBX SHA256 与上一批一致。

## 证据与边界

实际 Unity 手部差分测试冻结原动画作者后比较 BakeMesh：左手最大 8.343mm、右手 9.431mm，分别有 1,395 / 1,671 个运行顶点移动超过 0.2mm。30 骨、10 指、关闭复位、重开无重复、取消恢复均通过。

实际眼睑最大位移 16.75mm（包括向眼球前方的弧面运动）；自动闭合/睁开和关闭组件复位已通过。手动抓拍等待下一帧蒙皮更新，避免将 GPU 前一帧误标为当前 BlendShape。

最终检查与构建状态见下方交付记录。完整截图、视频入口为 `output/hero-anatomy-20260917/index.html`；Blender 母版展示图与 Unity 运行图分别标注。

仍有明确美术缺口：脸部鼻唇/下颌轮廓来自旧母版，眼周过渡和发束造型需要进一步雕刻；衣装部分纹样有拉伸，尚无完整表情、口型和大幅抓握动作。这一批是结构升级，不是全角色重雕，也不是魔兽品质验收。
