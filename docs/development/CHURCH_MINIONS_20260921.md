## 战斗边界

- 两招都是对主角的一次直接伤害。第一招与第二招分别一次真实 contact，均为该单位 attack；不新增束缚、治疗、护盾或召唤，只凭造型不产生未定义状态。
- 两次准备分别 2.2 / 2.8 秒，接触各 0.5 秒，恢复 4.5 秒，沿用原 D01 普通槽的 HP 与 attack 预算。移除原槽真盾会改变可攻击窗口，须核心模拟验证，不能仅凭相同总伤宣布平衡。
- 首现及后续复现只替换明确的普通 D01 槽；不增加波内人数，不更改十层末精英和六旧种的首次教学。
- 每波最多四敌、同一时刻一个高威胁准备、已有层号/首通奖励/开放门槛与进度键保持。旧怪稳定 ID 不改，新种追加独立 ID。
- 接触视觉停顿使用局部视觉时间；不暂停战斗时钟。接触后快速撑大再回收，每种维持自己的形体和运动方向。
