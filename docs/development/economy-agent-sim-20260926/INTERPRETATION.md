# 如何从结果改设计

本文件是离线实验的解释，不将参数直接写入游戏。完整批次数量和数值以同目录RESULTS.md及各批次独立审计为准。

## 先算实际产能，再讨论发多少钱

在本模型假设下：2000账号，活跃率50%，每活跃周期平均0.65次塔胜，每胜18%概率产生一份药品消费需求。

`药品需求 = 2000 × 50% × 0.65 × 18% = 117份/周期`

每份药需要1份药基。原模型初始药基产能70，成功修复泵站增加20，总计90。忽略其它缺料、NPC事件用药、产能闲置和库存缓冲，长期药品供应上限也仅为需求的 `90/117 = 76.9%`。没有泵站时为 `70/117 = 59.8%`。这与实测模拟履约的数量级一致，供给缺口不是增加钱就能消除。

高活跃80%时需求187.2份，同一产能的上限为48.1%。如果用20%的需求缓冲做下一轮测试，正常活跃所需药基约141份，高活跃约225份/周期；这只是必要产能估计，材料、制作人手、现金和库存同时满足才充分。不能直接把产能调到225就宣称通过。

由此可优先测试：有真实成本的泵站扩建、不同活跃规模的初始生产配置、让玩家能找到目标材料的塔层说明、合理的替代配方，以及事前有预算的药材储备。世界事件可消耗储备并制造新需求；突发需求超过可用库存时不得靠无限NPC生成补齐。

## 发钱与回收需要单独的发行账

源码Q30重玩每次105铜，不能用旧“每活跃日8铜”代理。假设1000名活跃玩家各重复一次已通关Q30，即105,000铜/周期；实际到达Q30时间与重复次数仍需建模，不能把这当当前真实日发行。

对照2000名合格玩家每7周期领取28铜、其中30%月卡额外28铜的长期满额上界，补给平均约10,400铜/周期。一次高阶重玩发行可以远高于补给。更高频重玩尚未跑入本轮（最多每活跃周期一次），所以不能把本轮当反机器人或无限刷金上限测试。

全年发行包含一次性首通，不能要求开服全年发行与销毁机械相等；还要单列末90周期持续发行、货币存量、实际需求和购买力。货币存量增长不自动等于同幅度通胀。

不得为凑平账偷偷删现行奖励。下一轮继续离线比较真实重玩频率、一次性进度支出、可提供实际价值的回收用途和未来共享服资产准入规则。手续费只是对已经发生的交易回收，不能假设所有发出去的钱都会高频成交；更高税也可能压低工艺净收入。

## 不把价格下降当成功

这个模型有固定价NPC底料、有限耐用品需求和逐步换档的配方。某一档商品跌到低价、没人再买，可能是过剩或被替代，不是健康的经济。旧购物规则和无利润约束的生产作为控制组保留；优先看允许替代购买、成熟工匠避免亏本的批次。

固定篮子里的基础药膏若不再成交，应显示NA。不能用后来的高级药简单替换，继续沿用原基期价格并声称购买力稳定。下一版应依据明确药效单位建立可比的功能消费篮子，并同时给出固定SKU篮子覆盖率。

职业需要同时检查投入的时间、材料机会成本、现金费用、实际成交收入和未售库存；本轮按职业分组的市场净现金流含个人买药/买装备，不能直接称为专业制造利润。完整配方成本、药效、角色实际携带遗落物及晋阶支出补齐后，才能冻结正式货币标尺。

## 当前可以得出的结论

可以继续用离线多组模拟排除明显不合理的设计，无须先让真实玩家承受未验证参数。可以冻结的是验证方法、账本边界和第一阶段功能范围；不能把本轮粗化行为及占位配方输出当成正式掉率、月卡额度或共享市场上线许可。

## 修正购物与利润约束后的对照

四组各5种子。基准免费药品履约均值74.38%，二倍供给94.54%（93.00%–96.29%），三倍供给94.51%（93.07%–96.31%）。这组占位规则下，三倍供给没有相对二倍带来清晰额外收益，先把二倍作为后续测试起点更合适；不是正式掉落批准。

二倍供给仍未通过全部价格检查：例如种子101固定篮子从最初30期约1.152降至0.606，后来缺少基础档成交而成为NA。这里包含供给增加、训练生产、产品换档等影响，不能把失败统一说成通胀，也不能挑低价时期宣称稳定。基准同种子可见篮子从1.182升到1.485，但尾期也出现NA。

当前20%门槛衡量单个30周期窗口变化，不能排除多个小幅上涨累积成长期通胀。下一轮应在冻结需求与可比商品篮子后，同时预设全年累计购买力变化和事件后恢复窗口；这些是新增要求，本轮没有事后改门槛让结果过关。
