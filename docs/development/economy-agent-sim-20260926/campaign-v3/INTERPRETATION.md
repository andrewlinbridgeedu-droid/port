# 27组工艺—封印物—战役实验结论

2026-09-27。已完成9种场景×3个种子，每组2000成熟账号、365周期。不是游戏实装，也不是2000真人测试。候选价格固定，用于检查物资与支付链能否运行，不能验收通胀或价格自发平衡。

## 已完成与尚未完成

已将四专业生产链、真实塔编队来源、有限进口及商人钱包、普通遗落物使用磨损/维修、玩家交易、绑定系统药、阵营采购和未使用投资款退还接入同一离线模型。游戏现有奖励和存档未改。

独立读取输出复核了27次运行、9,855个模拟日、2,516,108笔成交，资金恒等式与交易算术通过。物品守恒有模型内逐日断言；未做独立完整库存流水重放。30项相关单元测试通过。账算对不等于经济通过。

规划已有两方利益、关键NPC可挑战击杀、继任与项目后果、24条条件新闻和正文样稿；它们仍是候选剧本。当前模型只计算物资及累计胜场达标，没有模拟真实NPC战、独占合同胜负、经营分红、新闻刺激参与或高级封印物购买。

## 主要结果

下表为每组3个种子的年均铜币；战役均为一年两次，7周期准备、3周期行动。

|离线奖励候选|总发行|销毁及进口净流出|净增|实际交易总额＋基础料NPC销售|
|---|---:|---:|---:|---:|
|每活跃周期一次Q30现金105|42,276,183|1,124,134|41,152,049|1,373,016|
|每7周期首次合格Q30现金105|14,374,638|1,124,134|13,250,504|1,373,016|
|每14周期首次合格Q30现金105|9,336,073|1,124,134|8,211,939|1,373,016|

这不是通胀率，也没有证明玩家会每天如此刷关；Q30完整战斗时间和额外消耗未建模。三种规则的商品结果近乎相同，因为成熟账号在固定低价下都付得起，并非货币政策无关紧要。7/14周期没有成为已批准游戏规则。

1. **基础工艺链可运行，但尚不能称四专业均衡。** 无战役时免费玩家日常药品由工艺满足99.55%，绑定系统药补0.45%；模拟总履约100%。药品包括自产自用，不能把全部履约叫作市场成交。无战役成品首次销售率分别为织造81.27%、皮革56.19%、金属90.31%、炼金70.70%。自用不算销售，皮革同时有约5,162件期末库存，提示需求偏弱。固定售价和自采零现金成本不代表真实利润。
2. **普通封印物消耗确有回收，但不够大。** 无战役普通维修年回收约583,161铜，战役后约593,629铜，增加约10,468铜。全部额外销毁/进口净流出合计约18,640铜。不能由此把高级封印物也记成已验证的需求，更不能为填账强抬必需维修费。
3. **当前战役达标条件过松，准备期价值未证实。** 各候选每阵营的6次事件均通过150份药与100胜的门槛；取消准备期、人数70:30仍全部通过。这只否定本参数下的准备压力，不是否定准备期玩法；成熟库存与固定参与概率没有表现真实玩家决策。两方同时达标不等于双方都赢得独占合同。
4. **此时新增系统采购发行没有缓解缺货。** 每年新增12,000铜的对照，药品履约和生产与已有财政资金采购相同，仅净增货币多12,000。当前场景不是缺买方现金，不能把发行当常开按钮。真实冷服或买方预算不足仍可另测有限采购。
5. **投资收益尚未模拟。** 年投入40,000铜、退还未花款约32,288铜；这是资金使用及余款退还，不是80.72%收益率，也没有经营利润。用户希望少数投资正确者积累财富的路线，还需实际项目收入、成本、交付及风险结算。

## 对最新玩法方向的取舍

保留“挑战需要物品→工匠生产→忙碌玩家购买→物品真实消耗”的方向。但物品消耗与铜币销毁分开：药剂喝掉、封印物燃料用掉，销毁的是实物；向另一玩家买货只转移铜币。付给可继续采购的NPC也只是转移。只有明确退出本服的钱才回收货币。

新闻战役、生产、投资与财富差异可以成立；不能预设它们自然抵消无限重复发行。当前不具备冻结共享自由市场数值的证据。也不将银行收益写成系统保底印币。

## 下一步按这个顺序收敛

|优先级|具体工作|必须留下的证据|
|---|---|---|
|1|隔离战役原型：外围开路→核心NPC挑战→唯一死亡/继任→新闻及项目结算；沿用现有战斗，不加护送AI|重复回调不重复死亡/发奖、迟到挑战一致结算、双死不发两份独占合同；正文只引用已结算事实|
|2|选择现有普通封印物做配装对照，测准备带来的战斗差别|同一遭遇、装备组合、完整时长、胜败、药耗、磨损；从真实差异确定需求，不把随机45%胜率当战斗平衡|
|3|用测得的消耗改战役资源门槛，同时测低/中/高参与、库存、阵营比例|无准备与7日准备能出现可解释差异；小阵营有可达路线，外围贡献不要求购买高级装备；失败可有剧情后续|
|4|再加入库存影响报价、买方愿付上限、卖方成本底线和有限成交深度|免费/月卡分组支付能力、四职业实际利润/自用/积压、事件前后成交价；原料机会成本无可执行报价时标未知|
|5|接项目营业收入及成本，再接有限发行采购对照|分红来自真实净收入；发行只针对可验证现金不足且真实有用的有限需求，不保证所有商品卖出|

以上是后续实施顺序，不是已执行的测试。不把“继续调高战役药量”当作让游戏好玩的证明；高难核心应先通过配装、技能和操作体现挑战。
