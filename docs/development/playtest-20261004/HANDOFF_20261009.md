## 3. 现在的实现（`UnityBattleSource/Assets/Scripts/SpellSpectacle20260926.cs` 等）

### 3.1 猎犬扑咬（`early-hound` 敌方命中，`ClawHit`）
- 主体 = 用户手绘爪痕 `PaintedClaw`（`PClaw` 格），着色 (1,.4,.12) 深橙红、自发光 .25、0.46 秒。
- 外加 `Ink2D "clawfx"`（只画光，不画月牙）：两层弱光晕（.06/.1）、冲击星（放射刺 + 八角闪 + 一道冲击环）、18 条短亮线、火花。尺寸 `.33 × 可视半高 × tier`。
- `Ink2D "claw"`（代码画的三片月牙）仍在代码里，`Claw(t, strokes:true)`，但不再被调用——用户说"粗糙"。

### 3.2 主角普攻（`paper`，`InkHit` → `Ink2D "burst"`，尺寸 `.24 × 可视半高`，0.62 秒）
照"曜与霆"原始版 `FireExplosion`：三层叠加光晕（偏弱，主要给辉光后期当光源）→ 9 道宽半透明光芒 → 一道冲击环（0.3 秒扩散变淡）→ 16 条细的加法发光能量丝（宽柔底 + 窄亮芯、卷曲、向尖端变暗）→ 扭动大火团（40 点、fbm 幅度 .24、0.6 寿命内收掉）→ 极短白闪 → 28 条短亮线 + 火花 + 碎片。配色：外 `9A2EF0` / 次 `D45CFF` / 体 `FF6AD0` / 芯 `FFC4EE`（淡粉，不是白）/ 热 `F4B0FF`。

### 3.3 着色器 `Resources/SpellSpectacle20260926/SpectacleInk20261008.shader`
mode 0（色阶）改为"画意"而非卡通：色阶门槛 .16/.42/.80、过渡带宽 .07；交界随流动噪声游走（`V()` 把以 size 为单位的局部坐标写进 `u2.w/u3.w`）；内部细亮丝；亮度起伏；外缘 alpha 柔化。mode 3（加法）不变。

### 3.4 `Ink2D` 其它修正（对应上一份 §4.4）
- `Crescent` 的 `Pow(sin)` 加 `Max(0)`（NaN 已无）。
- `Ring()` 删除，改为两端收尖的不闭合 `Arc()`；另加 `ShockRing()`（单层、粗细按 fbm 不均）只用于"一闪而过的冲击环"。
- `SmokeDisc/FlatDisc`（灰烟片）、`Bolt/Polyline`（雷电）删除。
- `Flame()` 多了 `curl`、`mode`、`tint` 参数（加法能量丝用 mode 3）。`Dot()` 多了 `amp`，点数 24→40。

### 3.5 命中压暗
`Burst()` 里 `darken`：主角普攻（Form.Flick）0→.22，敌方轻击 0→.18（让光在亮大理石上显得出来）。

### 3.6 法术层辉光后期（新）
- `Scripts/SpellBloom20261008.cs` + `Resources/SpellSpectacle20260926/SpellBloom20261008.shader`。
- 挂在主相机（`SpellSpectacle.LateUpdate` 里有特效时 `Ensure`）。每帧把 SpellSpectacle root 下的渲染器（排除材质名含 `Wash`/`Dim` 的全屏染色与压暗）画进半分辨率缓冲 → 4 级双重模糊下/上采样 → 以 `Intensity = .28` 叠加回 `CameraTarget`（CameraEvent.AfterForwardAlpha）。没有法术时命令缓冲为空。
- 只照亮法术周围，不让白大理石/天空发光（整屏 bloom 会全白）。强度 1.1 时整团冲白（bloom1）。
- 环境变量 `MISTPORT_SPELL_BLOOM=0` 关闭（编辑器 A/B 录制用）。
- **影响所有华彩层特效**（不止这两招）：A/B 视频 `output/hit-feel-20261008/bloom-off-vs-on.mp4` 含错步穿行卡牌和 H07 彩虹弧。其它招式开辉光后有没有过亮，没有逐一看。
- **手机性能没测**。

`AGENTS.md` 第 7 条与 `.claude/skills/mistport-spell-spectacle/SKILL.md`（主仓库 + worktree 各一份，主仓库的两份也都改了）加例外："命中瞬间一闪而过、向外扩散并变淡的冲击环可做陪衬，但不能当主体、不能多层同心"（2026-10-08 用户同意）。
