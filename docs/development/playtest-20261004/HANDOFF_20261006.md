### 2.2 怎么合入 main

worktree 分支和 main 的历史不同，**不要 merge 整个分支**。每个提交单独套到 `origin/main` 上再推：

```bash
cd "/Volumes/andrew's SSD/Mistport-worktrees/hero-v4-device"
git fetch -q origin main
BASE=$(git rev-parse origin/main)
C=<分支上的提交>
OUT=$(git merge-tree --write-tree --merge-base=$C~1 $BASE $C)   # 输出含 CONFLICT 就停下手工处理
NEW=$(git commit-tree "$(echo "$OUT" | head -1)" -p "$BASE" -m "$(git log -1 --format=%B $C)")
git push origin "$NEW":main
```

所以分支和 main 显示"领先 18 / 落后 19"是正常的：分支上的提交在 main 上都有一份内容相同、哈希不同的副本。


- 步骤：Unity 导出 iOS 模拟器库 → 导出新鲜度检查 → Xcode 构建。约 25–35 分钟，建议后台跑。

### 7.2 查证：Q1 的盾为什么"消失"

Q1 守卫的控制印记保护层是 `GuardianWard`。旧版只画四条宽 0.06 的半透明细缝，手机上等于看不见。原件备份在 worktree 的 `backups/spell-spectacle-20261005/original/GuardianWard.cs`。

### 7.3 现在的实现

| 文件（worktree 内） | 作用 |
|---|---|
| `UnityBattleSource/Assets/Scripts/OvalLightShield.cs` | 新组件。用 Unity 内置球体网格缩成椭球，按身体渲染包围盒贴合；宽度封顶为身高的 55%（防止被横举的剑撑大）。`Attach` 常驻，`Flash` 定时亮起。不透明度 = 慢速潮汐（最低 18%）× Perlin 闪烁。支持 `Impact`、`Break`（放大碎散 0.55 秒）。 |
| `UnityBattleSource/Assets/Resources/Shaders/OvalLightShield.shader` | 加法混合。菲涅尔边缘 + 沿 `_FlowAngle` 扫过的流光带 + 绕膜游走的高亮能量纹 + 反向慢流 + 漂移亮点 + 可选晶面格闪烁。 |
| `UnityBattleSource/Assets/Mindstone/VFXV1/Extensions/aura-guardian-ward-v1/GuardianWard.cs` | 重写为 `OvalLightShield` 的外壳，接口（`Attach / Impact / ImpactAfter / Break / ISpellExtension`）不变，调用方无需改。 |
| `UnityBattleSource/Assets/Scripts/SpellSpectacle20260926.cs` 第 181 行附近 | `enemy-ward` 身份（`guard / fortify / calibrate / calibration / tower_armor`）直接 `OvalLightShield.Flash(..., Fortify, 2.2f)` 并返回，华彩层不再为举盾画任何主体。 |

两个预设的差异：

| | Ward（Q1 守卫印记） | Fortify（傀儡等举盾） |
|---|---|---|
| 颜色 | 蓝白膜、白边 | 琥珀金膜、紫边 |
| 流光 | 慢速、纵向 | 快速、斜向 |
| 晶面闪烁 | 无 | 有 |
| 隐现节奏 | 慢（0.55 Hz） | 快（1.1 Hz） |
| 持续 | 印记期间常驻 | 每次举盾 2.2 秒 |

可调参数集中在 `OvalLightShield.cs` 的 `Build()`（颜色、流速、角度、频率、晶面、亮点）和 `LateUpdate()`（尺寸系数 `1.08/1.04`、宽度上限 `0.55`、潮汐频率、最低可见度 `0.18`）。
