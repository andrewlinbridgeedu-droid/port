# 普攻短动作与紧接下一招

用户反馈全法术第二轮H00普攻动作过大，会影响以后更密集的出招。本次只修改普攻身体表现，不缩小飞牌/接触特效，不调整原生攻速、伤害、目标、0.16秒飞牌离手及0.58秒contact。

## 根因与修改

原入口先调用`PlayEmbeddedPlayerCast()`播放完整`Meshy · Attack`，再叠加普攻腕/肩动作。旧近景中主角在牌已离手后仍大幅转身、抬臂，约录像1.64秒才恢复（出招从0.20秒开始）。单纯降低附加骨骼角度不能解决底层长动画。

- 两个普攻入口（原生表现与旧本地演示）改用`PrepareCompactPlayerBasic()`：从待机姿态承接，禁止这次触发长施法FBX。其它技能入口不改。
- `FoolSkillChoreography.DrawBasic`缩为轻肩肘和短翻腕，取消左臂陪衬与大幅转胸，不加入腿部跨步、转身或跳跃。
- 0.09–0.16秒短促发牌，0.18秒起收势、0.34秒归零、0.36秒解除动作。牌继续按独立时钟飞行，0.58秒仍只回执一次。
- 普攻VFX仍独占Begin；入口不重复Begin。先前普攻尾效过期不能清除正在进行的另一技能动作。

## 验证设计

真实Unity录制沿用原全景/近景机位。H00单次；H00-followup-basic在0.2/0.8/1.4秒各发一次普攻；H00-followup-skill在0.2秒普攻、0.8秒接H07。这是表现层紧接压力样本，不是将正式攻速改成0.6秒。

新增录制断言：首个动作0.4秒内释放且Animator为Idle；此时未提前发contact；下一技能立即开始，旧普攻尾效过期后它仍持有动作；三种样本各1/3/2次接触，主角战斗根不移动。取消/重试安全检查另跑，不将顺利播完视频代替安全测试。
