# 布告任务梳理（2026-10-17）

用户要求："完整梳理一次，是不是所有布告任务都正常"。具体有三条：
- 人物会出现。
- 不要经常说过期：过期就直接刷新、不见，出现新的；可以有倒计时提醒。
- 点击人物，任务会正常进行下去；有时需要跑几趟。

分支 `claude/board-tasks-20261017`，起点是 main `f539fc1`。

## 范围

地图上会亮起的委托都看了：
- **街坊委托**：送货、找东西、赶塔怪、传话四种，每天 2–3 条，午夜换新。
- **街头急件**：每天一件，3 步。
- **合力差事**：每三天一件，4–5 步，到第二天午夜。
- **市政委托**：每周一件，5–6 步，7 天。
- **通缉问话**：和上面几类共用同一套人物和名牌。

## 发现的问题

1. **名牌和铃铛不见了**，这是"人物不出现"的主要原因。
   - 10-05（`43b2f82`）加了"名牌靠近屏幕边缘时往里收"，计算时用的是人物在整幅长卷上的横坐标，却和屏幕宽度比较。
   - 结果长卷上第一屏宽度以外的人，名牌全被推到同一个位置，离开了本人。
   - 委托人其实已经走到等候点，也能点，只是头上没有名字和铃铛，看不出是谁。
   - 模拟器上看到，花摊帮工站在委托板旁边，头上什么都没有。
2. **换天后最多 30 秒不刷新**。
   - 地图每 30 秒才开一次新的一天；从后台回到游戏时，只刷新住房。
   - 这段时间里，昨天的人还亮着，一点就说"这条请求已过期"。
   - 试玩设置里"时钟前进24小时"也一样。
3. **传话会卡死**。
   - 一打开托话人的页面，地图就改为点亮收话人，哪怕还没按"接下传话"、没扣体力。
   - 没接就离开的话，收话人那里没有可办的事，托话人又不亮了。
   - 页面上原来写着"已记下口信，请到某某面前交谈"，接之前就这么写，会误导。
4. **赶塔怪可能开不了打**。
   - 开打要求"正在和这位街坊交谈"，但打斗页盖上来时会触发街坊页的离开，把交谈对象清掉。
   - 改为开打时重新接上交谈。改后模拟器上从地图点人、开打、打赢、到账全部走通。
   - 改前在模拟器上没复现过，所以这一条是按代码判断的。
5. **满屏"作废、过期"**：
   - "今天的请求明天会作废"
   - "这条请求已过期"
   - "有效至第 N 天，逾期未完成会作废"
   - "这件事已经过期，或不在今天的委托里"
6. **同一等候点的人挤在一起**。
   - 名牌叠成一串，例如"钟楼广场水手账员"。
   - 两人只隔约 30 点，可点区域互相重叠。
   - 名牌本身也点不了。
7. **传话完成后，收话人的回话不显示**：显示代码在保存之前就执行了，结果没取到。

规则层（`MPCNeighborLedger`、`MPCStreetTaskLedger`）没有问题：每条委托都能做完，报酬只发一次。

## 改动

| 位置 | 内容 |
|---|---|
| `HomeStreetScene` 名牌 | 按人物在屏幕上的位置往里收；同一等候点后来的人，名牌依次抬高一行；名牌可以点；同点的人间距从 0.035 改为 0.05 |
| `ContentView` 换天 | 到午夜就醒来开新的一天（每 30 秒的检查保留）；回到前台时也开 |
| `GameStore` | `advanceInstitutionClock` 后立刻开新的一天；新增 `pacingDayEnd`、`errandTimeLeft` |
| 规则层 `neighborTargets` / `streetTargets` | 新增 `today:`，过了日期的委托在新一天开出之前也不亮（正在打的仗除外） |
| `NeighborConversationView` | 只显示今天的委托；倒计时"今天的委托午夜换新 · 还剩 X 小时 Y 分"；传话接下之后才点亮收话人，并给出"前往 · 收话人"；赶塔怪开打时接回交谈；收话人的回话会显示 |
| `HomeStreetTaskView` | 去掉"作废"，改为倒计时；任务被换新时页面自动关掉；每步之后有"前往 · 下一处"，地图转过去 |
| `HomeNeighborPosterView` | 只列今天的；打开时开新的一天 |
| `MPCDailyPacing` | `end(ofDay:)`、`remainingText(seconds:)` |

## 验证

- **规则测试**：679 项通过，含新的 `BoardErrandWalkTests`。唯一的已知问题 `q30TalentsAndRelics` 是改动前就有的。
- **走查测试**：
  - 第 1–40 天的每一条委托，都只到地图亮着的人或地点那里办，一直办到领钱：79 条街坊委托，街头急件 39、合力差事 13、市政委托 2。
  - 每一步亮的都是该步要找的人，而且在地图上；完成后不再亮。
  - 街头任务每件至少要跑两处。
  - 还测了午夜一过、新一天开出之前，昨天的人不亮；以及倒计时的文字格式。
- **模拟器**（原生工程 `.build/board-harness`，iPhone 17 Pro Max）。用户手机存档的只读副本放进独立档 `board-walk-20261017`，在副本上实打：
  - 第 5 天花摊帮工赶塔怪：开打、打赢、+15 铜、好感 +1。
  - 花商找东西：答错一次被划掉、不扣铜，答对 +12 铜。
  - "试玩时钟前进24小时"后，新委托立刻换上，昨天的人不再亮。
  - 第 6 天钟楼广场水手传话：没接就离开，托话人仍然亮着；接下后"前往 · 街头乐师"，地图转过去，转达后收话人的回话和 +8 铜都显示。
  - 修好后名牌全部出现，同点的名牌分行，点名牌能打开对应委托。
- **模拟器**，规则测试档 `review-board-20261017`：街头急件"风里的船期表"三步都靠"前往"一路走完，港务抄账员 → 报社 → 委托板，+15 铜。
- **手机**：没有。

## 还不能说的

- 午夜那一刻自动换新只在规则测试和试玩时钟上验证过，没有真的等到午夜。
- 任务换新时页面自动关闭，模拟器上没有触发过。
- 名牌位置只在 6.9 寸模拟器上看过，没在 iPhone 13 上看过。
- 急件午夜作废时，已经做了的步骤会一起清掉（规则如此，体力不退）。现在有倒计时提醒；要不要改成"接下的急件延到第二天"，需要用户定。
