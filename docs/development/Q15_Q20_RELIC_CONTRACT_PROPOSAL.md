# 三证环与无主印章：已批准的正式效果补全

范围：只改变装备对应遗落物的角色，不改变未装备时的正式技能。以下契约已于2026-09-13获用户明确批准“采用这两项规则”。核心已实现并验证，手机端实测进行中。

## 第15关三证环

保留已确认并已修复的收益：三种不同类别形成一组，重复类别重新计数；触发获得最大生命10%的护盾，并强化下一次有伤害的攻击20%。

正式负面：每次触发后，下一次实际结算到自身生命或护盾的敌方直接攻击提高25%。幻影承受的攻击不消耗此负面；换目标或护盾提前消失不取消；多次触发只刷新一份，不叠乘。受伤结算后清除，跨关与重试清除。

异常关系：三种互相矛盾的证明暂时保护持有者，也使归一系统更清楚地锁定其身体。提高承受伤害是真实负面；类别重计数和次数限制均不算负面。

## 第20关无主印章

保留文案正向意图：无名宣告后，下一次成功的身份错置转换不消耗误认。仍须满足原有转换条件；没有足够误认时不触发免费转换、不消耗这次机会。机会成功使用后清除，跨关与重试清除。

正式负面：装备印章时，无名宣告对全体敌人的误认层数从4层降为2层；归结准备、手动释放和每战一次保持现有规则。未装备时仍施加4层。

异常关系：没有主人承认的印章无法制造完整身份，却能留下不被转换抹去的残余证明。这取代旧文案中并不存在的“放弃终极25%增伤”，不凭空给基础终极补增伤。

## 验收约束

- 使用真实持有和手动装备；解锁前不可出现，获得后不可擅自替玩家装备。
- 三证环须覆盖护盾/生命承伤、幻影、反复触发和跨关清理；展示同一攻击的普通值与125%结算值。
- 印章须覆盖无装备4层/有装备2层、一次免费转换、后续正常消耗、条件不足不消耗机会、重试清理。
- 规则测试、构建、实际战斗截图分别记录；不能用测试通过代替战场验收。
