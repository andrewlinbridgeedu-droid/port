# 主体精修与翠毒机制

## 本批用户方向

继各招式特色版后，用户要求精修错影追猎的两个主角人影与荒谬归结巨牌；给猎犬两招增加脚下地裂；亡灵改为持续2—3回合的漫天毒雾并区分两招；守卫与女主不再以大片光作为主体，参考本机 Effekseer 的旋风、箭阵或聚合炸散。用户提供的 Meshy_AI__0914064051_texture.glb 是形态建议，不指定使用鸟；该源文件未改动、未直接替换任何敌人。

## 正式毒雾规则

当前战斗采用实时动作时钟，旧 `round` 每个敌人事件（含蓄力）都会递增，不能直接表示用户所指持续回合。本批将持续时间明确为3拍，每3秒一次，共9秒，界面显示剩余次数。

|技能|结算|铃后|行为区别|
|---|---|---|---|
|翠毒漫天|66×3，总198|99×3，总297|成功施毒3秒后首跳；新施毒替换旧毒，不叠层|
|返场毒爆|198直接伤害|297|一次爆发，不刷新持续毒雾|

上述数值沿用原攻击110×180%＝198总预算，属于依据用户方向实施的本批数值分配。铃仍延后3秒，并在本次施毒包/毒爆释放结算时消费一次增伤。幻影可承接初次施毒；已挂毒的各跳不再消耗幻影、闪避或三证环的下一次直接承伤暴露，正常吸收护盾并处理低血被动。敌人死亡、胜败、波次、重试和退出清理战斗毒状态与毒雾。

原生明确发送 `emerald-spell:mist|burst` 决定两招，替换 Unity 内部自增轮换；`emerald-poison:3|2|1|0` 驱动持续场。场景视觉不计算伤害。剧情进度、奖励与存档结构未改。
