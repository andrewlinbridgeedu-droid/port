## 怎么试玩

1. 打开“雾港·机构试玩”，从开局档正常选择愚者，完成Q1后点银行或右上“办事册”。初始180铜，生活费正常扣。
2. 点“试玩设置”切住房档；它是明确标注的Q13已完成、1200铜、联排屋测试夹具，不是真实首通。两档的钱袋、存单和合同分别持续保存，切换不重发夹具资金。
3. 住房档进入办事册 → 我的住处 → 书桌与来信，试玩核验、条款与三个交货柜台。普通房也可办事册 → 公开会面，进入同一客户的基础合同。
4. 在“试玩设置”把时钟每次前进24小时，检查存单、交货复核、租约、日费和材料预算。正式日期规则未删；此控制仅在独立DEBUG试玩包出现。
