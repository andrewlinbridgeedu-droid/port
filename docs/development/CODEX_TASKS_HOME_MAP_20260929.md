## 任务 1：首页地图层

用户定：首页就是港城，用现在的四季首页画；旧港城图（`HarborCityExplorationView`、`BountyCityPanorama`）不再出现。

1. **读 `home-map-layout.json`**，在 `CityHubView` 的画上加一层：三块街区、街道、出入口、等候点 H1–H10。四季、昼夜、天气照旧。
2. **23 名街坊**：复用现有 2.5D 行走图集，按远近缩放，只在街道上走，从出入口进出画面；同屏上限约 10 人；首页被其他页面盖住时暂停动画。
3. **平时点街坊**：停下、头顶出名字和一句寒暄，一会儿消失，没有选项、不给东西。寒暄句库先按季节、时段各写几句，`harbor-pedestrians.json` 里带提示的句子改成纯寒暄。
4. **常驻可互动的四个人**（`alwaysInteractive`）：莫尔、码头老水手（牌局），商人（铜币买卖，接现在角色页里的遗落物、止痛膏、晋阶主材购买），咖啡馆店主（补给）。只挂现有功能，不新增商品；底栏“商店”是真钱内购，不动。
5. **建筑里的人**（`namedPosts`）站在门前岗位上；没有任务时只打招呼。
6. **任务人物亮起**：给一个通用接口，规则库说“谁亮着、为了哪件任务”，首页就给他头顶标记，10 秒内把他召进画面、走到最近的等候点站着。加任务条（状态栏下方，可收起，点它镜头移过去）和屏外箭头。
7. **名牌**：新增邮局、诊所、港务处、旧街铺面、委托板；市政厅、警察厅改为可进入（先做通用柜台页，显示里面的人，没有任务时只能打招呼）。
8. **下线**：3D 街道、旧港城图、通缉调查地图不再有入口，源码和素材保留。日刊里“街坊委托”改为回到首页并把镜头移到委托板。
9. 世界事件服务区（`eventAreas`）和街坊委托改到委托板，本单**不做**，留到下一单。

验收：新档和旧档各看一遍首页；四季、昼夜都能看到人在街上走；点人只有寒暄；四个常驻的人功能正常；iPhone 13 帧率可接受；Preferences 只新增必要的键。

## 任务 2：送信（取代现在“核对单据”的 J0）

设计稿 2.2 节。

1. 规则库：信件模板（直投、认人、回信、改址、取件）× 23 人的目录；邮件包的步骤与完成判定；结算仍走 `MPCDailyWorkLedger`，每包 40 铜、按单递减，回执沿用 `postal-<序号>`。认人模板里，符合描述的两三个人都亮淡色标记，点错的只说“不是我”。
2. App：邮局柜台领邮件包；收件人通过任务 1 的接口亮起；点他交信。
3. 迁移：旧的“核对单据”做到一半的作废重领，不扣钱、不重复发钱。
4. 规则库单元测试＋一个 DEBUG 自检（五种模板各走一遍、重开游戏、重复点击不重复发钱）。

## 任务 3：B07 三声敲门客（六环）

设计稿 3.2–3.4 节和 B07 一节。**每案目标 10–12 分钟，六环都保留。**

1. 规则库：扩展 `MPCChurchBountyLedger`：证据卡（人证、物证、排除，带来源组）、被推翻的猜测、通缉令校验（嫌疑人＋两张不同来源的卡，至少一张物证＋现场两处身份特征）。通缉令对不对由规则库判定。五个旧结论 ID 保留作兼容（`witness`＝人证线，`wound`＝物证线，`exclude`＝排除，`compare`＝比对，`identity`＝现场）。
2. B07 的步骤、台词按设计稿写入；动手操作“对时刻”做成一个一分钟以内的小界面。
3. 首页：接案后邮差、诊所亮起；旧排水口街边标记；比对后出现“第三间空屋”现场门标；现场页核两处特征、开通缉令、进现有 B07 战斗。
4. 迁移：进行中的 B07 旧进度按兼容 ID 换成各环进度，已收集的证据不丢；已结案的不变、不补发。
5. 测试：两条线先后顺序各走一遍、先指错修门工、战败重试、中途重开、旧进度迁移。用 `ProgressionSim human` 估 B07 时长，超过 12 分钟就按设计稿 3.2 的办法砍“第二个人”，六环不动。
