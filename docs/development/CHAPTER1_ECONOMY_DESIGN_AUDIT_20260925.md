## 本次真正验证了什么

Python标准库独立程序生成59个银行事件、9个期末快照，以及19条项目路径175个事件。全部局部实体账满足：

```text
资产 = 现金 + 贷款毛额 + 存货 + 工具 − 贷款减值准备
负债 = 存款本金 + 应付存息 + 应急借款本金 + 应付应急费用
权益 = 实缴股本 + 留存损益
资产 = 负债 + 权益；现金及各资产/负债非负；减值准备≤贷款毛额
```

也核对成本合计、结果回款、止损、过价交易两任利润、共享比例配额及两个互斥1200政策预算的算术。没有给项目结果分配概率，不能据此推真实期望收益或最优决策。

**范围限制：** `sell`增加项目现金，没有同步减少客户或供应商对手账。有限客户/残值预算仍为输入假设；没有全经济钱物守恒证明。供给UID为输入例，不是执行了跨实体库存扣转。`tranches`和事件期数是标签，并非独立托管账户、拨款状态机或幂等事务。银行政策阈值写入规划但未实现成业务拒绝规则。因此这些结果不能称防刷、分期恢复或完整经济约束已通过。

## 铜币定标与长期压力补充

代码只有铜币基础定义，没有查到独立银/金面值比。“金币”标签仍读同一钱包。咖啡12、烤面包16、炖锅20确有扣款路径，但商品描述是特殊效果补给，不能直接作普通居民日篮子。普通工资、住宅租金、基础料物量与工坊工时仍无现行统一锚；J0每单40没有已测时长。

A技工12铜/小时使P2装配100只买10台合计8.33小时，每台50分钟。如果未来工序证实每台要4小时，工资480，项目至少980而非600；4小时是敏感性反例，不是已测数据。本轮不擅改旧价，要求主标尺确定后按物量/工时单重估候选。

新模拟16个场景各240期，共3840期、92,565现金事件及84,404物量事件。11主体均有有限现金，所有付款扣对手账；基本生活食物/燃料/住房与金属→车件→整车供应链实际扣转，统一有限劳动池，车辆保留所有权库存并按候选20期寿命退休。各现金事件满足总现金＝开局＋发行−销毁；各货物满足库存＝开局＋生产−消耗/退休，残差0且无负余额。独立审查也[重放复核了流水](../../output/chapter1-audit-20260925/economy/calibration/independent-review.md)。这是模型一致性验证，生产率/出价/工资/寿命仍为假设，不是游戏实测。

最关键的负对照：无源增发720,000 U时，固定数量保价合同仍让基本篮子指数100/足量，但实际车最高成交指数1900，影子篮子820；480期更达4060/1684。故“保价＋拒绝超发场景通过”不能单独证明完整制度稳定。固定总币也不足：燃料囤货使篮子119.22/最低履约66%，扩产117.19；期末净发行零、先发后收仍使篮子103.6。战争200单位燃料缓冲仅保4整期，第65期破限；基本篮子保住的短战仍有20辆需求未成交。有限J0类财政拨款不增发，却使车价175。不得只报告成交便宜部分、藏掉缺货或篮子外通胀。

银行支付边界现在明确建议为：600储蓄须兑成现铜才能消费。银行400自有＋600存款、放贷550，实体币1000不变；若存款可支付，本例M1=银行外现金550＋存款600=1150，需要另测。新长期模型仅自有资本现金中介，完全不含可支付存款，因此并未证明存款银行反通胀。

静态人口50/100/200不是半途迁入迁出；逐户公平、真实资源耗竭/产率、内生技术、可支付信用、跨城全产业网络与真实服务端幂等均未覆盖。保价保障还必须有真实库存/替代产能/采购预算；长期物量崩塌时不能硬保证购买力不降。本轮明确失败边界，**未得出全经济无通胀已通过**。
