# 通缉调查地图缩放与 B07 真机闭环（2026-09-25）

## 本次改动

`BountyCityInvestigationView.swift` 的城市调查地图现在支持双指缩放手势和顶部的放大／缩小按钮，范围 100%–260%；放大后可上下左右拖动，也保留西街、东岸平移按钮。城市标记与唯一的主角按同一坐标系缩放，主角移动时镜头跟随。到达房屋时，进入按钮固定显示在地图底部；通缉令核验成功后，战斗入口固定显示在室内画面底部，避免被长卷宗挤出屏幕。原有房屋点击、行走、证据与对话逻辑不改。

## 真机验证

Xcode 签名 Build 74 构建、安装并启动于 iPhone 13（设备 ID `2A835FEC-7B6D-513B-AF8F-B5A84B673035`）。安装前后 `Library/Preferences` 逐文件相同，留档于 `backups/bounty-city-zoom-20260924/device-before-build74/Preferences` 与 `device-after-build74/Preferences`。镜像画面确认从 100% 放到 135%、246%，放大后横纵拖动有效，主角与房屋标记仍贴合。双指手势已编译，但镜像工具不能可靠模拟双指触控，所以**双指本身未实测**；帧率也未量测。

在同一 iPhone 13 上，B07「三声敲门客」从已领取委托继续：跑完诊所、旧邮局、木工街、旧排水口、第三间空屋五处调查；核对嫌疑人和两份独立证据并出示通缉令；从空屋进入正式战斗，以空技能序列的自动普攻击败目标；回教会交案。真机存档读回显示 `claimed=true`、`currentLocation=教会`、`victoriousBattleID` 已结清，铜币 362→422、功勋 8→28，装备 `bounty-b07-bell-throat` 已获得并装备。交案前后存档分别在 `backups/bounty-city-zoom-20260924/device-after-b07-victory` 与 `device-after-b07-claim`。这验证了一案的探索—核验—战斗—交案—装备奖励闭环，不代表十案或第一章 1–30 关都完成实玩。

继续按正常存档测试战力成长：Q6「档案街入口」空技能编排首次实战失败；完成塔 F5、F6 并得到自动装备的 F6「盐痕短刀」后，以相同空编排再次挑战 Q6 仍失败。随后手动编入「错步穿行」，真机清过 F7、F8，F8 获得「双颚护胄」，画面与存档铜币 438→446→454 对应。至此尚未出现“刷塔后反胜 Q6”的完整体验，不能据此宣称战力闭环成立。继续测试时设备上的游戏被更新为 Build 75；Build 74 的前后结果不可直接与后续版本作严格同包对照。镜像期间数次跳到手机主屏，检查时曾发现应用仍在运行，也曾在更新后看到新进程；9 月 25 日 00:54 之前拉取的诊断记录中没有当次 Mistport 崩溃记录，故暂不将跳屏判为游戏崩溃。
