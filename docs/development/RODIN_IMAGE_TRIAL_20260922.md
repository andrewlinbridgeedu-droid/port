# Rodin 单图 3D 试作（2026-09-22）

用户指定用右侧 Rodin 浏览器将黑金/青绿长袍人物参考图转成 3D，并允许最多消耗 1 Credit。本次使用 Rodin Gen-2.5、High、Private、单图正面输入、非对称四边面和烘焙法线；材料选择 Native High，导出 2K PBR 与 Shaded 两版。网页钱包从 54 变成 53.5，观察到消耗 0.5 Credit。

作品页面：https://hyper3d.ai/workspace/rodin/03b62c22-c7db-48cc-a578-41828e618885

本地原件与可编辑文件：`ArtSource/VeiledWandererRodin20260922/`。完整下载压缩包、两份原始 GLB、参考图、Blender 工程、SHA256 记录均保留。视觉总览：`output/veiled-wanderer-rodin-20260922/index.html`。

Blender 5.2 从 PBR GLB 复导成功，得到单个网格、96,310 三角面、一套 UV、内嵌三张 2048×2048 PBR 贴图；没有骨架或动画。正面、斜侧、侧面、背面均从复导文件实渲；Shaded 备选也复导实渲。帽檐遮脸、帽面浅色投射污染、手与挂饰细节简化，背面为单图推断。该试作未达到原画精度、未减面绑定/制作动作，也未接入游戏或替换正式角色。
