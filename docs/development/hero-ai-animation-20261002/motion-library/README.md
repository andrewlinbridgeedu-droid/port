# 五组动作，三套衣装

**最新**：用户在全身动作页确认“好啊，接入游戏”。当前选稿已转透明并接入三场样板，见 [实际 Unity 预览](../integration/review.html)；原片、候选和历史观察继续保留，不能把原片认可当作真机认可。

用户认可首轮 AI 动画，允许衣装间的动作差异，并确定每套 5 段。用户随后要求加入投掷等全身发力动作；当前 15 段选稿中，扬袖起势与双手连发已换成两类新投掷候选。此前版本和已认可的首轮均保留，没有覆盖背影原画。

- [五组动作预览](review.html)：默认 ×3，可选 ×1/2/3/4/6，保留原速 MP4，另导出 ×3 文件。
- [两类全身新动作](full-body/review.html)：踏步过肩投掷、侧跨转腰甩投，各三套。
- [两类待复看原片](rejected-review.html)：交手换位和双掌同推，支持原速和慢放。作者觉得背部遮挡有问题；用户要求看原片，目前没有用户否决结论。
- [五组 ×3 连播](all-actions-three-outfits-3x.mp4)。

| 选稿 | 建议法术 | 作者观察 |
| --- | --- | --- |
| 斜步切出 | 错步穿行 | 夜行、红衣改用宽幅生成保留手部；夜行有明显转体。 |
| 抬手敕令 | 假面谕令 | 单手高位手势；红衣结尾未完全落手，后续需处理回位。 |
| 踏步过肩投掷 | 身份错置 | 脚步、身体倾斜和肩臂跟随明显；结尾部分未回到起始站姿。 |
| 落掌盖印 | 伪证烙印 | 三套抬手、落掌与身体下压幅度不同。 |
| 侧跨转腰甩投 | 双影追猎 | 迈步与转腰明显；部分转向镜头偏多，牌离手和回位还需处理。 |

对应法术只是选材建议，尚未绑定游戏技能。目前是灰底视频，未抠透明、适配战斗循环、接入 Unity/App 或装机。没有访问手机或 Preferences。

MiniMax-Hailuo-2.3，请求 6 秒、1080P。实际尺寸、时长、帧数、原文件哈希与完整解码记录见 `media-check.json`。宽幅动作保持服务返回尺寸，与早期 1080×1920 的竖幅不同。不是 4K 视频。

`actions.json` 为当前选稿表；`selection-before-full-body.json` 保存此前选稿。`revisions/` 保存补做和暂未选用的版本，`full-body/` 保存全身投掷原始生成结果。每段提示词、任务号、输入与输出哈希随文件保存。凭据及带签名的下载地址不入库。最新 15 段尚待用户逐段选定。

复跑脚本在 `tools/animation/`：`minimax_hero_motion_library.py`、`minimax_hero_revision.py` 和 `package_minimax_hero_motion_library.py`。已有任务号只查询下载，不重复提交。
