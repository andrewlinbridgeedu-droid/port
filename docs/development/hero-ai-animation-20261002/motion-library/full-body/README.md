# 两类全身发力动作

**后续状态**：用户看过本页后说“好啊，接入游戏”。已进入透明动画接入阶段，最新运行与构建记录见 [接入说明](../../integration/README.md)。下文为生成当时的观察与范围，保留原片缺陷记录，不等于接入效果已获认可。

用户希望有投掷等全身参与的动作。本轮分别生成三套衣装的踏步过肩投掷、侧跨转腰甩投，共六段；候选放入每套五段的选稿，此前版本保留。

[直接查看](review.html)：默认 ×3，支持原速、慢放和拖动进度。源 MP4 原样保存，`video-3x.mp4` 为另存的加速副本。

来源仍为三张原有背影原画。人物像素不变，补成 3200×4400 暖灰画布，为迈步、伸手及衣尾留出空间。请求 MiniMax-Hailuo-2.3、6 秒、1080P。不是新增 Blender 动作，没有修改游戏结算。

作者抽看半秒间隔的全身帧：这一轮迈步、抬后跟、身体倾斜、腰肩转动和衣摆跟随更明显。模型没有完全遵守提示词：部分转身露出正面，过肩动作的结尾还没有回到原站姿，个别牌离手表现不明确。它们是供选的动作原片，不能宣称已是干净循环或商业成品。之后若用于战斗，需要处理起落衔接、道具和透明背景；本轮不接 App、不装机。

`actions.json` 保留动作提示词；每段目录内有输入、请求、任务、状态与下载哈希。`media-check.json` 记录实际尺寸、时长和完整解码结果。作者抽帧不等于用户认可或逐帧无缺陷。
