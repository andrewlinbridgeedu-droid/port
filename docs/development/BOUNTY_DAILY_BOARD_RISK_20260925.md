# 每日通缉告示与战败风险（2026-09-25）

用户否定原双列暗色通缉板、按第几关张贴，以及无代价的“可死可重试”。本批重做告示板为明亮单列档案卡：罪行、真实招式、敌方生命／攻击、当前战力的估算危险、铜币与功勋在接案前可见。十案的调查与交案仍用原有证据链，B03／B08 扑克仍为可选线索。

每日在设备本地 00:00 更替 3–6 份**尚未接且未结**的固定案件，同一天关掉重开不重抽，已接案跨日继续，已结案不复活或重复领奖。抽取优先带一个低、中、高档目标。旧 `unlockMission` 数据继续保留给旧档和历史索引，不再作为领案或调查门槛；酒馆和教会看同一批告示。若未受理存量少于 3，显示真实剩余数；现有固定池只有十案，尚未实现无穷多新身份。

战败可重试，证据和已接案保留。每次**真实战败**分别掷 35% 铜币风险（现有铜币的 15%，向上取整，最多 60）、12% 一件普通遗落物风险；只有本战实际携带且自有的普通遗落物可掉，剧情绑定物与教会借物排除。退场／牌局失败不触发此规则。结果以战斗 ID 记账，重复失败回调不再扣；遗落物所属、装备栏、铜币、失败凭据同一待提交记录恢复，掉落旧件的损耗档重置，之后重新购入的是完好新件。没有永久角色死亡。

内容提示来自现行十案案文及战斗意图，例如 B03 护航残影存活时船长免伤、B04 连续同技会吃高额覆写、B10 囊体转息治疗；“危险”是用生命、攻击与玩家现有战力作的提示性估算，不是实玩后校准的通关保证。
