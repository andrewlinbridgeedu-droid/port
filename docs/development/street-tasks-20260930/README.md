# 城市贡献度开放的三类街头任务 · 2026-09-30

交接页“云端也能做”的第一项。设计稿（首页港城与街头任务 §6.2）定了城市贡献度到档后开放三类新委托：加急委托、街区难题、城市委托。原先规则库里只有“开没开”的开关，没有内容，也没有规则，铜币也没进经济模拟。本轮把它们写进规则库，接进模拟器和预算脚本重算。**用户 2026-09-30 说“先按现在这样”，铜币数额和台词按现稿确认；App 还没接。**

## 做了什么

**规则库** `StreetTasks.swift`，另有 12 项测试；规则库共 546 项，全部通过：

- **通用的多步街头任务模型**（设计稿 4.1 的 `StreetTasks`）。
  - 每一步是“找对人或地方，做一件事”，四种动作：交谈、交货、三选一、街头战。
  - 每步写明目标（街坊编号，或首页地图上的建筑、街点）、任务条文字和完成时说的话。
  - “谁亮着”由规则库算出（`MPCStreetTaskCatalog.streetTargets`），首页地图只负责画出来。
  - 邮务、街坊委托和余案以后改成多步时，也可以用这个模型。
- **内容**：[全部台词](content.md)。
  - **加急委托 23 条**，每位街坊一条，3 步，15 铜。当天发布的人固定取轮换顺序里和当天委托人相隔最远的那位，所以同一天不会重复找同一个人。
  - **街区难题 8 条**，每条串起 2–3 名街坊，4–5 步，30 铜，相关街坊各好感＋1。例如婚礼前夜、码头夜班、丢了的第十七页、广场长椅。
  - **城市委托 2 条**，5–6 步，60 铜，分别对应已画好的喷泉广场和工坊货场。完成后记下街景编号（`fountain`、`yard`），App 据此显示首页贴片。
  - 所有地点都核对过首页地图（`home-map-layout.json`）。三选一的答案都能从前面的对话推出来。
- **账本** `MPCStreetTaskLedger`：
  - 按贡献度档位发布：加急委托每天一张，当天有效；街区难题逢 3 的倍数的天发布，到第二天为止；城市委托从发布起 7 天内有效，7 天后发下一张，没做完的下次重发同一张。
  - 接单后才能做；每一步检查目标和动作；交货前查背包；三选一答错划掉，不扣钱；街头战用票据，一场只结算一次，打输可以再打。
  - 完成时一次性给铜。加急委托和街区难题附上贡献度回执，按“街坊委托”计分。另外返回要加好感的街坊，由 `MPCNeighborLedger.raiseAffinity` 加上，好感到档照样解锁小故事。
  - 街头战复用塔恶魔的身体（`church_maintenance_street_` 编号），深井战斗的演出路径和共享服复算都能直接用。

**模拟器**（`tools/progression-sim`）：“全都做”的打法每天把能接的街头任务做完，计时按人类计时模型逐步累加。

**预算脚本** `tools/daily-loop/budget.py`：新增 C 表（见下）。
