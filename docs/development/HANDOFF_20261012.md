## 3. 第 8 关记忆蛭改成黑油（10-14 用户认可：“黑油可以的”）

用户 10-12：“不属于我的名字那关 这个泡泡不好看，要更生动，如同石油一般冒泡起伏，略微蠕动”“用blender画逼真些”。

- **Blender**：`tools/vfx-spectacle-20260926/blender_leech.py`。极坐标高度场逐帧重建，48 帧无缝循环：
  - 平顶圆边的油池，边缘慢慢蠕动，整摊在起伏；
  - 泡泡是从油面里软软鼓起的圆顶，长大、破掉、留一圈渐弱的涟漪；
  - 材质：黑油 + 少量清漆 + 油膜虹彩；环境是手调的户外反射（头顶天光、地平线灰建筑、下方暗）。用摄影棚 HDRI 像黑塑料，全天空反射像浅蓝果冻，都试过否了。
  - 小面积主光，阴影接收面，透明底，512×256。
  - 命令：`/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P tools/vfx-spectacle-20260926/blender_leech.py -- <输出目录> 48 64 [起始帧]`

- **合入 main**：分支和 main 历史不同，main 上的提交是从分支摘过去的，**不要 merge 整个分支**。
  1. `git fetch origin main`；
  2. 用 `git merge-tree --write-tree --merge-base=<上次推到 main 的那个分支提交> origin/main <新分支提交>` 生成树，有 CONFLICT 就手工解决（可以用临时索引写树，不动工作区）；
