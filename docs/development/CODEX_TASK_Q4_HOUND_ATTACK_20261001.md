# Codex 任务：Q3／Q4 猎犬出招要像在攻击 · 2026-10-01

交给 Mac 上的 Codex，回复用户用中文。

## 用户反馈

2026-10-01，用户在真机上看 Q4“猎犬试探”：

> 敌人的攻击动作要更明显，现在看起来似乎完全不懂的，只是在散步。

## 原因（云端读代码查到，未在 Unity 里复现）

1. **四条腿的走路循环在出招时一直在播。**
   - `EarlyEnemyIdlePresence.cs` 的 `UsesContinuousEarlyHoundGait` 对 Q3、Q4 的 `early-hell-hound` 一直开着连续步态。
   - 蓄力、开火、破绽这三段都没有让步态停下来。
2. **出招动作只动脖子和下颚，而且幅度很小。**
   - 出招时用的身体动作是 `MainlineBodyRound2.cs` 里的 `Pose.EarlyHound`：脖子 −5°→+7°，下颚 7°→13°。
   - 那里的注释写着“Only the neck/muzzle layer: the continuous four-leg gait is untouched”，是当初有意只动这两处。
   - 蓄力时 `Q4HoundPresentation.cs` 只让头低 9°。
   - 结果是猎犬边走边点头，火球自己飞出去。
3. **`Shot()` 里的 `SetTrigger("Attack")` 可能不起作用。**
   - 这只猎犬的控制器能识别的状态是 `Walk`／`Walking Hold`，不一定有 `Attack`。
   - 请在 Unity 里确认。如果没有，就不要再依赖它。

## 要求的动作

伤害、命中时刻和 20 秒循环都由原生规则决定，**不改任何时间**：
- `q4_probe`、`charge`（2 秒）、`q4_flame_first`、`q4_flame_second`、破绽 3 秒；
- 碰撞时刻由 `Shot()` 的 0.45 秒飞行决定。

只改身体表现。所有位移只加在视觉子节点上，**不动编队根节点**，每段结束要精确还原。

| 段 | 现在 | 要改成 |
|---|---|---|
| **试探小火**（`q4_probe`） | 边走边点头 | 0.15 秒内停步、四脚站定；头猛地后仰约 15°，下颚张开约 25°；出火瞬间胸口前冲约 0.25 米，再回弹；碰撞后恢复走路 |
| **蓄力 2 秒**（`charge`） | 头低 9° | 停步；前腿弯曲，肩膀压低，后半身翘起，伏低像要扑；头压低并往后缩；身体有细微的低吼颤动，越接近 2 秒越强；尾巴绷直；两颗嘴边火球照旧变大 |
| **第一、第二颗大火球** | 同试探 | 前冲约 0.5 米，头往前甩约 20°，下颚张开约 30°；每发之后后坐约 0.2 米；第二发换一侧，或幅度更大 |
| **破绽 3 秒**（`opening`） | 头左右摇 13° | 保留摇头；身体往一侧歪，前腿外撇，像被晃晕了；3 秒内不走路 |
| 其余时间 | 走路 | 照旧走路 |

要点：
- 停步要快，开火要有向前的“冲”，打完要有“后坐”。玩家应该一眼看出：它在蓄力，它要咬过来了，它现在晕了。
- 先给每段做一版，录出来交用户看。用户觉得夸张或不够，再调幅度，不要自己先压小。

## 实施提示

- 停步的办法：
  - 在这几段里把猎犬 Animator 的 `speed` 在 0.1–0.15 秒内降到 0，结束时再升回 1，或者切到静止姿势；
  - `UsesContinuousEarlyHoundGait` 的地面校正要跟着处理，别让脚陷进地里或浮起来。
- 骨骼名以这只 Meshy 猎犬的实际骨骼为准。`EarlyEnemyIdlePresence` 里已经有 `chest`、`neck`、`head`、`jaw`、`tail` 的映射，可以复用。没有腿骨的话，用视觉子节点整体俯仰和位移来代替。
- 同一只猎犬 Q3 也用，Q3 的扑咬一起检查。
- 不要改 `Pose.Hound`，那是塔层和别的猎犬在用。
