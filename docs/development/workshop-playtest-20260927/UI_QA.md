# 工坊试玩界面验收与接入判断

2026-09-27，最终包 v0.3.3，标识 `local.mistport.workshop-playtest`。用户明确允许后，使用 macOS Accessibility 原生按钮操作和窗口截图。操作限定这个隔离 App；没有调用模型方法代替按钮，没有读写正式玩家存档。代理操作有工具延迟，不是人类玩家试测。

## 结论

**可以开始第一条本地内容的接入开发：塔材 → 批次制作 → 有预算的项目交货 → 安装 → 公共行动 → 世界结果。** 操作和钱物闭环已足以进入这一步，继续空转宏观调参的收益很小。

此结论不是正式发布许可，也不是完整世界战役、共享市场或银行验收。接入时须将预置角色资格/背包/工程进度换成合法实际状态，补齐可持久化且幂等的奖励与采购票据，然后在 iPhone/Unity 内验证。当前只有代理界面实走，趣味、真实需求和难度仍需真人样本。

## 实玩发现并修复

1. v0.3.1击杀后仍选死亡目标，技能可能无效。v0.3.2在目标死亡后自动选下一存活敌人，保留玩家仍存活的手选目标；高难实走中两次自动切换留有 `target` 事件，后续技能命中。
2. 工程12/12后还写“缺2条”、订单完成后写“再收0条”。改为未交货/待安装/已验收三种状态，并明确订单已收满。
3. 公共行动结束后仍写“还有一次”且可以买准备品。改为显示实际贡献和查看结果入口，移除已经无效的准备操作。
4. 战中用药后侧栏仍显示战前库存。v0.3.3直接显示战斗真实库存；`48-live-inventory.json` 与截图中侧栏和按钮同为1药，撤退后仍为1。
5. 恢复战斗后保留旧“导出已暂停”消息。v0.3.3恢复/暂停按钮同步更新状态消息。

冷却、公共动作间隔、药品满血禁用、勋章生效/冷却反馈在实际窗口可见。高难回执含1次勋章、2次药品（恢复332和329生命）以及蓄力打断；勋章结束代价和呼吸囊生命上限封存可从UI读到。未修改战斗数值。

## 操作边界核查

- 切到机制对照再返回，工坊战斗暂停：`22-tab-return.json`。
- 导出暂停，等待后时钟仍3.5秒：`23-export-paused.json`、`24-export-still-paused.json`。
- 胜利领取后按钮禁用，再次请求被工具拒绝，材料保持1：`46-claim-once.json`；核心层幂等另由既有测试覆盖。
- 项目仅买2件，第三件保留；安装后不重复消耗，不追加付款。
- 塔撤退无材料：`44-tower-retreat.json`。公共撤退用药照扣、贡献0，不再显示报名按钮：`50-public-retreat.json`。
- 重开先弹确认，取消仍保留35铜/1绑带/1药；确认才回48铜/0材料/11工程首页：`53-reset-dialog.json`、`54-reset-cancelled.json`、`55-reset-confirmed.json`。
- 完整窗口复看：普通/高难终局与v0.3.3战斗页，关键操作和结算无裁切。Stage Manager 的倾斜缩略图移入 `native/diagnostics/`，不作为布局证据。

CUA此前多次返回 `Sky Computer Use native pipe closed before response`，当时只读到首页；该历史限制已由本次用户授权的原生控制绕过。没有把旧首页读取补写成早已完成实玩。

v0.3.0的21项测试与288场程序矩阵仍是规则证据；v0.3.1–v0.3.3每版构建签名成功，本轮新增的是上述真实UI操作证据。v0.3.2自动选目标只在UI模型中处理，v0.3.3仅同步库存/消息；没有重跑并冒充新的288场。最终源码/包散列见 `source-sha256-v033.json` 和 `app-sha256-v033.txt`。

## 接入时固定的范围

先迁入一个普通公共事件和一条皮革工艺链；高难模式可继续内测，不把本例当人物决战。把当前夹具背包、资格、11套工程及其他账号成绩替换为实际记录，保留幂等回执；退出、重启和结算中断必须不会重复发料、扣款或发贡献。普通参与不强制买药/封印物，采购上限必须可见且有钱才接单。

仍未验收：四专业全部配方、完整八篇新闻/准备期、角色成长成本、核心人物死亡与继任、投资经营/真实订单、多人服务端与自由交易、银行、长期货币稳定、iPhone视觉体验。上述内容不能随第一条本地接入一起宣称完成。
