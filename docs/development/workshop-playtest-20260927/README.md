# 事件工坊可玩闭环验证

2026-09-27。范围为隔离macOS试玩，复用Swift战斗规则，不读取正式存档，不修改既有奖励。目标是让新闻动机、生产交付与公共行动能在同一窗口实际操作；不再只展示概率推演。

## 本轮实现

- 两派公报及立场入口；无需投资或工资才能参加。
- 真实F1目录和盾颚魔战斗。胜利回执才能领取候选韧皮，失败、撤退、重复领取均不发材料。
- 1韧皮＋13铜加工出3绑带，熟练度+1。项目只收2条，每条9铜，未售出的1条留在背包。
- 买入与安装分开：交货只是钱物转移，安装才消耗2绑带及预置布、锡罐并完成第12套组具。
- 普通/困难公共行动使用实际战斗结果计1/2点，正常失败与撤退占用一次尝试。药品9铜，服用才扣数量；购买款属于商人钱包，非销毁。
- 简化合同结果、公报及逐笔账单，可导出JSON。双方关键NPC仍存活，不假造人物决战。
- 暂停、切页暂停、重新体验确认和终局禁用动作；不支持读档续玩。

## 准备对照结果

[288场报告](preparation/TRIALS.md)与[原始数值](preparation/trials.json)均已生成；所有288条结果与上次v2.1基线逐字段相同，新增塔驱动分支没有改变原公共遭遇结果。普通护卫72/72、高难护卫66/72、普通回流72/72、高难回流72/72。144个药品配对中6组败转胜，73组结束生命提高。矩阵报告本身不模拟钱物；本轮工坊闭环才单独验证这些结算，两者不能混称市场验证。

`matrix-normalized.log`只从原始日志移除插入的测试框架提示并解析JSON，未改任何模拟结果；生成报告前校验288条、唯一配置及勋章实际生效。固定程序策略结果不是普通玩家胜率。多数遭遇对程序策略依然容易，不能据此宣称世界人物战已经够难；护卫抢攻没有时间优势这一旧限制仍保留。
