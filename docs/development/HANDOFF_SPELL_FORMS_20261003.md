## 法术样板改了什么

全部在 `claude/hero-v4-device-20261001`，改前原件备份在工作树的 `backups/spell-spectacle-20261003/original/`（不进 git）。

**`SpellSpectacle20260926.cs`**

- 新增 `Form` 维度，取值为 `Bloom`（原样）、`Throw`（投掷＋落印）、`Hunt`（召唤体追击）、`Rain`（落雨＋地涌）。
- `BeginPlayer` 多了一个预计命中时间参数。有形式的牌在施法一开始调用 `Launch`，按 `LaunchShots` 生成轨迹带和一个沿同一抛物线飞的亮弹头（`Flares.Projectile`），掐着时间在命中那一刻落到目标。
- 命中提前到来时，`Contact` 调 `Body.Hasten`，在 0.06 秒内补完飞行。
- 命中时走 `FormImpact`：尺寸是原来的 0.62，粒子朝前喷。
- 主角技能只有终极技（`declaration`）保留全屏染色。
- 新增 `HasForm()`。
- 配置改动：
  - `seal`：深红，熔蜡火焰质地，投掷；
  - `chase`：暗紫，墨质地，追击；
  - `climax`：彩虹，扑克牌加火花，落雨；
  - 三招都去掉了签名（泼墨、雷电、双翼）。

**`BattlePrototype.cs`**

- `BeginPlayerSpectacle` 和 `PlayTempoSkillVisuals` 把预计命中时间传下去。
- 节奏样板里，有形式的牌不再播旧的主角剧场层（`HeroArcanaTheatreVFX` 的分身光体和巨型塔罗，`HeroIdentityTheatreVFX`）。

**`CombatTempoPresentation.cs`**

- 伪证（`fool_skill_05`）也走节奏样板：动作用 `CastCardFan`，命中时间 0.62 秒。
- 命中时间会传给表现层。

**`CombatTempoDeviceReview.swift`**

- 主角样板卡组改成伪证、双影、荒谬三张。

**没动的部分**

- 规则层（Swift）没改，命中时刻也没改。
- 非节奏战斗里，这三招现在会同时播旧剧场和新形式，还没复看。那条路径的命中时间靠旧剧场报回，删旧剧场之前要先把命中时间移出来。

## 下一步

按“要改变，但是要保持同样的绚丽感”来做。

1. **推进段要粗而华丽。**
   - 每道轨迹三层：一条主带，加两条绕着主带旋转的副带，颜色错开。
   - 沿途在弹头经过的时刻撒 20–30 个小亮点，做成火花尾迹。
   - 弹头用大亮星，加上这一招的道具（扑克牌、蜡滴）。
2. **起点要在主角身前看得见。**
   - `BuildMesh` 的前 12% 淡入要关掉或缩短，起点宽度不能从 0 开始。
   - 弧顶压在约 0.6 个身高以内。
   - 荒谬的道具从主角肩头出发。
3. **双影要像两个“影子”。**最华丽、也最贴“双影”的做法，是复用 `HeroArcanaTheatreVFX` 已有的主角分身抓取（`CaptureGhosts`），让两个主角分身贴地冲向敌人，替换现在的墨带。不行就回到烟质地，做成两条贴地、宽约 0.25 身位的人影形带，不要立成墙。
4. **命中段放大到 0.85。**层次照旧版：主体 2–3 层，加签名，加亮芯。但只在目标周围、朝前张开，可以有一次目标周围的局部光晕，不能全屏。
5. **每一轮都录模拟器。**录 60 秒，用 `scripts/video_contact_sheet.swift` 做逐帧拼图，三招各取出手、飞行、到达、命中、回收五帧，和参考帧、旧版并排给用户看。
6. 用户认可主角三招后，再推到其他技能和敌人；然后做规则第一批。

## 怎么复现

构建（复用模拟器的增量缓存）：

```bash
MISTPORT_BUILD_OUT="/Volumes/andrew's SSD/Mistport-build-cache/hero-v4-sim-20261002" sh scripts/build_hero_v4.sh simulator 169.32
```

安装：

```bash
xcrun simctl install E64100C9-43DA-4B8C-996A-2D953A13219C "/Volumes/andrew's SSD/Mistport-build-cache/hero-v4-sim-20261002/Derived/Build/Products/Debug-iphonesimulator/Mistport.app"
```

静音启动主角样板：

```bash
xcrun simctl launch --terminate-running-process E64100C9-43DA-4B8C-996A-2D953A13219C com.yourcompany.mistport -MistportCityMute YES --tempo-device-review=hero
```

- 只改 Unity 脚本时，先在编辑器里编译一次，再用 `grep "error CS"` 查编译错误。编辑器编译命令见 `mistport-spell-spectacle` 技能。
- 录屏写到 `/private/tmp` 下，再复制到 SSD。
- 战斗大约在启动后 10 秒开始；三招在第一轮按卡栏顺序出，之后按冷却出。
