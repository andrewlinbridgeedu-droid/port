# 主角品质样板 · 2026-09-16

用户要求先做主角，承接“先把主角和代表敌人制作成品质样板，再扩其它角色”。本批只改主角，不重设计敌人/数值/关卡/法术主体。不能将本样板称为已经达到魔兽级整体制作。

## 本批方向

- 原主角黑发、紫黑衣装、金线与长衣带身份保留。原发片做局部几何收整，非全局加面。
- 沿真实衣领和双袖截面做独立蒙皮滚边。最终低面版990点、1980三角。通过主体char1的119个UV对应点解坐标转换，并审计全部残差；不得再按最大顶点数选择长衣带当身体。
- 主体真实UV语义图区分脸/手、发片与靴皮，保护皮肤，头发不再继承源atlas里的金纹与衣料normal。
- 不对称警戒待机：上臂自然下垂、前臂朝前；短观察/停顿/回看和小重心变化。骨盆略抬，原脚位置与朝向用两骨IK约束，原站位/步宽保留。攻击、受击、死亡、过渡时让出骨骼。
- 原面纹缺少清楚五官、眉区有黑纹污染。本轮使用内置imagegen生成原画身份的脸部投影纹理候选，再按真实相机投回原UV；平面纹理不能当游戏实拍。

## 原始证据与迭代

`output/hero-quality-sample-20260916/baseline`取自上一轮已构建运行器，保留真实旧战场，未以关闭全部历史修饰代替旧版。

首轮肘pole过于向侧，出现叉腰姿势，已拒绝并改为向下为主。滚边首两轮因错误选中FoolRibbonRight而拒绝安装，失败记录保留；第三轮明确匹配char1，119点最大残差1.237783e-7，990点滚边实际安装。

第三轮20秒实际运行最大足端求解误差0.0000005世界单位，根位置不变。只证明附加IK不额外移动原脚目标，不等于原动画任何帧都没有视觉脚滑。正背静帧已检查，未见明显新腕反转/手穿胸。

## 最终接入与验证

面部2048 RGBA投影已接入HeroFacePaint：只覆盖脸片，侧背面不重复五官；shader保护眼眉纹理，弱化旧脸部normal污染。刘海380点局部上抬8mm、内移最多2mm（合位移≤8.25mm），其它FBX属性含UV/蒙皮/骨骼/动画逐项保持。原头发此前局部整理1572点，最大2.42mm。不是重新雕刻完整头部；发片棱角及低面脸几何仍是限制。

第四轮发现滚边119探针中12个仍引用抬刘海前坐标，触发严格残差拒绝安装。已从最终FBX刷新真实探针坐标，不放宽阈值；失败记录保留于pass4-rejected。

八招实际运行命中/完成各一次，取消后无迟到命中、死亡清理及重试通过，证据output/hero-quality-sample-20260916/casts。最终待机/近景与原生构建结果见本报告追加回执。
