## 真机发现的正式路径问题

离线地图处理器原先只对请求文件做 `standardizedFileURL`，根目录未规范化。Foundation 会把存在的 `/private/var` 规范化成 `/var`，前缀检查因此把合法的 `index.html` 当成越界/缺失，街道呈空白。现统一规范化根目录与候选文件，并解析符号链接后验证仍在资源目录内，保留读取错误诊断。Mac复现显示旧检查拒绝已有文件，修正后可读，`../`仍被拒绝；iPhone随后成功加载并到达邮差。

夹具准备阶段还修正了：未进入标题页之后的城市流程、跳关途径只在内存未写入独立测试档、战斗未先预加载Unity。未将这些失败尝试记为通过。
