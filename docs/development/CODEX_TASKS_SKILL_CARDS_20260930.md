## 任务 C0：3 张样张（先做，交用户认可）

画**假面谕令、荒谬归结、无名宣告**三张。三张分别是铺垫、兑现、终极，边框三种颜色都能看到。

- **卡面中央只画道具，不画人物**：
  - 假面谕令：白色半脸面具，系紫丝带，后面有一个淡淡的人影；
  - 荒谬归结：舞台中央倒扣一只礼帽，周围落着扑克牌和断钟针；
  - 无名宣告：黑底上一块空白名牌，四周是烧焦的边。
- **边框**：
  - 铺垫用紫丝绒；
  - 兑现用暗红加金线；
  - 终极用黑底金边，只有这一张这样画。
- **左上角**：罗马数字编号。假面谕令 II、荒谬归结 VI、无名宣告 IX。
- **卡底戏票边**：带齿孔，写技能名。
- **右侧效果记号**：
  - 裂面具表示误认，一个记号代表一层；
  - 错开的双人影表示错位；
  - 箭头朝外表示施加，箭头朝里表示消耗。

  三张牌的记号分别是：
  - 假面谕令：施加 2 层误认；
  - 荒谬归结：消耗错位；
  - 无名宣告：全体施加 4 层误认。
- **尺寸**：
  - 每张出一张大图，用于获得新牌和图鉴；
  - 再出一张缩到战斗卡栏 58×85 点的预览，道具轮廓必须一眼能认出来；
  - 画风和首页四季原画一致。
- 提示词和原图放 `docs/development/skill-cards-20260930/samples/`，按 LFS 提交。
- **交给用户看。认可之前不画其余 7 张。**
