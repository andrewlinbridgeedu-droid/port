# 猎犬脚下旋焰 · 2026-09-14

用户明确否定方形火焰向主角推进，要求从主角脚下窜起、地面烧黑、火焰旋转同时缩小。

本轮两招火焰均固定在主角脚下，保留第一招破裂坑，第二招取消连续裂缝推进并改为不规则焦痕。圆柱径向密度在包围盒以内降为零；起火后收尾阶段同步旋转、缩小高度和半径。焦痕晚于火焰消退，并随原演出清理，不永久改变关卡地面。
