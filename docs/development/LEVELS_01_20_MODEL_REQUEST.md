# 第1—20关敌人模型规划：按剧情区分

2026-09-12。替代旧“只补5个模型”最低占位清单。用户最新确认：默认每关敌人不同；部分小Boss可以跨关，但故事必须连贯。以下逐关新造型是制作提案，不表示已实现或数值已批准。

## 核对结论

当前ChapterOneContent.swift把抄录傀儡复用于9/10/12/14/18，守卫、猎犬、寄忆核心也大量重复。外部UNIFIED_GAME_DESIGN含旧方案与候选，不是已批准的逐关美术表。旧5模型清单仅能替换技术占位，不能满足当前角色差异要求，不再作为用户制作订单。

3/4/6关同一猎犬已有明确连续故事：循名追猎→远处火球试探→解除颈圈追索。这是合理的小Boss连续线；不是每次死后复活。第5关已要求新敌人，翠焰亡灵模型已交付，但剧情及遗落物迁移未完成。不能因为它插在追猎线中而继续使用旧纸人/猎犬剧情。

## 制作原则与数量边界

- 同阵营允许共用材质语言、骨骼和基础动画，不能因此跨关使用同一可见角色模型。不同模型应在轮廓、器官/工具、动作上可辨认。
- 跨关角色只有明确小Boss叙事线才复用；目前确认的例子是3/4/6猎犬。不把五处互不承接的工作岗位都叫同一抄录傀儡。
- 上表为18组关卡主敌设计（20关减去猎犬两次复用），不是18份新增Meshy订单。第19关有两个独立主体，第2/11关为双体，其他关辅助敌人还需逐一核定。
- 现有1/2/3/5/8资产可作为保留或适配候选；未经逐项外观验收，不武断扣除新增数量。
- 下一步先确定各关主敌和必要辅助敌人，再生成逐模型制作卡与准确新增数量。暂停旧5模型订单，避免先制作通用傀儡后返工。
