# 第一章敌人美术与动作圣经 v1

## 总原则

第一章的敌人不是同一骨架换颜色。五区分别对应“时间被校正、记忆被封存、身份被替演、亡者被召回、选择被剥夺”，轮廓、材质和动作语言必须能在没有文字时区分。

- 商业日式 2D JRPG 彩绘，明亮但危险；角色轮廓清楚，背景水彩感不超过 5%。
- 相机为与当前战斗场景一致的高位 3/4 俯视角，默认朝向画面下方的玩家。
- 地面单位的足部必须落在同一地面线；角色图内禁止自带影子、光圈、文字、UI 与法术。
- 人物动作小而准确，主要强度来自独立 `spellFX`。禁止非等比拉伸、整图摇摆、透视扭曲。
- 不模仿任何既有商业游戏、动漫或小说的角色造型；只使用本项目原创名称、符号和服装体系。

## 第一区：旧钟区

### 失秒巡猎犬（普通近战）

- **前身**：钟塔、煤气管、雾灯线路的市政巡检机。
- **轮廓**：低伏四足，肩部擒纵轮，尾巴是机械配重；不能像未来机甲狼。
- **材质**：约 55% 旧黄铜、25% 深蓝珐琅、15% 黑铁与皮革护线、5% 青色记忆玻璃。
- **损伤**：掉漆、雨水氧化、外露纸带、刮除的巡检编号；目镜故障时才转红。
- **动作**：idle 爪掌承重与耳朵寻声；melee 压低—跃进—咬合—落地滑停—上弦；不常态飞行。
- **战斗读法**：红圈是即将落点，扑杀结束后的背部发条停转 0.7 秒，是反击窗口。

### 零号原型（精英）

- 失秒巡猎犬的早期军用试验体，不是放大版普通怪。
- 黑金重甲、胸前机械钟摆、脊背十二格倒计时；第二段追猎前亮起第十三格。
- 追猎结束后四肢泄压、背部上弦，形成清楚的疲劳窗口。

### 十三号（剧情伙伴）

- 旧型号救援犬，体型比普通疫犬略小，圆润但不幼儿化。
- 磨损黄铜、深蓝旧珐琅、一只折损耳朵、右前腿有布带维修，青色温和目镜。
- 胸前不是能源炉，而是可抽出的记忆纸带匣；玩家由此得到未经校正的一天。
- 只做 idle / alert / limp / memory-project 四组剧情动作，不作为抽卡宠物。

### 旧钟区其他敌人

- **雾钟怨灵**：被删除的一秒凝成的人形雾影；只有它允许持续低空悬浮。
- **逆时追猎者**：戴钟匠护目镜的真人执行者，脚下固定，手持记录坐标的怀表枪。
- **空壳钟卫**：沉重钟锤守卫，十二次假响后地面钟盘出现安全扇区。
- **吞灯兽**：以煤烟和灯芯形成的四足异兽，跃袭后必须重新落地。
- **逆流泵心**：固定场景机关怪，主体不位移，管线和刻度独立动画。
- **瑟维安**：人形守钟者与环绕镜盘；威压来自校时法术而非巨大身体摆动。

## 第二区：盐栈区

- **盐晶噬兽**：由码头鼠、盐晶和麻袋纤维聚合的低伏生物；晶化层会随移动剥落。
- **盐雾怨灵**：半透明盐雾人形，投射白潮针雨并留下地面结晶。
- **盐晶执事**：穿防盐围裙的人类管理者，使用封存钳与晶柱，不使用犬类轮廓。
- **白潮母晶**：固定生长体，攻击来自不同颜色晶柱和全场倒计时。

## 第三区：镜剧区

- **裂镜舞偶**：关节化舞台演员，披风内衬为破镜；两条假走位轨迹后从无反光侧突击。
- **舞台残像**：薄片般的彩色演员剪影，只在复制技能的一刻变得清晰。
- **镜幕替身**：完整人形但面孔像未上色面具，通过换位交换血条与站位。
- **首席替身**：六种路径幻影环绕主体，真身只在模仿玩家路径时出现一致的影子。

## 第四区：潮门港

- **锈潮钩客**：亡船水手，湿重外套、锚钩和拖地水痕；抛钩后沿直线冲锋。
- **溺忆幽灵**：困在透明水泡中的记忆人形，水泡可被玩家攻击击破。
- **沉潮领航者**：持逆向罗盘的船长，安全方向随罗盘转动而改变。
- **深潮门徒**：海水只在机制阶段托起披风，人物本体始终落在甲板或石台上。

## 第五区：雾岬上城

- **誓约执笔官**：灰白制服、长羽笔和悬浮契文；人物落地，只有纸页围绕身体运动。
- **无面侍从**：三人一组同步施法，面具相同、姿势略有时间差，击破一名产生缺口。
- **议会裁决官**：法槌、卷宗和三种禁令印章，轮换限制普攻、位移、治疗。
- **雾冠执政官**：根据玩家重复行为切换对应面具与反制颜色。
- **无冕议长投影**：不展示完整真身；由六张互相矛盾的半透明议席投影组成，必须用三种动作解除“唯一答案”。
