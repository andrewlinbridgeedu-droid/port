# 已经踩过的坑

按"症状 → 原因 → 做法"记录。都是 2026-09-26 这一轮真实遇到的。

## 画面

1. **录制器报 `no runtime errors` 失败，日志有 `abnormal mesh bounds ... nan`**
   原因：`Mathf.Pow(Mathf.Sin(π·t), 0.x)` 在 t=1 时 sin 是极小的负数，开分数次幂得到 NaN。
   做法：先 `Mathf.Max(0, …)` 再开幂（`Swell` 已处理）；`BuildMesh` 对非有限顶点有兜底，但不要依赖它。

2. **主体边缘像锯齿、宽度逐点乱跳**
   原因：在 `half(t)` 或 `pos(t)` 的 lambda 里调用 `R(rng, …)`，每个采样点都取了新随机数。
   做法：随机值在 lambda 外先取成局部变量。

3. **命中峰值整屏发白，彩色层看不见**
   原因：纯加法混合（`SrcAlpha One`）叠在浅色大理石上直接冲到白。主角原有的 `HeroSpellVolume`、`FoolSidestepRift` 以前就是这样。
   做法：用预乘 alpha（`One OneMinusSrcAlpha`），亮处部分遮住地面，饱和度拉开，高光按色相压缩。只有亮芯、溶解边、闪点做加法。

4. **多目标（H01 双人、H10 四人）叠成一大块白**
   原因：每个目标各一层全屏加法。
   做法：按同时存活实例数以 1/√n 分摊曝光；本层多目标用共享环境主体，每个受体只保留自己的命中心。

5. **用户说"雷同、缺乏创意"**
   原因：前两轮所有身份共用同一张金纹纹理、同一种白星、同一种撕边，只换形状和颜色。
   做法：材质、命中心、签名、动作都要按身份区分。用全身份峰值网格自查，看图时问自己：去掉颜色还能分出来吗？

6. **名招看不出来**
   - 雷电材质用在大面积主体（旋风）上缝隙太多，只剩细线 → 旋风改用烟材质。
   - 金龙太大，盘身冲出画面，又被形态主体和光柱盖住 → 缩半径、变细、多绕几圈，签名为 Dragon 时主形态只留 1 层、去掉副形态和光柱。
   - 莲花被升腾火舌盖住 → 签名为 Lotus 时不生成形态主体。
   - 剑雨刀刃太小、材质太碎 → 放大刀身，精英守卫改用晶体材质。
   - 漩涡绕超过一圈就像同心圆环（项目禁用） → 每臂 0.5–0.72 圈、向内变细。

7. **某个敌人颜色不对**（雾魂变红橙、B04/B06 变金铜、翠焰变橙色）
   原因：皮肤/模板复用，`ProfileEnemyId` 不是屏幕上看到的那个身份。
   做法：按幽灵组件、通缉身份组件、翠焰安装者识别（architecture.md "身份识别"）。每次加身份都要看录像确认颜色。

8. **材质图集行与行之间串色**
   原因：导入默认开了 mipmap。
   做法：`.meta` 里 `enableMipMap: 0`。

9. **焦盘、残迹抢了主体**（M08/M09 黑色焦盘）
   做法：爆发后 0.3 秒内把残迹透明度降到约 45%（`HoundGroundFracture`），让上涌的火成为主体。

10. **水珠变成蛋形白蓝实心椭圆**（B03）
    原因：旧代码里的水珠被接触放大系数一起放大。
    做法：水珠做小、做多。

11. **护盾像 CT 片 / 像肺**（M12 封存装甲），改成钢板后又被说"太实、不好看"
    原因：两片光滑、近乎对称的叶片夹着身体，加上暗蓝半透明底和分叉的亮纹，就是胸部 CT 的样子。但改成不透明钢甲也不对：用户认为法术应该是虚幻的。
    做法：保留"虚"，去掉"CT"。具体是：
    - 错落叠压的羽刃外形，不要光滑的器官状双叶；
    - 饱和的青→蓝→紫能量体，配细白亮边和辉光；
    - 用华彩层的金色卷纹和鳞片纹，不要分叉纹；
    - 尖端消散，加漂浮和呼吸；
    - 金色要直接替换底色，叠加到青色上会变白。
    见 `ArchiveEncounterPresentation.BuildSealedPlates` 和 `ArchiveAegis.shader`。着色器里别用 `line` 当变量名，它是 HLSL 保留字，会编译失败并显示洋红色。

## 录制与工具

12. **补录卡住不动，输出目录只有日志**
    原因：输出目录里没有 `capture-plan.json`。录制器从 `--round2-output` 目录读计划。
    做法：用 `scripts/record.sh`，它会自动复制 `assets/capture-plan-98.json`。

13. **强制结束 Unity 后，下一次启动报 `No valid Unity Editor license`**
    原因：许可证客户端状态没恢复。等一会儿重跑就好了。
    做法：不要中途杀 Unity。`record.sh` 遇到这个错误会等 30 秒自动重试一次。

14. **同一时间只能有一个 Unity 打开这个项目**。项目的 `Library` 是指向外置 SSD 的符号链接，SSD 没挂载时不能录，也**不要删除或重建这个链接**。

15. **录制器编码器路径写死为** `/tmp/mistport-vfx-encode/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v7.1`。
    重启后 `/tmp` 会清空。`record.sh` 会重建 venv 和软链。

16. **展示视频里中文标签显示为方框**
    原因：ffmpeg drawtext 的字体路径不存在（PingFang 不在 `/System/Library/Fonts` 根目录）。
    做法：`showcase.py` 依次尝试 `STHeiti Medium.ttc`、`Hiragino Sans GB.ttc`、`Arial Unicode.ttf`。

17. **拼接视频的预览图里很多格没有特效**
    原因：按段长度推算时间偏了。
    做法：预览图直接从原片按 `peak_seconds` 取帧，不要从拼好的视频里推算。

18. **近景机位看不到命中**
    原因：敌人招式的近景对准施法者，命中在主角身上。
    做法：看全景片，或者录 `*-recipient` 受体机位行。

19. **原总览录制计划缺 B07–B10**
    这 9 组来自 `output/tower-bounty-growth-20260924/capture-plan.json`，已经并进 `assets/capture-plan-98.json`。

20. **主角的“往前打”轨迹在屏幕上叠到敌人身上，主角和敌人之间什么都没有**（2026-10-03，169.30–169.33）
    原因：节奏样板里的主角模型只有约 1 米高，`player.transform.position + 1.15 m` 落在主角头顶上方。战斗相机在主角身后约 15 米、几乎平视（视角 28°）。在这种相机下，离地越高的点，投影越靠近敌人那条水平线：主角头顶 0.5 米处的起点在屏幕上已经和敌人的脚一样高，抛物线再往上一拱，就叠在敌人身上，像从敌人头顶喷出来。这不是着色器、淡入或遮挡的问题；世界坐标完全正确。
    做法：有形式的牌从主角**可见模型**的胸口出发（`BattlePrototype.HeroChestPoint`，取蒙皮包围盒）；空中弧线压低到约 0.15 个 s；贴地的东西（双影尾迹）最容易读出方向。改之前先开 `SpellSpectacle20260926.Diagnostics`，看控制台里的 `SPELLFORM` 坐标再下结论。

21. **节奏样板里，普攻会重放上一张牌的命中**
    原因：节奏样板的普攻不登记自己的 cue，它的 `player` 接触回执落到上一张牌仍在有效期（6 秒）的 cue 上。荒谬的彩虹命中因此每次普攻都亮一次。
    做法：主角牌的 cue 在第一次命中后最多再保留 0.45 秒，留给多段命中用。

22. **静音启动的复看仍然有声音**
    原因：`-MistportCityMute YES` 只管港城环境声。战斗音乐（`HomeMusicController`）不认这个开关；`audio-volume:0` 只压法术导演的音量，敌人、受击和 Effekseer 的声音照样响。
    做法：169.35 起，DEBUG 下带这个开关时不放任何音乐；Unity 收到音量 0 时把 `AudioListener.volume` 设为 0；主角样板在场景就绪时也会发一次 `audio-volume:0`。录完模拟器就终止应用并关机。

23. **命中整团立着，然后原地变淡消失，用户觉得不自然**（2026-10-03，169.51 → 169.54）
    用户在手机上框着普攻的命中说：“我要的是这类效果散开，消散，才够自然”。
    做法：命中的每个体在淡出时外扩约 55%、略微上浮，淡出时间拉长到 1.9 倍，并从自身表面甩出光点。光点以会胀大、往上飘的软光团为主，加少量火花，持续 0.8–1.3 秒（`Dispersing`、`Body.Disperse`、`Flares.Scatter`）。
    注意：
    - 只拉长淡出（169.52 的 1.5 倍、光点 0.55–0.95 秒）几乎看不出散开，峰值后约 0.3 秒就没了。
    - 主角身上的出手光不能和命中散得一样大。主角离镜头近，光团会铺满主角到敌人之间的走廊（169.53 的 Q4 错步）。出手光的光点尺寸约一半、数量四成、外扩 25%。

24. **身份材质画在宽带子上，用户不喜欢**（2026-10-03，169.60 → 169.65）
    用户在手机上框出错步落在猎犬身上的交叉斜刃和主角身边的出手光舌，说“我不喜欢这2个的样子”。两样都是 0.5 个命中尺寸以上的宽带子，用晶体材质（Voronoi 碎块加边线、硬边刻面）画，读成一块块碎彩玻璃板；出手光舌还挡住了主角。
    做法：错步落点换成 `Family.MirrorCut`（细长弯月剑光交叉，丝的外观，平静散开）；出手光换成四缕细光丝，从肩背往上往外飘。
    注意：
    - 绕身螺旋的光丝从低机位看是套住主角的竖椭圆，读成光框（169.62）。光要从身体往外走，不要绕回来。
    - 地面上往远处走的东西（冲刺擦光、鞋印）要画在视频主角下层，否则在主角身上叠成竖线和横条。
    - 细线散开不能大力扯，也不能靠缩小尺寸减推力（会扯出小折）；用 `calm`。
