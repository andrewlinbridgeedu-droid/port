# 物品体系：从序列 9 到成神

物品不是独立的数值碎片，而是世界、战斗和晋阶之间的连接层。每件物品必须同时回答：来自哪里、解决什么问题、在哪个阶段退出流通。

## 四类用途

1. **补给**：只影响接下来一至三场战斗，例如生命、侵蚀耐受、首次冷却。不能成为永久战力来源。
2. **情报**：发现隐藏节点、揭示敌人行动、改变任务分支或商店内容。愚者对这类物品有额外利用方式。
3. **制作素材**：用于技能媒介、遗落物维护和药剂制作。来源与怪物、地区生态绑定。
4. **晋阶材料**：服务于明确的序列配方与仪式验证。主要来自首领、精英、剧情选择；商店只能低概率补足一件辅材，不能直接买齐晋阶。

## 阶位与品质是两条轴

### 阶位（决定适用阶段）

| 阶位 | 角色阶段 | 投放原则 |
|---|---|---|
| I | 序列 9、第一章 | 城市日常物、低侵蚀怪物材料、晋阶辅材 |
| II | 序列 8–7 | 地区秘产、路径专用媒介、可组合制作 |
| III | 序列 6–5 | 联邦级禁物、带代价的强效消耗品 |
| IV | 序列 4–3 | 半神材料、规则碎片、跨路径交易物 |
| V | 序列 2–1 | 唯一性材料、神话生物残留、阵营核心秘藏 |
| VI | 序列 0 / 终局 | 神格容器与结局钥匙，不进入普通随机掉落 |

高阶区域不继续掉落低阶同名物。需要保留的物品会沿谱系升级，例如“雾糖方块 → 凝梦糖晶 → 无眠圣糖”，外观、名称、效果和来源同步变化。

### 品质（决定同阶稀缺度）

- 普通：可靠、单一用途。
- 精制：同用途强化或附带小型条件效果。
- 秘仪：改变一次行动规则，通常带使用条件。
- 圣遗：剧情唯一或限量，不以单纯数值替代旧物。

## 投放约束

- 普通任务保证补给或基础制作素材，避免空手而归。
- 精英任务提供路径素材或遗落物维护材料。
- 区域首领提供晋阶主材/线索；商店稀有货只负责补缺。
- 情报物必须改变可见信息、关卡或选择，不能只换成货币。
- 所有物品插画表现真实可持有的对象；抽象符号只用于类别与状态，不作为商品本体。
